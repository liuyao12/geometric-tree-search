What is being compared?

Free-range enumerates every allowed placement touching the target, checks all dead points, propagates all forced moves, then branches in the earliest generation. Every target point starts at generation zero. All four lanes use this same graph and exact rollback.

GCTS adds redundant vector markings, residual-capacity proofs, and bounded failed-move lookahead. RL learns returns for irregular three-placement cluster proposals and uses them to order the complete base list. Every proposed step passes the base scheduler. No periodic motif or catalog identity guides either lane. The cluster lane combines rollout lookahead with online returns; its advantage cannot automatically be attributed to learning.

Learning starts fresh in every lane. These are online experiments, not a pretrained or held-out generalization claim. The export includes proposal expansions, costs, point data and independently replayed results.

What would count as evidence?

The main result is an exact finite point window. Hat and turtle use one slab on the index-3 A₂ sublattice: both caps have planar weights, and translations stay within the slab. Other catalog tiles use the original 3D window. All targets have an open lateral boundary. It does not certify a geometric solid tiling or infinite extension. A budget limit means unknown. Only a fully exhausted finite search proves that this window has no solution.

Research tiles and nonconvex stress tests are separate from known periodic controls. A missed bounded periodic probe does not establish aperiodicity. All geometric pictures illustrate the point data; geometric overlap is not a base legality test.

Compare multiple seeds and larger windows. Total time includes model construction, complete graph construction, marking synthesis, learning and verification. Runs are sequential to avoid four workers competing for CPU. Memory is an estimated data footprint, not browser process memory.
