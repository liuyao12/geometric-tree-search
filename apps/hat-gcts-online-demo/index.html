What is—and is not—being learned

A geometric certificate, not a branch ID

  1. 01

    Try geometry first

    The search starts with one unmarked Hat. A trial is failed only when placing it exposes a frontier point with no legal Hat continuation.

  2. 02

    Find a mismatch witness

    The learner searches overlapping A₂ site/channel pairs. It adds only the local sites needed for at least one unequal value across the failed contact.

  3. 03

    Protect the prefix

    All contacts in the accepted patch are equality constraints. A proposed update is committed only if the full prefix replays without a marking conflict.

  4. 04

    Reuse geometrically

    The learned marking transforms with every Hat orientation. A later placement with the same forbidden local geometry is rejected before lookahead.
