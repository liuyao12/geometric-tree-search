How to use the marking controls

Start tiling with the checkbox off to ignore markings. Check “Tiling with marking” to start again from the same seed with the chosen directions enforced. “Show marking,” direction colors and line weight only change the drawing; they do not change or restart the search.

All five directions give the complete fixed Ammann rule. The 1- and 3-direction settings are weaker experiments, enforcing the first direction families in the fixed cyclotomic frame. All five stripes remain on every rhomb; unenforced directions appear gray. These settings count marking channels, not the rank-four integer coordinate lattice.

The search checks exact polygon non-overlap, corner capacity and a single outer boundary, with genuine backtracking. It uses no window oracle. Unmarked rhombs allow more tilings, including periodic ones, so adding matching rules does not guarantee a faster search. A finite patch or a budget stop is not a proof about infinite tiling.

The thick and thin rhombs each carry a complete, fixed five-stripe template. When matching is enforced, the solver finds compatible rigid orientations for the selected direction families. These orientations can be resolved differently as the search extends or backtracks.
