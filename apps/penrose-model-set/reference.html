Why this is the proper generalization

Each individual Penrose vertex set is Delone, while the common cyclotomic module is dense. The universal module remains the exact ambient address space, but the canvas now draws only the finite support reachable by the active patch.

All model coordinates are exact integer coefficient vectors in the basis 1, ζ₅, …, ζ₅⁴, with an exact integer denominator. Pentagrid floors and radius comparisons are performed in ℚ(√5). The P1 patch is reconstructed from unit-edge direction steps in ℤ[ζ₅]. Conversion to floating-point occurs only when a coordinate is projected to a canvas pixel.

Ammann-bar crossings require an augmented support set on tile edges, for example exact parameters involving φ/2 = (1+√5)/4. These are algebraic points, but usually not Penrose vertices. The current markings use exact edge parameters 1/(4φ), 1/(2φ²), 1/2, and their complements. The same complete template is used for every copy of a given rhomb, including tiles on the outer boundary.

The P2 view follows the standard mutual-local-derivation rule illustrated in Figures 30–32 of Bettencourt’s Penrose-tiling thesis ↗.

P3 generates lattice translations on exposed edges, checks capacity and fixed Ammann marking compatibility, then applies an exact de Bruijn pentagrid predicate. No precomputed target patch is queried. P2/mixed catalogs retain the bounded model-set solver. Original 1981 paper ↗
