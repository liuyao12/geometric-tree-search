## Current experiment

Choose Penrose tiles and a patch-generation rule. The **Marking space** lane
observes the current patch without constraining its search. Each oriented tile
has one symbolic variable at each vertex and edge midpoint. Coincident support
points impose equalities. Their rigid images impose equalities as well. This
cuts down a finite-dimensional linear space exactly.

The **Local matching** lane runs the same search without the observer. Both
lanes can use bare geometry or supplied Penrose boundary rules. The **Ammann
control** uses supplied infinite lines and is a separate marked problem,
independent of the bare/supplied selector. The circular P2 arcs are an optional
illustration; no search or learner imports them.

The sevenfold tab retains its existing supplied Socolar-rule and bare-rhomb
experiments. The new marking-space observer is currently fivefold only.

## Mathematical model

Coordinates use
\(\mathcal O_{\mathbb Q(\zeta_5)}=\mathbb Z[\zeta_5]\) with independent basis
\(1,\zeta_5,\zeta_5^2,\zeta_5^3\). Vertex and midpoint addresses belong to
\(\frac12\mathcal O_{\mathbb Q(\zeta_5)}\). The physical embedding is dense;
placements are generated by finitely many exact vertex alignments, never by
scanning all ring points inside a planar region.

Let \(A\) index support addresses across the distinct rigid oriented tile types.
Start with \(M_0=\mathbb Q^A\). For each contact in the current patch, impose
\(x_a=x_b\), together with its images under the allowed rigid group \(G\).
Thus \(M(P)=\ker D_P\), where \(D_P\) includes this symmetry closure.
The group permutes address variables; it includes the stabilizer actions of
symmetric tiles. No independent rank is inferred from the number-field degree.

For equality constraints the exact kernel is represented by equivalence
classes. With \(R_P=\operatorname{span}\{e_a-e_b\}\), the displayed universal
values are the images of \(e_a\) in \(\mathbb Q^A/R_P\), denoted \(u_i\).
The solution space is the dual of this quotient. Assigning arbitrary scalars
to its independent symbols gives every scalar solution. Group closure lets
rotations and reflections induce a permutation action on the quotient.
Symbols are not fixed numerical labels; different symbols need not disagree.
Unassigned points outside the finite support have no value, including no
implicit zero.

A reversible union-find structure maintains the partition and exact dimension.
Contact counts count a spanning set of equalities at each occupied world
point before symmetry closure, including redundant equations. The independent
equality count is the original dimension minus the remaining dimension.
Adding a tile intersects the space; removing it restores the exact previous
space. Monotone transport revision numbers also change on nontrivial rollback,
so the renderer never reuses a stale partition.

This is a branch-local patch observation experiment, not pair-corona training.
Even a subsequently failed partial branch has its own compatible marking
space; its constraints are not promoted to global evidence. There are no
negative labels, permanent learned exclusions, saved assignments or activation
gate. Constants always survive. The learner does not prune candidates. A
nontrivial marking here does not certify infinite extension, a forcing rule,
aperiodicity, or a realization by curves.

## Architecture and scope

| File | Current role |
| --- | --- |
| `learning.js`, `lanes.js`, `learning-display.js` | UI, exclusive worker dispatch, exact symbolic-value display |
| `learning-worker.js` | Selects marking-space observer for the primary lane; uses generation-first scheduling in all live Penrose lanes |
| `assets/cyclotomic-marking-space.js` | Fixed support, verified rigid permutations, incremental equalities and exact rollback |
| `assets/cyclotomic-obstruction-search.js` | Shared growth adapter; historical pair learner remains available to existing research callers |
| `assets/tiling-frontier-graph.js` | Complete shared candidate incidence, global dead/forced priority, reversible graph; explicit generation-first option |
| `assets/penrose-selection-problem.js` | Bare geometry or supplied boundary inputs |
| `assets/penrose-circular-arcs.js` | Display-only circular arcs |

All graph decisions first check global dead ends, then propagate forced moves,
then branch at the earliest generation. Minimum candidate count breaks ties
within that generation. New tile generation is one plus the minimum incident
generation; seed generation is zero. Candidate generation enumerates all
oriented positive-support vertex alignments. Complete undo includes the graph,
point totals, generations, failed-child exclusions and marking-space partition.
The observer cannot alter candidate legality, so it does not add marking
invalidation dependencies. All three live lanes opt into this scheduler; older
headless callers keep their historical degree-first default for benchmark
reproducibility.

This is a **geometric control**, not a conforming pure point-value baseline:
polygon-overlap and partial-edge predicates supplement corner capacities;
supplied rules are optional problem inputs. The finite-support observer cannot
certify unrestricted plane coverage. Floating-point spatial indexing remains a
conservative optimization around exact cyclotomic predicates. No RL proposal
system is enabled. See the [master contract](../../docs/basic-tiling-algorithm.md).

- `scripts/test-cyclotomic-marking-space.mjs`: independent recomputation from
  all transformed patch contacts, exact dimensions, group-equivariant classes,
  rollback and alternative branches; bare and supplied P3/P2/P1/mixed inputs.

  active support counts and known-line control.
- `scripts/test-tiling-frontier-graph.mjs`: global dead/forced checks, both

- `scripts/test-penrose-lanes.mjs` and `test-penrose-display-cache.mjs`: worker
  isolation, pause/resume, display caching and model changes.
