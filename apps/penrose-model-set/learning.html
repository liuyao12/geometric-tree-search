What is being learned?

The learner starts with no marking points. At a dead frontier point, it checks whether a pair of placed tiles makes completion around that point impossible. Only an exhaustive negative certificate becomes a rule; a timeout or a failed larger cluster is insufficient.

Each certified pair gets conflicting 0/1 values in a fresh channel at a common world point, transported to both tile templates. Rotations and reflections permute channels. Subsequent matching uses only equality of defined values at coincident points. Undefined is different from zero. The marking reuses the failed frontier vertex wherever possible; some proofs require a point outside one of the tiles.

Learning survives backtracking and Continue. Reset starts the selected search empty. Switching methods pauses the current search and preserves its progress. Run or Continue advances only the selected method. Each method keeps its own corona target and active timer; paused time is excluded. Changing the tile selection resets all methods. The point–candidate graph maintains forced moves and branching. The learner does not inspect Ammann bars. Its adaptive channels are not the classical five line families.

P3 uses independent edge arrows. P1/P2 and mixed sets use the previously supplied colored boundary ports. Those boundary rules were transferred from the existing decorations; they are problem input, not newly discovered aperiodicity rules. The learner has no access to bar interiors or extensions.

Mixed sets are experimental. Tiles are permitted, not required. The existing common scale is preserved: P1 cannot share a whole edge with P2/P3 at this scale, while mixed P2/P3 can be attempted. A run may exhaust its frontier or use only part of the selection.

The Ammann method compares infinite supporting lines directly, without an edge-label check or point-value marking table. Whenever a line meets another tile, that tile must carry the same line in the same family. Lines crossing in different families are allowed. The canvas clips the lines only for display. This method can produce a different patch. Run stops at a completed frontier corona; finite patches do not prove infinite extendibility.

Why sevenfold is interesting

These three rhomb shapes occur in studied sevenfold quasiperiodic tilings. Schaad’s A Challenging 7-Fold Tiling Puzzle gives a substitution construction. Socolar’s Weak matching rules for quasicrystals establishes weak local rules for rotational orders not divisible by four. Weak rules bound displacement in internal space; this is subtler than copying Penrose’s edge arrows.

The undecorated rhombs also tile periodically. The optional rule here forbids equal-shaped neighbors across a full edge. It removes monochromatic rhomb grids, but is an exploratory restriction: neither infinite extension nor aperiodicity has been established for it. No published sevenfold matching rule or learned certificate is being claimed.

Point model, markings, and search scope

Coordinates use the independent basis \(1,\zeta_7,\ldots,\zeta_7^5\), with \(1+\zeta_7+\cdots+\zeta_7^6=0\). Edge directions are \(e^{k\pi i/7}=(-\zeta_7^4)^k\), so all tile vertices stay in \(\mathbb{Z}[\zeta_7]\). A rhomb of acute angle \(k\pi/7\) contributes corner values \(k/14\) and \((7-k)/14\); a complete corner has total \(1\).

The experimental marking assigns \(0\) or \(1\) at edge midpoints in \(\tfrac12\mathbb{Z}[\zeta_7]\), in separate channels for each shape and unoriented edge direction. Opposite boundary directions give conflicting values for equal-shaped neighbors. Different shapes have undefined values in each other’s channels. Hollow and filled dots display the two values.

This is a geometric search control: exact coordinate identities, integer corner capacities, and exact marking equality are combined with floating-point polygon separation and edge-to-edge checks. It is not a certified exact geometric solver or a pure point-value baseline. The complete point–candidate graph checks global dead ends, then forced moves, then the earliest generation, with reversible updates. Only exposed corners are activated; there is no claim of covering the entire infinite point domain. The existing Penrose methods remain separate.
