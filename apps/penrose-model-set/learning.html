What is being learned?

The learner starts with no marking points. At a dead frontier point, it checks whether a pair of placed tiles makes completion around that point impossible. Only an exhaustive negative certificate becomes a rule; a timeout or a failed larger cluster is insufficient.

Each certified pair gets conflicting 0/1 values in a fresh channel at a common world point, transported to both tile templates. Rotations and reflections permute channels. Subsequent matching uses only equality of defined values at coincident points. Undefined is different from zero. The marking reuses the failed frontier vertex wherever possible; some proofs require a point outside one of the tiles.

Learning survives backtracking and Continue. Reset or a mode change starts empty. The point–candidate graph maintains forced moves and branching. The learner does not inspect Ammann bars. Its adaptive channels are not the classical five line families.

The known benchmark adds the existing continuous Ammann predicate with extent 2. It is a stronger constraint and can produce a different patch. This comparison measures this implementation, not a claim of universal superiority over Ammann markings. Run stops at a completed frontier corona; finite patches do not prove infinite extendibility.
