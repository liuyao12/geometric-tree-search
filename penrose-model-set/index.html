What is being learned?

The learner starts with no marking points. At a dead frontier point, it checks whether a pair of placed tiles makes completion around that point impossible. Only an exhaustive negative certificate becomes a rule; a timeout or a failed larger cluster is insufficient.

Each certified pair gets conflicting 0/1 values in a fresh channel at a common world point, transported to both tile templates. Rotations and reflections permute channels. Subsequent matching uses only equality of defined values at coincident points. Undefined is different from zero. The marking reuses the failed frontier vertex wherever possible; some proofs require a point outside one of the tiles.

Learning survives backtracking and Continue. Reset starts the selected search empty. Switching methods pauses the current search and preserves its progress. Run or Continue advances only the selected method. Each method keeps its own corona target and active timer; paused time is excluded. Changing the tile selection resets all methods. The point–candidate graph maintains forced moves and branching. The learner does not inspect Ammann bars. Its adaptive channels are not the classical five line families.

P3 uses independent edge arrows. P1/P2 and mixed sets use the previously supplied colored boundary ports. Those boundary rules were transferred from the existing decorations; they are problem input, not newly discovered aperiodicity rules. The learner has no access to bar interiors or extensions.

Mixed sets are experimental. Tiles are permitted, not required. The existing common scale is preserved: P1 cannot share a whole edge with P2/P3 at this scale, while mixed P2/P3 can be attempted. A run may exhaust its frontier or use only part of the selection.

The known benchmark adds the existing continuous Ammann predicate with extent 2. It is a stronger constraint and can produce a different patch. Run stops at a completed frontier corona; finite patches do not prove infinite extendibility.
