Why this is the proper generalization

Each individual Penrose vertex set is Delone, while the common cyclotomic module is dense. The universal module remains the exact ambient address space, but the canvas now draws only the finite support reachable by the active patch.

All model coordinates are exact integer coefficient vectors in the basis 1, ζ₅, …, ζ₅⁴, with an exact integer denominator. Pentagrid floors and radius comparisons are performed in ℚ(√5). Conversion to floating-point occurs only when a coordinate is projected to a canvas pixel.

Ammann-bar crossings require an augmented support set on tile edges, for example exact parameters involving φ/2 = (1+√5)/4. These are algebraic points, but usually not Penrose vertices. The current midpoint support is an intentionally visible baseline; the next learner adds the classical one/double golden ports.

The P2 view follows the standard mutual-local-derivation rule illustrated in Figures 30–32 of Bettencourt’s Penrose-tiling thesis ↗.

This first implementation uses de Bruijn’s regular pentagrid, dual to a Penrose rhomb tiling. The accepted completion is certified by that pentagrid window oracle. Original 1981 paper ↗
