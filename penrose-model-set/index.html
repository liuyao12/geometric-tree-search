What this comparison demonstrates

Each lane runs a real depth-first search in its own worker. Candidates attach to the nearest exposed edge, with the same deterministic ordering and proposal budget. Both enforce exact polygon non-overlap, corner capacity, and a single outer boundary. The right lane also solves the rigid orientations of the two fixed Ammann-striped prototiles. Exhausted branches are genuinely removed and retried.

Unmarked rhombs can form tilings that are not Penrose tilings, including periodic ones. Markings restrict the allowed solutions, so the right lane need not finish faster. Proposal counts and backtracks show the effect of the extra rule; the synchronized playback is not a wall-clock speed benchmark. A finite target or exhausted budget does not settle infinite tileability.

The left-hand stripes are independent copies of the fixed templates; they may fail to line up because they are not enforced. On the right, every accepted patch has a consistent assignment of complete templates. Ambiguous template orientations can be resolved differently as the search extends or backtracks.

Vertices have four independent integer coefficients in ℤ[ζ₅]. Geometry and stripe tests use exact algebraic arithmetic; only the 2D rendering uses floating point. The earlier model-set experiment remains available through the reference link above.
