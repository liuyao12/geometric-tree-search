Use reusable contacts to rank whole assemblies

Take the six-tile seed as one orbit type and each recovered half-turn motif as the other. The search assumes two threefold orbits and uses edge-connected children. An edge between the types fixes a placement of the second type. A second contact fixes the orbit translation. It can join two children of the same type or join the two types at another relative phase. Without one of those extra contacts, the six children separate into three disconnected pairs. This covers all connected contact patterns within the two-orbit model.

Two placed clusters overlap whenever one pair of their unit tiles has a forbidden relative displacement. The displacement inventory derives each mark from a common occupied lattice sample. It reuses the mark across every cluster that contains the corresponding tile pair. An independent exact polygon computation verified all 144 orientation tables from 2,444 root-relative tests.

The three \(m_{AB,i}\) values represent the three relative phases. Each contact repeats under rotation. A separate cycle check certifies that the exposed edges form one outer ring.
