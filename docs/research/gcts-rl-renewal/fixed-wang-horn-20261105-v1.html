The fixed verifier

One transition table has 294 states, 23 symbols, and 6,716 transition rows. An exact membership rule specifies its finite palette. The archive lists every tile type used in the accepted rectangles. Each square is placed by translation and checked by its four edge colors. The top boundary fixes the context and goal and leaves the certificate cells free. The bottom cap requires the unique accepting head.

Qualification compared 175 explicitly constructed tile types against membership, checked 256 generated certificates against typed logic, and rejected 6 malformed strings and a fixed-input tile mutation. A long unary control took 105,452 steps. The first attempt stopped at 100,000 during that qualification. The completed attempt used a separate limit for the long control and kept the original theorem-search limits.

The current grammar covers ground facts and quantified unary implications with the same argument, a successor, or a predecessor. The branch choices and learned failure marks live on the certificate records. The fixed machine propagates each selected input and produces a checked Wang frame for an accepting certificate. General first-order proofs and RL guidance remain open.
