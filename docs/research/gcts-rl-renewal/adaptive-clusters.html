This experiment extends semantic point-cell search. These are positional rule instances with identity transformations. It does not implement a new fixed literal Wang palette or a new native execution. The earlier compiler to the common Wang core remains a separate result.

What it means to turn logic into markings.

\[\frac{A\qquad A\Rightarrow B}{B}\]

A modus-ponens cell occupies its own required point and assigns the serialized formula \(B\) at its output receptor. Its marking support reaches back to a receptor containing \(A\) and a receptor containing \(A\Rightarrow B\). Exact character agreement certifies the reference binding; the declared inference type certifies the rule. Colors distinguish output, premise, context and continuation layers. Markings can reach any earlier line inside the finite region.

Attention is a useful analogy for selecting relevant earlier statements. In a Transformer, attention weights combine representations; here a selected logical reference requires exact agreement. A learned policy may propose a reference or a cluster, while the checker enforces the logical rule. See the original Transformer paper. Attention is not implemented in this experiment.

The present catalog contains primitive modus ponens obtained uniformly from subformulas of the supplied premises. No theorem proof, arbitrary-tautology oracle or semantic lemma cell is supplied. This is an implication fragment with explicit premises, not a complete propositional prover. Negation and conjunction inside compound receptors are matched as formulas; their introduction and elimination rules are not added here.

RL worsens attempts on two positives, improves one slightly, and changes none on the remaining cases. The zero policy defers every time and exposes the cost of merely enumerating proposals. These are small single observations, not a statistical speed claim. Saturation remains the effective control for this finite implication fragment.


The checker sees the entire proof, with explicit hypotheses.
Independent explicit enumeration reconstructs every base domain and terminal tree without importing the producer's graph factors, matcher, transaction engine or policy. It checks every primitive placement, remote word, flow value, capacity sum, family source window, hierarchy child, constituent scheduler step, seeded draw, gradient and reward update. Tests compare all tiny exact solutions, exercise compound supports and gapped interruptions, and verify exact rollback after a rejected or budget-interrupted transaction.
The source proof checker validates the sequent \(\Gamma\vdash C\). In the compiled host request, every supplied hypothesis is explicitly installed as a named premise axiom. No expanded implication-discharge certificate is claimed. The existing discharge adapter grew a six-line chain with seven hypotheses to a request of about \(233\) million bytes and hit its byte limit during development; it is not used in these measured results. A compact discharge/assumption mechanism remains a separate implementation gap.
Conformance is limited to full-capacity positional semantic cells with complete formula ports, identity transformations, root generation \(0\) and successor generation \(1\). Complete domains remain the source of degree claims. This extension introduces no redundant failure marking, fractional shared capacity, dynamic scope, quantifier family or infinite-tiling certificate.


What to pursue next.
The exact aggregate and scheduler transaction gate is now exercised for adaptive propositional clusters, including an actual nested discovery. The useful next experiment needs richer non-chain proof structure and an economical interface join: bound/unbound hypothesis contexts, scope-safe quantified families and stronger matched proof-search controls. RL needs a better return signal and held-out structural diversity before an advantage can be inferred. The broader turtle, Penrose and universal proof-system goals remain active.
