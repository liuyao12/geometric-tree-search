Axioms are supplied; theorem proofs are discovered.

The rule schemas are

\[\begin{aligned}H_1&:A\Rightarrow(B\Rightarrow A),\\H_2&:(A\Rightarrow(B\Rightarrow C))\Rightarrow((A\Rightarrow B)\Rightarrow(A\Rightarrow C)),\\H_3&:(\neg B\Rightarrow\neg A)\Rightarrow(A\Rightarrow B). \end{aligned}\]

Modus ponens combines \(A\) with \(A\Rightarrow B\) to derive \(B\). The primitive catalog has \(288\) axiom instances and \(708\) modus-ponens instances, grounded using the same query-independent parameter pool \(\{P,Q,P\Rightarrow P,P\Rightarrow Q,Q\Rightarrow P,Q\Rightarrow Q\}\). Hypotheses enter as fixed boundary formula ports in one shared scope. There is no arbitrary-tautology oracle.

Prefix tokens P, Q, i, n, followed by terminator e, encode formulas. Every character is a scalar value at a declared point. The assigned scope value is \(0\). Formula IDs are absent from marking values. Reference distance changes a placement's support; it does not change these values.

A discovered proof becomes a formula-dependent family.
The cold graph search first discovers \(\vdash P\Rightarrow P\) in \(5\) primitive lines. Its actual certificate becomes the identity family. Substitution preserves the axiom schemas and modus ponens, so replacing \(P\) by an arbitrary formula \(A\) throughout those lines yields \(\vdash A\Rightarrow A\). Each used concrete expansion is checked again.
The family can attach to a compound-formula output receptor, and another search composes it with weakening to derive \(\vdash P\Rightarrow(Q\Rightarrow Q)\). That proof has \(3\) commands expanding to \(7\) primitive lines. It was found automatically; the composition proof is not supplied.
Scope of this abstraction: a family use is currently a derived proof-cell rule with a logical expansion. A capacity-preserving geometric decomposition into the original proof cells remains open. For compound identity, its instantiated expansion includes axiom parameters outside the original bounded pool. That changes the bounded catalog's expressivity; it is not merely compressing a proof already present in its five-slot envelope. Every comparison within a family-enabled condition gives all methods the same family. Families are useful here, but their benefit is not unique to GCTS.


Exact point semantics and independently checked failures.
For logical slot \(j\), the required occupied point is \((2j,0)\), with integer capacity \(12\) representing \(t=1\). Scope is at \((2j,1)\); formula character \(r\) is at \((2j,2+r)\). A rule has positive occupancy at its own slot and marking support at its own output and all referenced earlier ports. Negative slot numbers denote the supplied hypotheses. Rotations and reflections are disabled; instances are positional rule families.
Every required slot is activated at generation \(0\). All rule/reference instances are enumerated, including all distant marking-only dependencies. Global dead ends precede global forced placements, then earliest generation precedes degree ties. Copy snapshots provide exact rollback. Logical order and actual placement order can differ: a conclusion constraint can be placed before its supporting inference slots.
Logical markings define validity. RL only orders validated continuation clusters of \(1\)–\(3\) proof-cell placements, with every base alternative retained. It does not supply a shortened candidate domain. This experiment has no learned redundant marking synthesis and does not show its benefit.
The independent auditor re-enumerates every terminal search tree, binds statements and hypotheses, checks every used point assignment and primitive logical expansion, verifies graph samples and proposals, and recomputes the actual on-policy draws, rewards and policy updates. Budget cutoffs remain unknown. Tests separately exercise complete candidate incidence, distant updates, dead/forced/generation ordering, shared fractional candidates, exact rollback and tiny logical/point certificate-set equivalence.


The next research gate is an economical family compiler.
The large ground candidate graph is the present bottleneck. Next preserve complete domains while factoring schema parameters and reference choices, and compile family interfaces into the common fixed Wang core with recoverable primitive placement expansions. Quantified logic then needs substitution, capture avoidance and checked scope transitions. The current two-atom experiment does not implement those features or a proof system for all mathematics.
Formula saturation is the effective baseline for this finite grounded dependency problem. A useful GCTS contribution must be measured on problems where typed boundaries, adaptable lemma families and constrained substitution add work beyond finite formula closure. Further turtle/Penrose and infinite-tiling certificates remain in the broader active program.
