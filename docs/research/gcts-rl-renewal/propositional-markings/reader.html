Finite point calibration · Human-designed construction

A clause becomes an overlap test

Bit tiles and clause-tuple tiles place values at shared points. A guard adds an assigned zero at a distant marking port. The ordinary marking-agreement rule can then exclude a forbidden tuple from the current candidate graph.

The finite calibration passes. \(100\) complete-assignment checks and \(76\) partial-boundary checks agree with the separately authored Boolean oracle. Every saved search trace passes an independent graph/state audit. This verifies the declared small construction and search mechanics. Learning, new theorem discovery and a GCTS/RL search advantage remain open.

Base support

Each named candidate has \(t=1\) at exactly one required integer point. Its markings may extend beyond that support.

Agreement

Assigned values must match at every shared marking port. An absent value \(\ast\) is unconstrained; an assigned \(0\) is not absent.

Evidence scope

A finite marked-model solution or exhausted search is separate from a learned-clause certificate, an infinite tiling or a theorem-search result.

Bit and tuple candidates

A bit candidate \(B_{i,b}\) fills \(v_i=(6i,0)\) and assigns \(m(p_i)=b\) at \(p_i=(6i,2)\). For each clause \(c\), all \(A_{c,s}\) with \(s\in\{0,1\}^{I_c}\) remain in the inventory. Each fills \(a_c=(6c,6)\) and copies its tuple to the shared variable ports.

The tuple also assigns its forbidden flag at \(q_c=(6c+2,8)\):

\[m_{A_{c,s}}(q_c)=\mathbf 1[s=f_c].\]

The guard supplies a zero

The guard \(R_c\) fills \(g_c=(6c+2,6)\). In the guard-unmarked model its flag value is absent. In the active model it assigns \(m_{R_c}(q_c)=0\). Equality at shared ports removes incompatible candidates through the normal graph.

The guard value enters the current state when the guard is placed. Its sole candidate is globally forced before branching, unless a global dead end is detected first. Activating a guard on a reused prefix requires a new marking version and full revalidation or replay.

With every guard active, exact marked tilings correspond bijectively to satisfying assignments of the declared finite CNF. An empty clause has a single empty tuple with forbidden flag \(1\), which conflicts with its zero guard. The guard-unmarked baseline retains the bit/tuple consistency markings; it is not a model with every marking removed.

The same point graph makes the decision

The calibration uses the complete named grounded candidate universe. After each placement it rebuilds the full frontier graph, including dependencies at distant marking-only ports. It checks global dead ends, then global forced moves, and only then branches at the earliest generation. Candidate count breaks generation ties. Persistent immutable states preserve the exact parent across branch rollback.

All declared finite roots have generation \(0\). A tile has one positive support point, so its generation is \(1\), rather than its placement index. This deliberately small instance does not exercise nontrivial growth generations, fractional deficits or a candidate shared across several positive-support points.

Explicit boundary inputs

Seed bit assignments initialize values at variable marking ports. They do not insert preselected bit tiles. The guard mask, seed values, whole tuple inventory and operation budgets belong in each saved case record.

Precise outcome labels

A complete finite solution, exhaustive failure of this exact marked model, and budget-limited UNKNOWN are different outcomes. A timeout or unfinished trace cannot become a negative clause certificate.

    A finite specialization with explicit limits

    This is a finite pre-grounded, fixed-orientation candidate calibration. Every candidate is already positioned at its named integer points and declares identity_only. No runtime translation generator, rotation or reflection is exercised. Each candidate has singleton unit positive support. General geometric tiling and translation-generator qualification remain outside this calibration.

    The complete tuple inventory can grow exponentially in clause width. This construction supplies neither a single fixed finite Wang inventory nor an infinite-tiling or universality result. It is a human-designed reduction, not an automatically discovered theorem or a change to the existing arithmetic search.

    A guard represents a clause. Learning or proving that clause is a separate task. A redundant learned guard needs an independent entailment certificate in the complete original context. Branch-specific certificates remain scoped to that branch unless their assumptions are included explicitly. Exhausting a bounded model does not establish unprovability in its underlying theory.
