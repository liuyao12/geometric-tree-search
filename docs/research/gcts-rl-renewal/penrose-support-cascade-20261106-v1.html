The red edge must be covered. For any admissible rhomb incident to it, each edge in the interior requires another rhomb across it. A leaf of the proof gives a witness that a proposed rhomb extends outside the region.

Find the receptor from the boundary

The inventory checks the logical proof once. Each placed marking then checks three kinds of geometric premises. Required boundary segments must be present, interior support edges must stay off the boundary, and exterior witnesses must still exclude their rhombs. The index proposes an anchor from the rarest required segment direction and displacement.

When the exact marking misses, the adaptive arm tries new exterior witnesses for the same rhombs. The same symbolic derivation still applies when all its premises can be established. The run independently reconstructed and verified the geometry and source statement for every reuse.

Learn which search to try after a miss

A contextual bandit chooses plain placement search, a search for fresh exterior witnesses, or fresh two-round propagation. It sees the outline and the guard counters from the shared index. During training it receives feedback for its chosen action. The reward uses the logarithm of a combined work count and penalizes reaching the placement bound.

Scope of the experiment

The pilot used paired boundary edits of 13 checked Penrose covers. Of 62 valid edited outlines, four required two rounds of support propagation for this checker and 58 passed that screen. The eight illustrated bindings include the original receiver, three rigid copies, and four boundaries with an added rhomb. The compact checker also rejects the same proof with the root premise removed.

Across all 67 valid one-rhomb additions to the donor outline, 37 retained every geometric premise and reused the same proof. The other requests went to the ordinary search. It found 2 independently checked covers in those cases.

On the requests with a reusable proof, the matched unmarked runs visited 2,837 nodes and performed 41,884 placement checks. These are search work counts. Geometric replay of the reused proof is still required for each receiver.
