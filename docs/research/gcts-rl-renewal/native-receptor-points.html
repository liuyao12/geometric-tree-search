What the distant markings enforce.
Each slot has two required points: one selects a syntactic command, and the other selects a rule guard. Every original command remains in the command domain, including commands that will fail. Command-word agreement connects it to a valid guard instance. Formula-word agreement connects that instance to its earlier premises.

\[A,\quad A\Rightarrow B\quad\vdash\quad B.\]

A modus ponens guard at line \(j\) writes \(A\) at line \(i\)'s formula port, writes \(A\Rightarrow B\) at line \(k\)'s port, and writes \(B\) at its own output port. The source command tiles write their actual formulas at those same points. Indices satisfy \(i,k<j\), so an unsupported dependency cycle cannot fill the proof region.

\[m_{\mathrm{source}}(p_{i,r})=\operatorname{enc}(A)_r
\quad=\quad m_{\mathrm{guard}}(p_{i,r}).\]

The word is canonical UTF-8 JSON followed by a distinct integer terminator. Each byte has its own point; a formula is never compared by hash or by an approximate embedding. Prefixes of different lengths disagree at the terminator. A conflicting guard is rejected internally before it can become a candidate.
Axiom, reflexivity and generalization guards are structural instances of the declared rules. Tautology guards are compiled by asking the whole fixed native machine to check each basis formula as a one-line tautology command. An unfinished native computation leaves compilation unknown; it does not justify omitting a guard. The catalog contains no theorem-specific proof sequence.
This is a problem-defining logical marking layer. It is not a learned exclusion inferred from failed samples. The finite positional inventory and its compilation costs are exposed. It does not add an infinite collection of formula-specific types to the universal primitive Wang palette; the resulting commands are encoded into that existing palette for native verification.


Search costs, including the rule catalog.
Ten declarations and two fresh-process methods give \(20\) cold observations, with method order alternating between cases. Both methods use the same exact-line syntactic certificate grammar. Point search allows \(10{,}000\) placements and \(120\) seconds after catalog construction; it allows \(64\) native catalog queries and checks the found proof separately. The chronological prefix control allows \(128\) native queries and \(120\) seconds checked between queries. Each native query permits \(10^9\) selected-symbol steps, except the explicitly unfinished control. These are different effort budgets, and this is a single observation per method, not a statistical performance claim.

Cold time includes loading the fixed code, launching the native oracle, compiling all tautology guard instances, constructing the point inventory and graph, searching, verifying a discovered certificate, and closing transport. The full worker clock also includes Python startup, imports and serialization. Materializing accepting native response grammars is a separate cost. Operating-system caches are not cleared.
These observations test the bridge from logical rule markings to native certificates. They do not establish an advantage over SAT, saturation, SMT or an established theorem prover. No RL policy or learned failure marking is used in this increment. Training a proposer over checked, adaptable inference clusters remains a separate research objective.


What was independently checked.
The auditor reconstructs every command and guard without importing the new point model or search. At every visited node it scans the entire inventory, rebuilds both legal domains and the scheduler decision, and checks the complete state and rollback fingerprints. It independently reconstructs payload bytes and reruns every recorded native computation using a separately written interpreter. Every accepting response grammar is derived again, and each displayed proof context is decoded from the actual native checkpoint.
For small envelopes, the auditor additionally enumerates every complete word in the original command grammar and compares existence of a marked region with a separate logical kernel. This finite differential test is not native execution of every possible word, and it is not a universal compiler theorem. The full primitive Wang rectangles use the established exact scan acceleration; this experiment does not place their enormous expansions square by square using GCTS.
Arithmetic results here are equality theorems in an arithmetic vocabulary, with no PA axiom or induction. The incidence result uses given ground premises; it is not a proof from the full Hilbert axiom groups. The new longer results are chains of given propositional implications. Finite exhaustion concerns the declared line count and formula basis; it does not assert unprovability in the underlying logic.
