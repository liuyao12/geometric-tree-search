MEASURED RESULT · FULL COSTS DECIDE USEFULNESS

Credit is obtained. Search is not improved.

Useful RL acceleration is still not demonstrated. Every local learner verifies eight evaluation targets and exhausts two finite controls, using \(1196\) base attempts. Plain GCTS verifies the same targets and controls using \(1152\). The complete-tree learners use \(669\), \(1152\) and \(669\) attempts. Local evaluation cold times are \(15.779\), \(15.627\) and \(15.494\) seconds. Local training adds about \(27.3\) seconds per seed, plus \(23.886\) seconds of shared catalog construction and independent inventory checking.

The saved evaluation traces show that all three local policies defer on the addition cases. On multiplication they try ten reverse fragment proposals before reaching the proof, using more work than plain search. Their learned direction coefficients favor reverse fragments. This identifies an observable weakness of the filled-cell progress proxy; it does not establish a causal ablation or reject RL as a whole. This proxy should not be adopted as the main accelerator.

The two learners use the same saved-prefix engine, authored features, complete primitive graph, proposal universe, scheduler and base fallback. Only the training return changes. Policies then diverge, so their later traces and random-stream positions also differ. Matching the seed does not make the observed trajectories identical.

Three seeds on this small fixed arithmetic family cannot establish broad theorem generalization or a statistically supported timing ranking. The fixed prior is unknown on multiplication in seeds one and seven; the zero-weight control is unknown there in seed nineteen. These near-wall outcomes stay unknown. An unequal verified / exhausted / unknown aggregate cannot support a speed ranking. The local reward is a progress proxy; it may favor viable but unproductive branches.

DECLARED PROXY · OBSERVED WORK · NO LEARNED PRUNING

A partial return has a limited meaning.

The complete-tree control retains notebook 31's delayed reward and discards all credit from an unknown request. The local learner uses

\[r_{\mathrm{local}}(a)=\mathbf{1}\{\text{native acceptance and successful continuation}\}+\frac{D(a)}{n}-\frac{\log(1+C(a))}{\log(1+50000)}.\]

Here \(n\) is the fixed number of proof cells, \(C(a)\) counts every actually executed base-placement attempt in the chosen proposal and its observed continuation, or in the ordinary fallback for deferral. \(D(a)\) is the largest observed increase in filled cells over that action's viable point states, measured from its parent. A viable state has no known degree-zero frontier point in its complete graph. This is an observed lower bound on explored progress, not an estimate of the unobserved suffix. Nested action returns overlap and are not additive proof-work totals.

An interrupted cluster transaction rolls back. Its temporary occupancy earns no committed progress; its executed validation steps still cost work. An interruption before any constituent executes gets no local credit. Pre-sampled choices after an earlier successful child are censored. Deferral is credited only if ordinary base fallback actually executes. A complete native check is required for the theorem bonus. No unknown request receives that bonus.

Both learners freeze their coefficients throughout each episode, use the unchanged twelve graph/interface features and sequential softmax sampling, and apply the same projected update with rate \(0.2\), coefficient range \([-6,6]^{12}\), and running baseline \(b'=0.9b+0.1r\). Every LCG variate, softmax probability, log-probability gradient, reached return and update is exported and independently recomputed. No convergence or unbiased-gradient theorem is claimed for these capped, pseudo-random DFS proxies.

The driver starts with no fragment library or policy. It searches the two donor statements anew, mines and checks their four fragments, and independently validates eight training catalogs. Each signal trains for four rotating epochs on those eight statements, with its own continuous stream in seeds \(1\), \(7\) and \(19\). Learner order alternates. Ten external evaluation statements are withheld from both learning and mining, including comparisons that omit cell bounds. Every evaluation lane rebuilds the same base catalog and uses a five-second search wall and \(50000\) actual-placement limit. Final proof compilation and native verification lie outside that search wall and inside cold request cost.

Keep the open suffix visibly open.
