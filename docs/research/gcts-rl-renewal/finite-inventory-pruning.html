The finite dependency model

Fix a finite formula-state set \(\mathcal F\) and the complete declared inference-template set \(\mathcal R\). A template \(r\) records its ordered input states \(P(r)\) and output state \(q(r)\). A formula state includes any context or scope information needed by the searched language. In the arithmetic specialization, conditional contexts are explicit in formulas. Ignoring an extra guard during this calculation is safe only when doing so adds possible edges.

Every searched proof is a finite sequence. Its line may use a zero-input template, or a template whose inputs are outputs of strict-earlier lines. Include every declared zero-input option: axioms, reflexivity, allowed tautologies, and any reusable closed theorem. Include all templates even if their native admission is still unknown; treating them as potentially valid enlarges the approximation.

\[ S_0=\{q(r):r\in\mathcal R,\ P(r)=\varnothing\},\qquad S_{k+1}=S_k\cup\{q(r):r\in\mathcal R,\ P(r)\subseteq S_k\}. \]

Here containment means that every ordered input state belongs to the set; repeated inputs are retained in the template but do not change this membership test. The finite increasing chain reaches a least fixed point \(S_\ast\).

Structural unreachability is safe pruning

Every output appearing in an accepted proof belongs to \(S_\ast\). Consequently, every template with an input outside \(S_\ast\) can be removed without removing any accepted proof word in the full declared grammar.

Proof. Induct on the position of a line in a proof word. A zero-input line has its output in \(S_0\). Otherwise, all inputs occur at earlier positions and belong to \(S_\ast\) by the induction hypothesis. The fixed-point condition then places the output in \(S_\ast\). A removed template would require an earlier output outside \(S_\ast\), contradicting the same argument. This preserves each original proof word, including its line count and reference choices. \(\square\)

A reachable output need not be a theorem. The closure ignores ordering costs, finite row budgets, native validity and some placement constraints. It is a necessary condition. If a requested output lies outside the closure, the result is impossibility in this finite grammar, provided its completeness certificate is correct. It says nothing about unrestricted first-order provability.

The same ranks constrain early proof rows

For a reachable state, define \(d(f)=\min\{k:f\in S_k\}\). Number proof rows from \(0\). An accepted output on row \(j\) has \(d(f)\le j\); a required input read from source row \(s\) must have rank at most \(s\). Thus a candidate violating either inequality is impossible at that position.

Proof. A zero-input output has rank \(0\). Otherwise, by induction each earlier input has rank at most its source row, hence at most \(j-1\). Applying its template puts the output in closure layer at most \(j\). This argument holds for every declared proof word and supplies no selected derivation. \(\square\)

The closure rank and chronological proof-row index are distinct from GCTS frontier generations. A positional implementation must certify its projection of the complete candidate universe and keep the reference scheduler unchanged. This note supplies the safety argument; it does not report a measured positional-search result.

A witness small enough to inspect

An auditor should reconstruct the entire original template set from the declared syntax bounds, rather than accept a supplied shortlist. It then checks the original formula identities, input order, output, scope guards and inventory version. Native-unknown edges remain in this original set during closure.

  1. Every zero-input output appears in the claimed reachable set.
  2. Every reachable state has a finite rank and either a zero-input witness, or a template whose inputs have strictly lower ranks.
  3. For every original template, if all its inputs are reachable, its output is reachable.
  4. Every excluded template names at least one input outside the reachable set. The retained inventory contains every other template.

The rank witnesses prove that the claimed set is contained in the least fixed point. The seed and closure checks prove the reverse containment. Together they identify \(S_\ast\) exactly. For pruning alone, a certified larger closed set is also safe: it can miss useful exclusions, but it cannot remove a valid proof.

The calculation uses a reverse dependency index and a queue of newly reached states. It is ordinary finite graph analysis. It has no dependence on the requested conclusion, a saved target proof or a policy prediction. Source and inventory changes invalidate the witness; adding a new zero-input theorem can make a previously unreachable cycle usable.

What this contributes to the search program

The five-node arithmetic preparation exposed a practical bottleneck: the complete specialized inventory grows sharply, and native admission of a single larger local definition can take tens of seconds. Structural pruning reduces the declared interfaces while preserving the full successful proof language. The independently audited reduction above is established; a target-search result and total time to its checked proof require separate evidence.

After the witness is checked, retained interfaces still need the declared native admission. GCTS must maintain the complete retained frontier-point/candidate graph, global dead and forced checks, earliest-generation branching and exact rollback. Unreachable templates are removed globally under a proved redundant constraint; this is distinct from learning a marking restriction from samples. A marking implementation must expose its actual point values and dependencies. The fixed-point computation itself is not RL or a learned marking.

This analysis may benefit other proof-search engines too. The research question is whether certified inventory reduction, reusable receptor families and learned proposals together reduce total time to a checked proof, charging construction, admission, search and checking. No GCTS-specific speed advantage follows from the lemma alone.
