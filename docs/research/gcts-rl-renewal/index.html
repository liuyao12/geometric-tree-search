What this bridge proves—and what remains open

For each declared finite envelope, certificate acceptance is equivalent to derivability in its compiled inference closure. Alternative schema witnesses for the same formula/rule relation share one canonical witness; this preserves derivability rather than proof multiplicity. Initially all facts are false. A command can add a fact only through a kernel axiom instance, reflexivity, tautology, capture-avoiding instantiation, distribution with its side condition, equality substitution, modus ponens or generalization. Induction reconstructs a kernel derivation for every true fact. Conversely, each kernel proof whose formulas and schema parameters are in the envelope supplies a valid command sequence. A certificate cannot introduce a new theory axiom.

The new fair driver expands the syntax envelope and dovetails certificate length, rectangle height and node budget. Every finite kernel proof has finitely many terms, formulas, templates and variable names; the grammar enumerator eventually includes them, even for arbitrary Unicode variable names. Acceptance is absorbing, so larger certificate and height bounds preserve a witness. Every fixed rectangle is revisited with unbounded nodes. Under unlimited computation, every proof accepted by the kernel is eventually covered. This is completeness relative to the executable kernel, not a formally verified semantic completeness theorem.

The finite compiler is operational. The unrestricted syntax driver is extremely expensive and has only bounded semantic controls. It is a family of finite compiled machines, rather than a single fixed checker for arbitrary serialized abstract syntax. Checked infinite axiom schemas, a formally proved compiler, harder mathematical tasks and useful hierarchical proof fragments remain open.

The policy starts from zero weights and sees no accepted proof. It learns inference sequences in a separate kernel-fact environment; a valid proposal becomes a preferred Wang rectangle. Every constituent still passes global dead/forced scheduling and all base alternatives remain. What is learned, and what makes this proof relation universal?

The four declared benchmark rules are \(\mathtt{a}\to\mathtt{b}\), \(\mathtt{b}\to\mathtt{a}\), \(\mathtt{aa}\to\mathtt{a}\), and \(\mathtt{b}\to\mathtt{bb}\). These define a small test theory, including cycles and length changes. REINFORCE starts at zero weights and sees no proof witness. Every applicable singleton and two-move sequence is eligible; rewards charge actual word moves and checker steps. Training uses source lengths four to six; evaluation uses lengths one to three from the same theory and target family. This is limited generalization.

The extended marking is an analytic control, not a learned failure encoding. A tile \((a,b,c)\) additionally assigns \(a\) and \(c\) at the bottom-value points of its neighbors. Complete horizontal Wang agreement already gives \(a=S_{\rm left}\) and \(c=S_{\rm right}\), with blank exterior side values. Every complete rectangle therefore satisfies the extra marking, although inconsistent finite prefixes can fail earlier.

The arbitrary-machine reduction represents a configuration by \(L\alpha q a\beta R\). For \(\delta(q,a)=(p,b,+1)\), the interior rule is \(qac\to bpc\); at the right border it is \(qaR\to bpBR\). Left moves use \(cqa\to pcb\) and \(Lqa\to LpBb\). A stationary move uses \(qa\to pb\). The symbol namespaces are disjoint. Induction preserves one state marker and both delimiters. Before the halt state, the unique enabled rewrite is exactly the machine transition; border rules extend blank tape. Only the halt marker enables erasure and the final rule \(Lq_{\rm halt}R\to\mathtt{ACCEPT}\). Thus the encoded word reaches that target exactly when the machine accepts. The code implements all these forms and tests them.

This is the classical computational expressiveness of directed string rewriting, not a new universality theorem; see Post's original construction. The independent word checker validates found assertions directly. Testing the generated machines is still weaker than formally verifying the compiler.

The fair driver revisits powers-of-two word capacities, proof lengths and rectangle heights with increasing node budgets. Unused proof bytes have explicit padding; acceptance is absorbing. A finite stage limit remains unknown, and unlimited negative cases need not terminate. The familiar mathematical proof kernel still needs an explicit translation to this system.

PENROSE · EXACT COORDINATES

Exact arithmetic first.

Coordinates use \(\mathbb Z[\zeta_5]\), represented by four integer coefficients modulo \(1+z+z^2+z^3+z^4\). Multiplication, conjugation, and \(\varphi^2=\varphi+1\) are checked exactly.

The physical module is dense: \(\varphi^{-1}=\varphi-1\) belongs to it and its positive powers approach zero. A finite set of vertex angles cannot silently stand in for a rhomb's whole interior. A faithful point encoding or explicitly specialized control must be declared before the learner transfers.

Unmarked rhombs also admit periodic arrangements. Learning a Penrose-compatible subsystem would restrict that problem; it cannot automatically be called redundant pruning of all unmarked rhomb tilings.

Wang edge colors fit the shared model directly. Put \(t=1\) at a cell center and assign the four colors as \(m\)-values at edge midpoints. Admissible translations place one tile at each required center. Point agreement is exactly Wang adjacency, with no corner constraint added.

THE RESEARCH PROGRAM

Goals with concrete gates

  1. Implemented & checked

    Exact turtle baseline

    Complete incidence, exact rollback, global propagation, and generation-first branching. Finite patches and certificates are independently replayed.

  2. Growth tested

    Learn geometric failure markings

    Cold contact labeling and scalar synthesis work. Compact and exterior markings have complete exclusion audits and matched growth tests. A stable acceleration and richer encodings remain open.

  3. Context proposals

    RL proposes clusters and sequences

    Shared placements count once; diverse motifs and scheduler-checked continuations retain all base moves. The measured turtle policies have not demonstrated an acceleration. Next: learn hierarchical productions and improve the cost of proposing them.

  4. Library obstruction

    Learn marked tiles at multiple scales

    Two child types share a learned channel; their parent learns its own. A checked three-round argument now rules out the joint library of thirteen four-turtle parents. Next: variable-size parent families and boundary reuse with fine-scale refinement. A stationary substitution is optional.

  5. Region pilot 02

    Practical boundary solving and plane coverage

    Authored larger cores and a disconnected target complete with singleton fallback; RL improves this hierarchy’s completion rate, while singletons remain faster. Resident inventory reuse reduces a matched batch’s cost. Learning amortization, richer boundaries, other systems and unbounded coverage remain open.

  6. Conditional theorem

    Transfer to Penrose

    Complete connected sector assignments now have an analytic plane-faithfulness proof. All pair and full-root-star contexts have finite completions. No useful marking was learned. Search a compatible infinite continuation and a hierarchical Penrose-compatible subsystem.

  7. Kernel bridge

    Build checkable proof search

    Generic word proofs and finite first-order kernel catalogs now compile to accepting Wang rectangles. Cold RL and fair bound drivers retain complete base search; arbitrary-TM expressiveness has an explicit reduction. Next: checked infinite theory schemas, a fixed serialized-syntax checker, hierarchical proof fragments and harder mathematical statements.

REPRODUCIBILITY & LIMITS

Every claim has a scope.

The solver imports only the turtle's vertices and angle units from the article. Occupancy uses integer capacity \(12\); missing marking values are unconstrained, and zero is assigned.
