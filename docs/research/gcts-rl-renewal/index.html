PROGRAM REVISION · LOCAL SOLUTIONS, COARSE INTERFACES

Clusters become tiles. Boundaries become the task.

The updated objective includes fixed and movable boundaries, rather than requiring a turtle substitution. For a fixed finite required set \(D\), exterior point contributions prescribe the boundary problem:

\[T_{\rm ext}(p)+\sum_{c\in S}t_c(p)=1,\qquad p\in D.\]

A movable boundary introduces explicit shape or position variables with a declared admissible family. Those variables and their point conditions must backtrack with the tiling state. The practical gates are verified coverage, time, memory, reuse cost and robustness across tile systems—not the discovery of a particular recursive rule.

How the PDE analogy changes the next experiments

The boundary trace records residual capacities, all assigned marking components—including exterior dependencies—and base-placement ownership. Joining two local solutions means matching that trace and checking the resulting exact point values. It is a discrete compatibility relation; linear superposition and PDE convergence theorems are not assumed.

Three proposed transfers are useful: solve local boundary problems with a larger collar before retaining their core; learn a coarse interface problem for obstructions that local propagation cannot remove; refine a failed coarse assembly back to lower-level search. Hou and Wu's multiscale finite-element construction and oversampling and Xu and Zikatanov's algebraic multigrid framework motivate these experiments. Their PDE guarantees do not establish guarantees for this discrete tiling problem.

Next: compare exact fixed-boundary regions, explicitly movable boundaries, and growing nested cores. Train clusters on local boundary completions, learn new marking channels from certified failures at each declared level, and retain singleton refinement/fallback. Report time to satisfy required obligations, learning and assembly cost, memory, and independent expansion checks. A sampled cluster inventory alone cannot prove the original base problem impossible.

The atomic cluster engine is exact for its declared aggregate tile inventory. Its global scheduler operates at that level; it is a different problem from executing a macro in the base scheduler. Every accepted aggregate flattens to a checked base patch. Including all unmarked singleton types preserves the base solution set as all-singleton paths. A hierarchy certificate must descend in level and preserve every inherited marking; omitted child data and cycles are rejected.

PROOF PILOT 01 · GENERIC RULE CHECKER + COLD RL

From word proofs to marked points.

A finite directed word theory declares rules; a proof lists which rule to apply and where. The assertion is \(u\Rightarrow_R^*v\). The new compiler accepts arbitrary finite alphabets and rule lengths, including insertion and deletion. It produces a finite Turing machine that checks unknown proof bytes against an externally declared theory and target. Wang search fills those bytes and the accepting computation.

This is an executable, computationally universal proof relation. An explicit reduction translates arbitrary finite Turing transition data to word rules. What is learned, and what makes this proof relation universal?

The four declared benchmark rules are \(\mathtt{a}\to\mathtt{b}\), \(\mathtt{b}\to\mathtt{a}\), \(\mathtt{aa}\to\mathtt{a}\), and \(\mathtt{b}\to\mathtt{bb}\). These define a small test theory, including cycles and length changes. REINFORCE starts at zero weights and sees no proof witness. Every applicable singleton and two-move sequence is eligible; rewards charge actual word moves and checker steps. Training uses source lengths four to six; evaluation uses lengths one to three from the same theory and target family. This is limited generalization.

The extended marking is an analytic control, not a learned failure encoding. A tile \((a,b,c)\) additionally assigns \(a\) and \(c\) at the bottom-value points of its neighbors. Complete horizontal Wang agreement already gives \(a=S_{\rm left}\) and \(c=S_{\rm right}\), with blank exterior side values. Every complete rectangle therefore satisfies the extra marking, although inconsistent finite prefixes can fail earlier.

The arbitrary-machine reduction represents a configuration by \(L\alpha q a\beta R\). For \(\delta(q,a)=(p,b,+1)\), the interior rule is \(qac\to bpc\); at the right border it is \(qaR\to bpBR\). Left moves use \(cqa\to pcb\) and \(Lqa\to LpBb\). A stationary move uses \(qa\to pb\). The symbol namespaces are disjoint. Induction preserves one state marker and both delimiters. Before the halt state, the unique enabled rewrite is exactly the machine transition; border rules extend blank tape. Only the halt marker enables erasure and the final rule \(Lq_{\rm halt}R\to\mathtt{ACCEPT}\). Thus the encoded word reaches that target exactly when the machine accepts. The code implements all these forms and tests them.

This is the classical computational expressiveness of directed string rewriting, not a new universality theorem; see Post's original construction. The independent word checker validates found assertions directly. Testing the generated machines is still weaker than formally verifying the compiler.

The fair driver revisits powers-of-two word capacities, proof lengths and rectangle heights with increasing node budgets. Unused proof bytes have explicit padding; acceptance is absorbing. Every fixed finite proof eventually fits one recurring bound triple and a sufficient exhaustive-search budget. Optional learned preferences retain all alternatives. A finite stage limit remains unknown, and unlimited negative cases need not terminate. The familiar mathematical proof kernel still needs an explicit translation to this system.

Why the smallest marking is sound for complete point-model tilings

The learned scalar marking has assigned support inside the tile's positive occupancy support. Therefore every disagreement occurs between a pair represented in the complete contact catalog. The checks cover all twelve symmetry transforms and establish that every rejected contact is certified negative.

If a complete unmarked tiling contained such a pair, it would supply a legal continuation at every decision in that pair's exhaustive proof tree. Each leaf instead has a frontier point with no legal candidate. This contradiction rules out the pair. Consequently every complete unmarked point-model tiling satisfies the smallest marking.

This is a redundancy result for the stated point model, not a proof that a tiling exists. Larger marking supports can interact outside the contact catalog and remain learned restrictions until those interactions are certified.

The extended-support redundancy argument

For each pair of assigned prototype points and every allowed relative orientation, align the two points and enumerate the resulting translation. This finite set contains every possible marking disagreement. Retain the capacity-legal pairs and independently check an exhausted unmarked extension certificate for each excluded pair.

A complete unmarked tiling containing a disagreeing pair would supply a legal tile at every frontier decision in its finite failure tree, contradicting the certified empty domain at a leaf. Scalar symmetry checks transfer the exclusions to every orientation. This argument permits exterior markings; it proves redundancy for complete point-model tilings and does not prove that any such tiling exists.

At a dead leaf, the new validator exhaustively enumerates the stated frontier point. At an internal node it enumerates the entire frontier, certifies scheduler precedence, and checks every alternative. The change reduces verification work while preserving the certificate's inference rules.

SUBSTITUTION DISCOVERY

Motifs are a beginning.

The first iteration's library contains translation-normalized irregular sequences, proposed and selected by a policy-gradient learner. A repeated sequence is not a substitution. The missing object is a finite family of metatiles with exact expansion maps, compatible interfaces, and repeatable recursive coverage.

The dilation controls impose a fixed exterior contribution at boundary points. They only test an integer enlargement of one turtle outline. Multi-type, algebraic, and combinatorial substitutions remain open.

PENROSE · EXACT COORDINATES

Exact arithmetic first.

Coordinates use \(\mathbb Z[\zeta_5]\), represented by four integer coefficients modulo \(1+z+z^2+z^3+z^4\). Multiplication, conjugation, and \(\varphi^2=\varphi+1\) are checked exactly.

The physical module is dense: \(\varphi^{-1}=\varphi-1\) belongs to it and its positive powers approach zero. A finite set of vertex angles cannot silently stand in for a rhomb's whole interior. A faithful point encoding or explicitly specialized control must be declared before the learner transfers.

Unmarked rhombs also admit periodic arrangements. Learning a Penrose-compatible subsystem would restrict that problem; it cannot automatically be called redundant pruning of all unmarked rhomb tilings.

PENROSE PILOT 01 · COLD UNMARKED VERTEX STARS

Declare the point model. Test every contact.

The new connected-star model uses \(L=\mathbb Z[\zeta_5]\times\{0,\ldots,9\}\). At each rhomb vertex, \(t=1\) on the occupied angular sectors. Placing a rhomb activates all ten sectors at every vertex, including zeros. Every generated slot is explicitly a generation-zero root. Ten rotations act on coordinates and sector labels together. This pilot supplies no arrows, marking, known patch, or substitution.

The contact learner found no failures. It therefore learned no nontrivial exclusion marking. A Penrose-compatible hierarchical subsystem remains to be discovered; unmarked rhomb tilings also include periodic arrangements.
A dense-module counterexample and the remaining faithfulness gap

Translate a thick rhomb by \(\varphi^{-1}=\varphi-1\). The two vertex supports are disjoint, while an exact algebraic separation test certifies positive-area polygon overlap. Point capacity therefore accepts this disconnected control.

More generally, positive powers of \(\varphi^{-1}\) form infinitely many distinct translations approaching zero. Only finitely many can belong to the difference set of any finite support. Sufficiently small remaining translations produce the same obstruction for unrestricted placements.

Search grows a connected component through shared vertex sectors, so it does not simply insert this disconnected pair. Complete vertex stars may support a faithful developed rhomb complex, but the equivalence to covering the plane has not been proved. Activating every point of the dense module would be a different problem. The finite audit below checks the actual searched polygons independently.

TOWARD GEOMETRIC PROOF SEARCH

A computation is a tiling with a certificate.

Wang edge colors fit the shared model directly. Put \(t=1\) at a cell center and assign the four colors as \(m\)-values at edge midpoints. Admissible translations place one tile at each required center. Point agreement is exactly Wang adjacency, with no corner constraint added.

A radius-one transition rule \(f(a,b,c)\) becomes the tile

\[S=b,\qquad N=f(a,b,c),\qquad W=(a,b),\qquad E=(b,c).\]

Horizontal agreement reconstructs each neighborhood; vertical agreement checks the next configuration. This first illustration is a two-step machine control; the generic proof checker above now exercises the same local construction. A separate checker verifies the computation and rejects a tampered accepting row.

Statement + formal theory→Proof enumerator + trusted checker→Accepting computation tiles→Verified proof

For a chosen recursively axiomatized theory \(\mathcal T\), a machine may accept exactly the certificates that its proof checker validates for \(\phi\). Leave the certificate portion of the initial tape unspecified; Wang search then chooses its symbols. A finite accepting rectangle would certify \(\mathcal T\vdash\phi\). Fair enumeration of certificate lengths, tape widths, and run lengths would be needed for a complete search. Computational expressiveness does not decide every mathematical truth.

THE RESEARCH PROGRAM

Goals with concrete gates

  1. Implemented & checked

    Exact turtle baseline

    Complete incidence, exact rollback, global propagation, and generation-first branching. Finite patches and certificates are independently replayed.

  2. Growth tested

    Learn geometric failure markings

    Cold contact labeling and scalar synthesis work. Compact and exterior markings have complete exclusion audits and matched growth tests. A stable acceleration and richer encodings remain open.

  3. Context proposals

    RL proposes clusters and sequences

    Shared placements count once; diverse motifs and scheduler-checked continuations retain all base moves. The measured turtle policies have not demonstrated an acceleration. Next: learn hierarchical productions and improve the cost of proposing them.

  4. First channel learned

    Learn marked tiles at multiple scales

    A two-turtle cluster learns its own scalar channel from checked base failures; a parent inherits it. Extend the marking learner to multiple types and higher-level failure contexts, then search coarse assemblies with refinement. A stationary substitution is optional.

  5. Region pilot 01

    Practical boundary solving and plane coverage

    Six finite targets and two movable families complete, with checked local solutions exported as parent tiles. The singleton baseline is faster than the aggregate lanes in this pilot. Interface compression, learned cluster markings, larger targets and other tile systems remain open; an unbounded continuation still needs a coverage argument.

  6. Unmarked contacts

    Transfer to Penrose

    All contacts in the declared vertex-sector model have checked finite completions. No useful marking was learned. Close the developed-complex faithfulness gap and search a hierarchical Penrose-compatible subsystem.

  7. Universal relation

    Build checkable proof search

    Generic finite word proofs now compile to accepting Wang rectangles; cold RL and a fair bound driver retain complete base search. The arbitrary-TM reduction is explicit. Next: connect the first-order kernel, add checked theory schemas, and evaluate harder mathematical proofs.

Every claim has a scope.
