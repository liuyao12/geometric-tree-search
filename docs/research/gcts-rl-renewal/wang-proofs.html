The English mechanically reads each formula, followed by a separate explanation of its inference rule. Brackets preserve nested implication and quantifier scope. This helps read the formal certificate; the English itself is not independently checked as a natural-language proof. The full primitive view expands every used lemma, remaps all premise references, and independently checks every resulting line. Root references are global in that expanded view; lemma definitions use local references and explicit local assumptions. Neither a lemma name nor a successful final line substitutes for checking the preceding derivation.

A uniform finite tile system and an unrestricted mathematical proof-search language are research goals.
