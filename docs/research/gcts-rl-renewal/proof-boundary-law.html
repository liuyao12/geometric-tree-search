Declare the wire language.

An atom command is a leading 0 and nine little-endian bits for an integer in \(\{0,\ldots,256\}\). The atom \(256\) is nil. A 1 command pops two values and pushes their ordered pair. A ; terminates a band. After it, only blank padding is permitted up to a fixed : frame marker. A truncated atom, stack underflow, value above nil, missing terminator or data after termination rejects.

The fixed problem band produces the tagged trees for protocol, theory and target, in that order. The free certificate band must produce exactly two additional trees: blocks and proof. Only its payload symbols vary. All headers, logical head positions, program constants, other initial bands and the physical start state are fixed. Its payload alphabet is 0, 1, ; and blank; the frame marker is fixed at the declared end.

No input command names a heap cell. Starting from the fixed program-constant heap, each pair is allocated by the ordinary canonical-cons microcode. That code either reuses an existing identical ordered pair or appends a record containing already-existing children. Induction on constructor commands therefore gives an acyclic heap containing exactly the represented trees. Shared subtrees may be represented repeatedly on the wire and allocated once in the heap.

The constructor first pops exactly three fixed values into reserved bands and requires an empty value stack. It then constructs exactly two free values on that empty stack, pops them into separate bands, and again requires the stack to be empty. Thus even an initial free pair command cannot consume fixed values. The request object has five fixed field names; certificate data cannot replace its protocol, theory or target fields. The syntax wrapper checks tagged objects, arrays, byte strings, natural and negative integers, Booleans and null, including unique object keys. Negative zero and improper lists reject. Names are exact byte strings. This wire language is deliberately defined directly; it is not a JSON text parser. UTF-8 JSON encodings used in the recorded controls form a subset of its byte-string inputs.

Every loop and operation above is compiled to finite selected-symbol microcode and then literal single-tape transitions. Bounded heap, stack, word or tape space can interrupt a valid construction and remains unknown. The structural argument assumes enough declared space for the particular finite computation. It does not justify rejection from a cutoff.

Turn the literal machine into local point tiles.

Let \(M\) be the published finite deterministic tape table, with tape alphabet \(\Gamma\), states \(Q\), start state \(q_0\) and accepting state \(q_A\). Let \(\Sigma=\Gamma\cup(Q\times\Gamma)\); a pair denotes the single head and the symbol under it. Make acceptance absorbing for the local spacetime representation. Rejection, undefined transitions and resource stops have no accepting continuation.

For every neighborhood \((a,b,c)\in\Sigma^3\) containing at most one head, the ordinary radius-one transition rule determines the next middle value \(F(a,b,c)\), when defined. A headless neighborhood copies its middle value. A middle head writes, stays or leaves according to \(M\). A neighboring head enters exactly when its transition moves toward the middle cell.

Each defined neighborhood gives a Wang tile with colors

\[S=b,\qquad N=F(a,b,c),\qquad W=(a,b),\qquad E=(b,c).\]

Represent it on the doubled integer lattice: occupancy \(t=1\) at the center \((2x,2y)\), and these four colors as marking values at \((2x,2y-1)\), \((2x,2y+1)\), \((2x-1,2y)\), \((2x+1,2y)\). These marking parity classes do not add corner constraints. Horizontal agreement enforces overlapping neighborhoods; vertical agreement enforces the next row. Thus an exact point tiling of a declared rectangle is precisely a consistent spacetime diagram.

The bottom boundary fixes the entire initial tape except the certificate payload. The initial physical head is fixed at the start position; varying a payload value under a logical cursor varies only its ordinary marked tape symbol, not the physical head. Blank side guards and side colors \((B,B)\) prevent the head from leaving the finite window. The top boundary requires exactly one accepting head, with the other top values unconstrained headless symbols. For each finite width this top condition is a finite union over accepting-head positions and symbols.

The two directions.

From a computation to a tiling. Given a payload whose constructor and complete checker reach acceptance in \(H\) steps within the declared tape window, write every successive row. At each cell use its actual three-cell input neighborhood and its determined output. The colors agree by construction; every center is occupied once. The top row contains the accepting head.

From a tiling to a computation. Horizontal colors force each row's neighborhoods to agree with one common row. The fixed bottom has one physical head. Induction on rows shows that the north values equal the deterministic operational successor and preserve exactly one head. Blank side guards forbid an out-of-window move. Consequently the accepting top can arise only from acceptance of the same chosen payload by the literal table. The constructor then binds the checked request to the fixed assertion.

\[\exists\text{ compatible accepting rectangle for the boundary}\quad\Longleftrightarrow\quad\exists\text{ compatible payload accepted by }M.\]

This equivalence concerns operational acceptance of the published table. The additional implication to a theorem of the intended first-order theory requires correctness of the input, tree, tape and logical-checker implementations. Finite independent replay supports those implementations; a universal machine-checked correctness theorem remains open. A fixed malformed theory need not admit any accepting payload.
