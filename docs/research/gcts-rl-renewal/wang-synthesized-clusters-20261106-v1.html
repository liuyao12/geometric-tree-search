A cluster that changes shape when it attaches

To lift a sequence, the miner locates the smallest common subterm containing its rewrite positions. It creates fresh variables for the primitive laws and unifies the constraints along the sequence. The input and output terms become the two interfaces of the new law. The checker replays the resulting law on arbitrary fresh parameters before admitting it.

General law

\(u_{0}+(u_{1}+u_{2})=u_{1}+u_{0}+u_{2}\)

Use in a held-out proof

\((e+d)\times b+(c\times e+d\times c)=c\times e+(e+d)\times b+d\times c\)

  • \(u_{0}\mapsto (e+d)\times b\)
  • \(u_{1}\mapsto c\times e\)
  • \(u_{2}\mapsto d\times c\)

This is one of 8 compound-term applications for which the full donor-shaped catalogue contains no single cluster with the same input and output at the selected site. The extra flexibility produced useful new applications. Across the benchmark, it solved fewer problems than the donor-shaped inventory.
