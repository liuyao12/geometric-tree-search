NOTEBOOK 99 · AUTHORED AGGREGATE DESIGN · NOT A DISCOVERED THEOREM

Two lemma families can share actual primitive tiles.

The symbolic incidence example assumes that two distinct points lie on each pair of lines. Write \(H(P,Q,\ell,m)\) for the conjunction that \(P,Q\) are points, \(\ell,m\) are lines, \(P\ne Q\), and both points are incident with both lines. Only the guarded Hilbert uniqueness axiom I.2 and ordinary logical rules are used.

\(H(P,Q,\ell,m),\ H(P,Q,m,n),\ \operatorname{Incident}(R,\ell)\ \vdash\ \operatorname{Incident}(R,n)\)

\(13\) primitive inference placements

\(\begin{gathered}H(P,Q,\ell,m)\\\operatorname{Incident}(R,\ell)\vdash\operatorname{Incident}(R,m)\end{gathered}\)

\(5\) identical placements

Uniqueness axiom and instantiation at the two points

Second lemma instance

\(13\) primitive inference placements

\(\begin{gathered}H(P,Q,m,n)\\\operatorname{Incident}(R,m)\vdash\operatorname{Incident}(R,n)\end{gathered}\)

The union contains \(13+13-5=21\) inference placements, plus three seeds for the ordered local hypotheses. Reuse means the exact same decorated primitive placement, counted once; equal formulas alone do not authorize sharing. Local assumption commands alias their input rows and add no occupancy.

The first output at row \(15\) is the second instance’s incidence input, read by its row-\(23\) modus-ponens port with offset \(-8\). High-level receptors project to those primitive reader ports. Adding the old unit-macro offsets at the final row would conflict with existing primitive ports.

This is a frozen authored construction, with no independent aggregate audit yet. It changes the finite boundary to \(24\) primitive rows; it is not a drop-in replacement for the old five-row macro board. Full primitive graph enumeration, compiler/native correspondence, and atomic cluster execution remain open.
