What the square grid checks

A premise selects a clausal schema and a typed substitution. The circuit requires each schema literal to produce a ground atom, then checks every bit of the resulting clause. Each derived row selects two earlier clauses and a pivot. The final clause must be empty. The four rectangles rejected 36 changes to individual premise bits.

The palette is fixed and tiles only by translation. The finite term bound, typed atom catalogue and interior gate selectors are fixed instance data. The schema choices, substitution choices, proof references and clause bits are free certificate fields. Compressed ribbons check the full rectangle through repeated transport rules. The excerpt above shows the input columns for one logical line. Its checking gates can span many physical rows.

The ground search enumerates finite term layers. Exhausting one layer without a refutation leaves the first-order problem open. This experiment starts with clauses. It leaves a general formula-to-clause front end and the unbounded search implementation open.
