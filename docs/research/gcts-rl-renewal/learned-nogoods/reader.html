Read an implication query in plain English

\[F\models\bigl((X_i=b)\Rightarrow(X_j=c)\bigr),\qquad i\ne j,\quad b,c\in\{0,1\}.\]

“Under the original clauses, does fixing the first bit force this value of the second bit?” To look for a counterexample, fix the first bit as requested and the second bit to the opposite value. The stored seed pairs are sorted by variable index.

\[P=\{X_i=b,\ X_j=1-c\}.\]
FOUND

A complete assignment satisfies the original clauses and this counterexample prefix. The implication is false.

EXHAUSTED

Every completion of this exact finite query context failed. Its whole-prefix negation is eligible for certification.

UNKNOWN

The declared search was unfinished. It proposes no clause and supplies no negative certificate.

A completed failed query context can be refuted entirely by propagation. This pilot does not require a deep failed branch or a positive branch-decision count, and does not claim to mine such branches.

Selection follows a frozen order

Each \(X_i\) is Boolean: a positive literal is true at bit \(1\) and a negative literal at bit \(0\). Each original context is the conjunction of its four input clauses.

The next test must add information before it is already known

This result changes the experiment design. A future frozen catalogue should contain contexts where complete failed-prefix search can certify a constraint stronger than the current propagation. We must record the first additional live candidate it actually eliminates, then compare against ordinary search with the identical certified information. Earlier guard availability is a separate scheduling/layout control, and cannot be credited as learned information. Hierarchical lemma and receptor-family reuse remains a separate research track. These are next tests, not results of this pilot.

What the finite pilot establishes

The saved evidence passes: this pilot shows automatic discovery and independent certification of a few redundant clauses in these original finite contexts, their compilation into real point markings, and their lack of additional point pruning on the same replay queries. The prior calibration established only a human-designed Boolean-to-point construction; its counts and resource outcome are not current pilot evidence.

Each candidate is already positioned and fixed in orientation, with transformation mode identity_only. Its positive support is one required integer point with \(t=1\), and all other base contributions are zero. This does not exercise a runtime translation generator, rotations, reflections, fractional capacity, multi-point positive support or nontrivial growth generations. The full tuple inventory can grow exponentially; it is not a fixed universal Wang set.

This is a small finite consequence-learning adaptation. It is not the master contract's complete neighboring-pair/corona marking learner, an infinite tiling result, a newly discovered general mathematical theorem, a new Q proof, or an RL experiment. Discovery and replay use the same contexts and catalogue; there is no held-out or transfer claim.
