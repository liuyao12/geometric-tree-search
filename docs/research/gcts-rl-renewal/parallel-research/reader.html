ROOT experiments

Mathematical reader

Expose target formulas and, when available, each discovered proof line as a formula and natural English.

Parallel review has made a concrete contribution.

Owner loop-variable error

ROOT found that the owner V3 pin loop shadowed the validated group record. No actual execution had begun, and the frozen V3 source was preserved for an immutable successor.

Frame interface mismatch

The independent reviewer found that adapter V2 accepted an exact seven-field frame while the owner passed a nine-field decoded transport. An otherwise successful path would have been rejected. The saved V2 review specifies repair without discarding the raw transport evidence.

Bind the buffer actually decoded

The V3 review found that verifying one file read did not hash-bind a later decoded buffer to the same pin. The adapter V4 repair checks the length and digest of the actual buffer being decoded. This is an exact-byte authority repair; no concurrent replacement experiment is claimed.

Next deliverables should return us to mathematical search.

  1. Close the prospective execution contract. Engine authoring supplies immutable interface repairs and complete source bindings; independent review checks decoded frames, actual-handle provenance, complete resource terms and bounded residual work. Source hashing alone supplies no resource qualification.
  2. Qualify one fresh, previously unexecuted context. After those prerequisites, ROOT may run the separately frozen version once and save semantic and full resource outcomes separately. The original first donor stays unknown.
  3. Produce an inspectable automated proof. Save the exact statement, allowed inventory, search budget and independently checked certificate. The reader must translate the actual returned lines, including hypothesis occurrences and lemma expansions, without inserting a human-authored proof route.
  4. Measure the search contribution. Compare the same target set, checker, primitive domains, inventory and budget with and without GCTS markings, learned proposals and reusable clusters. Report costs of discovering, qualifying and reusing clusters, plus failures and unknowns. Keep held-out targets out of policy fitting and parameter tuning.

The accepted search contract remains the master algorithm: complete candidate bookkeeping, global dead ends then forced moves, earliest-generation branching, complete fallback and exact rollback. A heuristic score cannot make an unknown into proved pruning.

Keep repeated premises distinct

\(\Gamma_0:\ell=m,\quad\Gamma_1:\ell=m,\quad\Gamma_2:\operatorname{Incident}(R,\ell)\;\vdash\;\operatorname{Incident}(R,m)\).

The same equality occupies two different hypothesis positions. Search and certificate checking must preserve their distinct occurrence licenses.

donor-repeated-equality; repeated formulas do not merge the occurrences.

Here geometry is expressed through formal symbols such as Incident; the tile canvas is not a Euclidean drawing. These goals use a finite incidence-and-equality fragment, rather than a full Hilbert geometry or Peano arithmetic theory. Broader theories need separately specified axiom and inference coverage.

A returned placement of an authored cluster is library reuse. A new proof-search result must identify the target, the exact allowed library and the certificate found by the algorithm. A learned contribution additionally needs actual training records and comparison runs.
