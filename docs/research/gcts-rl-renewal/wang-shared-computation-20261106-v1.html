Reduce halting to an accepting rectangle of the shared palette

Use the two-counter instruction convention in Dudenhefner’s CM2. A configuration has a program counter \(i\) and counter values \(a,b\). Encode it by the ground atom \(P_i(S^a(0),S^b(0))\). Let \(h\) be the program length and route every out-of-range address to \(h\). Dudenhefner’s CM2 definition and undecidability theorem

The top boundary includes the initial fact. For first-counter increment it includes the universal closure of \(P_i(x,y)\to P_{i+1}(S(x),y)\). For decrement with jump target \(j\), the two universally quantified branches are

\[ P_i(S(x),y)\to P_j(x,y),\qquad P_i(0,y)\to P_{i+1}(0,y). \]

Swap the argument roles for second-counter instructions. The top boundary also denies the existence of a halting configuration by requiring \(\neg P_h(x,y)\) for all \(x,y\).

If the machine halts, each instruction instance and one resolution derive the next configuration from the preceding fact. The last configuration resolves with the denied halt and gives the empty clause. The fixed arithmetic and geometry checker accepts those ground instance and resolution records. Its computation is a finite rectangle with a suitable width and height.

If the machine runs forever, interpret \(0\) and \(S\) as zero and successor on the natural numbers. Interpret each \(P_i\) as exactly the pairs reachable at address \(i\). The initial fact and every transition clause hold by closure of reachability. \(P_h\) is empty, so the denied halt also holds. Hence sound ground instantiation and resolution cannot derive the empty clause.

The top and side tiles fix the input prefix, free proof fields and tape walls. The prefix and the rule for framing any candidate width are computable from the initial configuration and program. Adjacent interior squares enforce consistency of the overlapping tape triples. Each triple determines the next value of its middle cell, so induction on rows gives exactly the deterministic verifier computation. The bottom cap requires acceptance. This reduces CM2 halting to existence of a finite accepting rectangle of some width and height for the prescribed frame.

Give bounded tactics a complete increasing-depth fallback

For a finite first-order input, use the earlier checked definitional clauses, treating equality by its congruence axioms when requested. At each depth \(d\), enumerate the finitely many ground terms and all ground instances whose terms have depth at most \(d\). Perform complete propositional variable elimination and keep the resolution derivation when it finds a contradiction.

Herbrand’s theorem supplies a finite unsatisfiable ground family for an unsatisfiable universal clause set with a nonempty ground term universe in each sort. All terms in that family have a common finite depth bound. Therefore the schedule with unbounded resources eventually finds an empty clause for each valid entailment in this input language. A finite run can return an unresolved depth bound. The schedule may continue indefinitely on invalid entailments. Each checked proof uses a finite depth and a finite fragment graph. python3 source/shared_wang_v1.py prove fol input/example-fol-v1.json fol-proof.json --limit 5
python3 source/shared_wang_v1.py verify input/example-fol-v1.json fol-proof.json
python3 source/shared_wang_v1.py prove cm2 input/example-cm2-v1.json cm2-proof.json --limit 24

Use --guided with fol to try the frozen tactic policy first. --limit bounds the fallback term depth for first-order inputs or the number of processed configurations for two-counter programs. With the flag omitted, search can keep running. Certificate generation separately caps tape steps per patch via --tile-steps. Bounded search returns an unresolved result without writing a certificate.
