What the boundary and squares check

From a statement to proof text

A deterministic front end clausifies the hypotheses together with the denied goal. For a many-sorted input it adds unary sort predicates, guards to source clauses, and clauses stating the result sort of each function. Equality uses explicit equivalence and congruence clauses. These source clauses form the fixed top prefix. The front end and its source-language interpretation are part of the trusted translation.

In the open suffix a grounding record names a source clause, supplies ground terms for its variables, and gives the resulting clause. The machine checks term syntax and substitutes the same text at every occurrence of a variable. A resolution record names two earlier clauses and a pivot. The machine checks complementary pivot signs and requires every residual literal in the conclusion. The final clause is \(\bot\). The proof reader decodes the raw boundary records and identifies a tile row at each line's acceptance.

From proof text to local square rules

The one-tape verifier has 4,037 states and 37 tape symbols. A north color carries the old tape cell. A south color carries the next cell. West and east colors carry overlapping pairs of old cells, so the square can see its old neighborhood and enforce the unique local update. The left and right walls delimit the tape. The top fixes the start head and the positions of the verifier's markers. Only certificate character positions are open. The accepting bottom row uses a flag that switches at the unique accepting head.

In a run of read-only sweeps, the checker verifies the exact tape substring against the permitted symbol set and checks the range of head positions. An explicit change checks the affected squares against the palette. All other columns have headless neighborhoods and carry their old cells through. The overlapping old pairs agree at every shared edge by construction. The audit also expanded 2,353,416 squares in a small frame and checked their literal edge colors.

Why this can express unbounded proof and computation

There is no fixed maximum term depth, number of variables, or proof length in the verifier rules. For an unsatisfiable finite set of universally closed clauses, Herbrand's theorem gives a finite unsatisfiable set of ground instances. Propositional resolution refutes that set. Those two operations give the verifier a finite accepting witness when the frame is allowed to grow. Each tested search still has declared bounds. Robinson, 1965

A two-counter program can use a predicate for each instruction position and terms \(0,S(0),S(S(0)),\ldots\) for counter values. Its clauses encode increment and the zero and nonzero decrement branches. Reaching an out-of-program label derives a halt atom. If the program halts, the reached configurations give a finite Horn proof. If it runs forever, interpreting each configuration predicate by the reachable configurations gives a model in which the halt atom is false. This reduction uses the same clausal format as the mathematics examples. Dudenhefner, CM2 instruction convention

In this experiment the search operated on clause moves and then supplied the certificate suffix. The fixed tape machine checked the suffix using square rules. Learning directly over the physical tape layout remains an open search experiment.

Controls and independent decoding

The independent decoder checked 47 proof records against their displayed clauses. Across 130 small syntax and substitution trials it agreed with the compiled machine. The case-specific controls reject incorrect pivot signs, forward references, lost literals, and nonempty final clauses. A separate corruption reverses a recorded sweep and is rejected by the frame checker.

The quantifier-swap control asks whether \((\forall x\,\exists y\,R(x,y))\Rightarrow(\exists y\,\forall x\,R(x,y))\). The two-element model with \(R(x,y)\) defined by \(x=y\) makes the antecedent true and the consequent false. The finite search found no refutation in the tested layers.
