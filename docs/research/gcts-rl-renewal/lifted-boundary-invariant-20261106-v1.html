Learning boundary invariants for Turtle and Penrose

Two reusable Turtle edge-weight tables certified 27 of 36 new failures whose area and ordinary edge counts passed. Penrose has a precise limit for this strategy. Every balanced boundary is a signed sum of rhomb boundaries, even when the region has an edge that no rhomb can cover.

Derive an invariant from the tile palette

Subdivide the sides into common primitive segments. For each direction, count edges in one orientation with positive sign and those in the opposite orientation with negative sign. Each tile’s vector is a row in a matrix \(A\). The generator searches the rational nullspace of \(A\) for an integer weight \(w\) with nonzero value on the requested boundary.

The checker evaluates the weight on every allowed tile orientation and on the actual target. Each interior segment occurs twice with opposite orientations, so its contributions cancel. A boundary with nonzero total weight cannot be the boundary of a union of the available tiles. A sealed pocket is checked when the request requires its whole interior.

Adding equilateral unit triangles changes the Turtle repertoire. The earlier mark is unavailable, and the pilot constructs a 400-triangle cover of the same target.

Learn where an edge starts

Replace the direction key with a pair consisting of the positive direction and the starting vertex modulo a period. Reversing an edge negates its contribution. Add a training row for each orientation and each translation residue. Finite-field elimination gives a sparse weight vector for a failed query. For all three donor outputs, the same coefficients also annihilate the full training table over the integers. The three outputs reduce to two distinct integer tables.

The inventory precompiles the allowed rotations, reflections, and residue shifts of each checked weight table. The receiver sums its boundary once per period. A nonzero value certifies impossibility before the fixed-region solver builds its interior occupancy map. For a long straight side, quotient and remainder give the number of edges in each residue phase.

What additive edge markings can prove for Penrose

In the unmarked, edge-to-edge unit-rhomb model, each pair of distinct unoriented edge axes gives an allowed rhomb. View a closed unit-edge boundary as a word of signed steps. Swap adjacent steps on different axes. The old two-step path minus the new two-step path is the signed boundary of that rhomb. Sort all steps by axis using these swaps.

When the signed count on each axis is zero, each sorted block is a closed walk on a line. Its directed edge chain cancels. The original boundary is therefore an integer linear combination of translated rhomb boundaries. Every additive antisymmetric edge weight that vanishes on each rhomb also vanishes on such a boundary, even with arbitrary dependence on position or values in another abelian group.

The local certificate checks all four incident rhomb choices on the marked boundary edge. Each has a geometric witness that it extends outside the region. This check uses the requirement that a tile be placed inside the region. The signed sum alone allows a negative coefficient.

Read the shared induction proof

Starting from \(F(0)=0\) and \(F(S(x))=F(x)\), one explicit induction instance yields \(\forall x\,F(x)=0\). Interpret \(F\) as the integer boundary imbalance after a given number of placements, encoded as a natural number with zero preserved. Exact geometry supplies the zero increments and the nonzero target value. One shared proof is bound to 19 signed-direction certificates and 28 periodic certificates.

The proof uses the induction instance. In the two-element control with both successor and \(F\) interpreted as the identity, the recurrence and base equation hold and the conclusion fails.

The grounding choices are specific to the stated induction formula. Resolution search produces the derivation, and the translation-only Wang backend checks the inference records. The compact checker verifies the same logical derivation from the original hypotheses.

Original hypotheses
  • \(\mathrm{F}(0)=0\)
  • \(\forall x{:}\mathrm{Nat}\,\mathrm{F}(S(x))=\mathrm{F}(x)\)
