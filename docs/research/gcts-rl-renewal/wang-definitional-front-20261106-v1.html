Each named predicate takes exactly the free variables of its subformula. The compiler introduces the two directions of the definition as short clauses. For a Boolean connective, an independent checker tests the clause template on all eight assignments to the name and its two inputs. It reads variable scopes and sorts from the original formula and reconstructs every source clause.

Universal subformula

If \(D(\bar x)\) names \(\forall y\,B(\bar x,y)\), the clauses are

\[ \neg D(\bar x)\lor B(\bar x,y),\qquad D(\bar x)\lor\neg B(\bar x,w(\bar x)). \]

When the name is true, the first clause requires every instance. When the name is false, the fresh function supplies a counterexample.

Existential subformula

If \(D(\bar x)\) names \(\exists y\,B(\bar x,y)\), the clauses are

\[ D(\bar x)\lor\neg B(\bar x,y),\qquad \neg D(\bar x)\lor B(\bar x,w(\bar x)). \]

Any instance makes the name true. When the name is true, the fresh function supplies a witness.

Interpret the names by their subformulas from the inside out. Any model of the original premises and the denied goal expands to the new clauses by choosing the indicated witnesses or counterexamples. Conversely, in a model of the clauses, the two directions force each name to have the meaning of its subformula. The signed units require all premises and the denied goal. Thus the clause set is unsatisfiable exactly when the original entailment is valid over nonempty sorts. Plaisted and Greenbaum on structure-preserving clause form

The fixed palette checks instances and resolution. The independent source checker verifies the formula-to-clause translation outside the rectangle. The search can project the top boundary to the clauses actually used. The audit derives that same projection from the checked source and proof rows.
