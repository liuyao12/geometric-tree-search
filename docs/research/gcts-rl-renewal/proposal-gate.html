The request comes before the expensive join.

At a genuine branch, after reviewing any retained family, the gate receives eight features from the existing complete graph: region size, frontier size, selected candidate count, progress, selected position, known formula ports, ambient forbidden-variable fraction, and a bias. Computing these features constructs no family or syntax index.

\[z=w\cdot x,\qquad p_{\mathrm{request}}=\frac{1}{1+\exp(-z)}.\]

Training samples request or defer. Evaluation requests exactly when \(z>0\); a tie defers. A request builds the unchanged exact pool and uses the earlier fixed selector to choose a family. RL learns when to request this pool; it does not learn a new member selector in this experiment. Every executed constituent remains an ordinary original tile, with complete fallback and exact rollback.

All numeric sampled request events and updates
Eight statement-only training requests run for eight passes: \(64\) fresh sampled episodes, beginning with zero weights. Their maximum training region is \(6\) inference cells; the longer evaluation chain has \(8\). The learning signal uses observed inclusive cold-solve time \(\tau\), with search wall budget \(T\):
\[r=\mathbf{1}_{\mathrm{success}}-\frac{\log(1+\tau/0.001)}{\log(1+T/0.001)}.\]
The update averages sampled score gradients over each trajectory, applies its running baseline and clips weights. This is the declared heuristic update, not a claim of an unbiased policy-gradient estimator. The audit verifies the recorded clock binding and every numeric update; it cannot reproduce wall time.
