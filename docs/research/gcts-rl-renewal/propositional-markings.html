What the markings encode

    
Write the formula on line \(i\) as an injective finite word \(E(F_i)\). Our current encoding uses every byte of canonical UTF-8 JSON, followed by the distinct terminator \(256\). At a source port, byte position \(k\) is a separate point:

    
\[m\bigl(p(i,k)\bigr)=E(F_i)_k,\qquad p(i,k)=(4i,100+k).\]

    
A modus ponens guard concluding \(B\), with antecedent source \(a\) and implication source \(b\), also assigns

    
\[m\bigl(p(a,k)\bigr)=E(A)_k,\qquad m\bigl(p(b,k)\bigr)=E(A\Rightarrow B)_k.\]

    
Overlapping assigned values must agree. The rule schema relates the output \(B\) to the two required words; equality alone does not establish entailment. Command words also bind each proposed command to the appropriate guard. Every formula ends with a terminator, so unequal-length words cannot pass by agreeing on a prefix.

    
The complete frontier graph sees all marking dependencies, including distant points outside a placement's occupancy support. All proof obligations start active. It checks global dead ends, propagates forced moves, then branches at the earliest generation, with exact rollback and every original candidate retained.

    
For this bounded example the inventory is instantiated from the assertion's finite formula basis and all strict-prior reference choices. Its types have fixed orientation and declared positional placements. A general inference schema is a family of such placements; it is not by itself a construction of a single finite universal tile set.

  

  

    
The attention analogy is useful.

    

      
Propose an attachment
A query could represent a missing premise; earlier formulas supply keys. Learned compatibility scores could rank source lines, inference families and lemma clusters. The chosen proposal still expands to original placements, and complete fallback remains available.
This is a proposed neural extension. Notebook 62 trains a feature-based cluster policy; it does not train a Transformer attention network.

      
Check the attachment
Exact formula words and the declared inference rule decide whether it is valid. A high attention score cannot repair a conflicting byte or authorize a new rule. These logical markings define the proof problem. Separately certified redundant markings can accelerate search without changing its solutions.
If an independent checker reads the decoded symbolic proof, display markings may be omitted from that certificate. The rule, formulas and source references still have to be checked.

    

    
Transformer attention computes a weighted combination of values using query/key compatibility. Our proof proposal would instead select discrete attachments and validate them exactly. The resemblance concerns access to distant dependencies. Vaswani et al., Attention Is All You Need, §3.2.

  

  

    
Encoding truth values is a different experiment.

    
We could also give propositional variables binary markings and use gate placements for the truth tables of \(\neg,\land,\lor,\Rightarrow\). That encodes a satisfying assignment. To establish \(\Gamma\models G\), we need to establish that \(\Gamma\land\neg G\) is unsatisfiable. A single satisfying tiling of that expression would instead provide a counterexample.

    
For the present proof, the premises require \(P=1\) and \((P\Rightarrow Q)=1\); a counterexample would require \(Q=0\). These requirements are inconsistent. A checkable derivation or an unsatisfiability certificate establishes the theorem. A failed budget-limited search establishes only an unresolved result.

    
The immediate research target should remain proof-line markings and adaptable checked lemma interfaces, while truth-value SAT supplies a useful propositional comparison. Mature SAT search already exists; useful progress requires measuring the cost of reaching the same checked result. MiniSat project.
