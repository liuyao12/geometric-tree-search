    One rule language, many theories as data
    The selected profile accepts the original six primitive rules: named axioms, indexed hypotheses, universal-instantiation licences, atomic equality-substitution licences, ordered modus ponens, and universal generalization. Theory symbols and original hypotheses remain input data. This arithmetic test supplies only the two addition axioms:
    
\[\begin{aligned}A_Z&=\forall x\;(x+0=x),\\A_S&=\forall x\,\forall y\;(x+S(y)=S(x+y)).\end{aligned}\]

    Finite syntax, implicit inventory
    Terms have at most \(12\) constructor nodes and complete formulas at most \(44\). Literal binders use the input names and \(32\) reserved fresh names. Every proof formula is checked in its proper scope. The full set of bounded primitive instances is represented by membership rules rather than materialized as one ground array.
    Whole-formula generalization and instantiation of newly derived universal formulas are available. The full original hypothesis context controls the freshness condition. Capture avoidance, exact source order and every expanded primitive are checked.
    Search bounds are separate
    The ordinary search retains at most \(2048\) facts and \(256\) parameter terms, attempts at most \(50{,}000\) proposals over \(32\) waves, and returns at most \(24\) primitive commands. Equality transport tries a limited set of atomic contexts. These are incomplete search heuristics, not restrictions that certify exhaustion of the underlying language.
    The old ground-catalogue caps remain attached to the old profile. Exact new ground counts and a complete candidate-graph interface are pending. There is no claim of full first-order logic, induction, full Peano arithmetic or a universal finite tile palette.
    

    Why a board can encode a proof
    This is a human-written conditional representation argument, separate from any engine-discovered theorem. Fix the original context, target, input epoch and board height \(H\). Each valid primitive instance is a tile with ordered input offsets \(d_j<0\):
    
\[t(0,0)=1,\qquad m(1,0)=\mathrm F(C),\qquad m(1,d_j)=\mathrm F(A_j),\qquad m(2+j,0)=\mathrm D(d_j).\]

    Here \(\mathrm F\) carries the complete literal formula and \(\mathrm D\) carries an ordered source offset. Require unit occupancy at every \((0,r)\), mark all possible negative source rows with a disjoint outside value, and mark the final output with the private original target.
    

    Exact board to derivation
    Unit occupancy gives one tile per row. A negative offset reads an earlier row; the outside sentinel forbids a read before the board. Agreement of full formula values identifies each required premise with that earlier row’s conclusion. Induction on rows then applies the original primitive rules. The final boundary forces the target.
    Derivation to exact board
    For a nonempty valid word of length \(L\le H\), prepend \(H-L\) copies of its first zero-input primitive and shift all original source indices equally. Place the corresponding prototypes by translation. Every input mark meets its actual source formula and the final output meets the target. This needs coverage of those primitive instances, not a claim that a search found them.
    The separate point checker reconstructs the entire proposed packet, compares exact value types, then accumulates all unit contributions and marking occurrences. Padded-word membership and the unchanged independent logical checker remain mandatory. The full argument and assumptions are downloadable below.
    

    What this says about GCTS and RL
    A positive word and its converted board would establish automatic symbolic proof search plus checkable geometric representation. They do not establish that GCTS found the proof. Complete frontier/candidate bookkeeping, global dead-end and forced-move checks, earliest-generation branching and exact rollback remain requirements for a future GCTS search over this implicit inventory.
    The next useful comparison is a matched ordinary and GCTS search using the same rule language and permitted lemma families, charging construction, verification and failed attempts. Learned receptor families and RL proposals must earn a measurable benefit on held-out targets; reusable lemmas alone are already familiar in proof search.
