What an interface means.

There are finitely many logical tape bands indexed by \(t\), each with a fixed physical base \(b_t\) and a logical cursor \(h_t\). A response begins in state \(q\), ends in state \(q'\), moves cursors by \(\Delta_t\), and describes input requirements \(A_{t,p}\subseteq\Gamma\), final writes \(W_{t,p}\in\Gamma\) and visited-cursor extents \(E_t\). Missing input requirements mean unconstrained; missing writes mean unchanged. A zero-valued tape symbol is an assigned value, never missing.

Every input symbol at relative position \(p\) must belong to its declared set. The response then applies its writes, leaves the rest of every band unchanged and updates the cursors. The extent includes all visited cursor positions, including the final position. These sets are symbolic interface families, not new set-valued GCTS markings. Each concrete input satisfying them yields an ordinary ground computation and ordinary equality-marked Wang tiles.

The response also derives its selected-symbol count \(n\), final selected band \(\ell\) and an affine literal-transition count. For incoming physical head position \(P\),

\[H=P+\sum_t c_t(b_t+h_t)+\kappa,\qquad P'=b_\ell+h_\ell+\Delta_\ell.\]

The published root uses \(P=0\). Its fixed headers, band boundaries and exactly one ordinary cursor marker per band form a layout invariant. A selected-symbol action preserves that invariant whenever its cursor stays in the declared band. The existing finite table audit verifies every literal scan, read/write action and marker update implementing that selection.

Primitive and sweep leaves.

A primitive leaf binds one actual symbol-table action \((q,a)\mapsto(q',w,d)\) on band \(t\). It requires \(a\) at the cursor, writes \(w\), moves by \(d\), and has

\[n=1,\quad c_t=1,\quad \kappa=2+\mathbf1_{d\ne0},\quad E_t=[\min(0,d),\max(0,d)].\]

Its literal expansion seeks the origin, the selected header and the cursor marker, applies the declared symbol action and relocates the marker when necessary. All other cells form an unchanged frame.

A sweep leaf binds a state whose actions on an explicitly derived symbol set \(S\) all satisfy \((q,a)\mapsto(q,a,d)\), with \(d\in\{-1,1\}\). For \(n\) repetitions it requires every traversed symbol to lie in \(S\), writes nothing, and has

\[\Delta_t=dn,\quad c_t=2n-1,\quad \kappa=d\,n(n-1)+3n.\]

The required positions are \([0,n)\) for a right sweep and \([1-n,1)\) for a left sweep. Its extent additionally includes the final cursor position \(dn\). The first expanded micro-action costs \(P+(b_t+h_t)+3\) literal steps; later actions cost \(2(b_t+h_t+id)+3\) for \(1\le i<n\). Summing gives the displayed law. Direct tests compare both directions and all primitive symbol actions against the literal one-tape runner.

Composition derives its own boundary.

To compose responses \(R_a\) and \(R_b\), require the first output state to equal the second input state. Translate every second-child input and write position by the first child's cursor displacement. If a second-child read touches a first-child write, that written symbol must satisfy the read. Otherwise intersect the corresponding incoming symbol sets; an empty intersection rejects the composition. Later writes override earlier writes. A final write implied by a singleton incoming requirement can be omitted.

\[\Delta_t=\Delta_t^a+\Delta_t^b,\qquad n=n_a+n_b,\qquad \ell=\ell_b,\] \[E_t=\operatorname{hull}(E_t^a,\Delta_t^a+E_t^b),\] \[c_t=c_t^a+c_t^b+\mathbf1_{t=\ell_a},\] \[\kappa=\kappa_a+\kappa_b+\Delta_{\ell_a}^a+\sum_t c_t^b\Delta_t^a.\]

These equations follow by substituting the first output cursors and physical head into the second cost law. The interval operations are exact, including read-after-write constraints and unchanged cells. The executable verifier receives no proposed interface: it derives every one of these values.
