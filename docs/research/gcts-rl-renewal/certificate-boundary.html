How this bears on long-range propositional markings.
For modus ponens, one proof line supplies \(A\), another supplies \(A\Rightarrow B\), and the receiving line must produce \(B\). A distant marking can route those formula words to shared premise receptors, so equality of marking values implements the required agreement. The distance between the lines need not be bounded by adjacency.

\[A,\quad A\Rightarrow B\quad\vdash\quad B.\]

A source line can write the exact encoded formula at a receptor point, and an inference family can write the required premise at that same point:

\[m_{\mathrm{source}}(p)=\operatorname{enc}(A),\qquad m_{\mathrm{receiver}}(p)=\operatorname{enc}(A).\]

The encoding must distinguish formulas exactly; a hash without collision checking is insufficient. Matching connects an already justified formula to a valid inference instance. It does not itself establish an arbitrary conclusion. Axiom origins and a well-founded order of dependencies are also required, so a cyclic collection of mutually supporting formulas cannot count as a proof.
With one finite primitive palette, arbitrarily distant semantic links need checked routing or parameterized clusters whose expansions use the original primitives. We cannot silently add infinitely many primitive tile types, one for each distance or formula. That is a reason to expose a succinct family interface while retaining its complete native expansion.


An attention mechanism can propose which earlier interfaces to connect. The proof checker still verifies the exact formulas and rule conditions. Learned scores can order proposals; a failed sample is not enough to justify permanently excluding a candidate. Necessary conditions derived from checked failures could become certified GCTS markings.
This experiment establishes a missing baseline: the whole native machine now guides discovery of previously unknown certificate commands, rather than merely replaying a supplied finished proof. It is a chronological certificate-word control, not primitive-square GCTS search, learned native failure markings, or a new inventory policy. Notebook 59 supplies independently checked native family guidance; integrating that machinery with the free assertion/certificate boundary remains open.


Arithmetic and geometry: what was actually proved.
The arithmetic vocabulary cases discover \(S(0)=S(0)\) and \(\forall x\,(x=x)\). These are logical equality theorems valid in Peano arithmetic and every interpretation of the declared function symbols; they use no arithmetic axioms or induction. The propositional case derives \(Q\) from the given premises \(P\) and \(P\Rightarrow Q\).
The symbolic incidence case derives \(\operatorname{Point}(a)\) from \(\operatorname{Inc}(a,\ell)\) and \(\operatorname{Inc}(a,\ell)\Rightarrow\operatorname{Point}(a)\). Those are explicitly given ground premises, not the full Hilbert axiom groups. The checker uses symbols and arities; no drawn configuration determines validity. General Hilbert theorem discovery, substantial arithmetic theorems, adaptable lemma families and the Turtle/Penrose plane objectives remain active.
The too-short implication envelope and absent-fact envelope are finite search controls. Exhaustion concerns their declared certificate grammar and line bounds; it does not show that a theorem has no proof in the underlying logic. Zero query budget remains unknown.
