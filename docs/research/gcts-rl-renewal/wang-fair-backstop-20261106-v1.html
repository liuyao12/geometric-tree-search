A fair backstop for proof-search advice

The inventory proposer can stop at its budget while a separate fair search keeps running. Every offered step is checked before it enters the fair core. The resulting proofs use the same fixed Wang palette and long-range copy markings as the earlier notebooks.

Keep a mandatory search path

First: advance the fair coreTake the next typed ground instance and process the oldest queued clause against earlier clauses. Preserve its queue, term stream and proof dependencies.
Then: check one advisory recordAdmit an exact source instance or a resolvent of previously admitted advisory parents. Reuse a clause already found by the core. Reject a bad record and continue the next fair tick.

The existing bounded multi-premise inventory search produces a finite list before the driver starts. It uses the previously frozen lemma inventory and the fixed propagation families. This experiment adds no newly trained policy. The interface can accept records from an RL-guided proposer, but these runs test the search guarantee rather than an RL advantage.

The core owns its proof state. An adviser cannot remove a clause, rewind enumeration, replace a parent, or spend the core’s round budget. The experiment still stops the core after a declared finite number of rounds.

What an unbounded run would guarantee

Claim about the idealized algorithm. For a finite well-typed first-order clause boundary with nonempty sorts, the backstop with unbounded resources and a finite advisory list eventually finds an empty clause whenever that boundary is unsatisfiable. This is a mathematical argument about the algorithm; the finite experiments below do not establish the universal claim by testing.

  1. Every ground term has a finite constructor size. The typed term stream enumerates every substitution for every source schema at a finite size layer.
  2. Every admitted clause has finitely many predecessors in the FIFO queue. Later advisory clauses are appended. They cannot keep an earlier clause from being processed.
  3. When a clause is processed, it resolves with the already processed clauses on complementary literals. Each finite ground resolution derivation is therefore reached after finitely many ticks. Duplicate and tautological clauses do not need separate processing.
  4. An unsatisfiable Skolem clause set has a finite ground refutation. This is the standard ground resolution theorem, not a new GCTS result. Combining it with the first three points proves the claim. Robinson’s original resolution paper develops refutation completeness and search principles.

For equality, the finite boundary includes equivalence and congruence schemas for its signature. Our extension of the argument is to quotient any model of those schemas by each sort’s equality relation; congruence makes the functions and predicates well defined on the quotient. Thus ordinary predicate resolution can serve as the complete backstop for the equality encoding too.

Each returned proof consists of source instantiation and ground resolution records. The existing elaborator adds sort proofs and produces a Wang diagram with anchored copy links. The new driver does not introduce an additional logical rule or change the palette.

The guarantee assumes enough storage, arithmetic range and verifier budget. The current Python program has practical limits. For an infinite recursively enumerated axiom theory, an additional fair schedule over finite axiom prefixes would be needed; this driver takes a finite boundary. General first-order provability is a semidecision problem, so an open finite run gives no non-entailment verdict.

Scope of the proof system

The general formula-to-clause boundary has a separate independent Python checker. The Wang squares certify the clausal derivation, and copy markings bind its local pieces together. Thus the present end-to-end checker includes the formula boundary checker; this report does not claim that all preprocessing has been embedded in one ordinary Wang rectangle.

The fair core supplies a standard completeness argument. The research contribution being tested remains whether learned markings and reusable receptor families lead to useful proofs sooner. The clause-encoding control shows why such claims need conventional baselines. This backstop makes advice dispensable for correctness and eventual discovery in the stated finite-boundary setting.
