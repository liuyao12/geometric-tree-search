What the reinforcement learning changed

Training sampled a linear-softmax policy. The terminal reward uses an independently checked positive patch, an independently checked nondead best-prefix graph, and recorded search costs. A certified negative receives a penalty. The fixed objective is

\[ r=2\mathbf1_{\mathrm{success}}-\mathbf1_{\mathrm{negative}}+\frac{U_{\mathrm{verified}}}{U_{\mathrm{core}}}-0.10\min(t/t_{\max},1)-0.02N/N_{\max}. \]

Only viable checked progress receives occupancy credit. Each update uses the reward minus the previous running baseline, averages the chosen-minus-expected softmax feature gradients over branch choices, and clips weights to the declared interval. Heldout RL uses deterministic maximum score, with both bank and weights frozen.

Verification, limits and costs

All finite target points, including untouched zeros, are active generation-zero obligations. A new tile touching an untouched target receives generation one by the existing-point formula. Newly exposed positive support becomes active too. Every decision checks global dead points, then the finite core-full/viable-frontier checkpoint, then global forcing and generation-first branching.

The v2 cache defers extended marking materialization until positive capacity passes. Every valid candidate still has its complete mark-only dependencies. Its entry guard is a cooperative resource limit, not an operating-system byte limit. Time, node, depth, cache and cohort stops remain unresolved; marked failure is not an unmarked non-tiling claim.

Scope. These are finite point-core checkpoints with viable exposed frontier and free exterior, not exact packing inside an impermeable polygon boundary. A proposed expansion is not an executed cluster. This study does not establish a substitution rule, infinite tiling, RL superiority, practical arbitrary-region performance or necessity of the learned marking.
