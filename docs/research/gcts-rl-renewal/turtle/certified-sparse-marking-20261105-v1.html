Why a certified conflict is safe to prune

Let \(F\) be the set of points queried by a verified negative tree, including its dead leaves. Suppose a capacity-legal placement set contains the two seeds and saturates every point of \(F\). At any nonterminal node reached using placements from that set, its queried point is still unsaturated. Some unused placement from the set contributes to the point and fits the current prefix. The verifier checks that the tree includes a child for every such legal placement. Following one of these children at each step reaches a dead leaf, where the same argument would give a legal placement. This is a contradiction.

Every full unmarked point tiling saturates all queried points. For a geometric tiling with the allowed Turtle placements, the angular contributions around each lattice point fill one turn, so the same saturation condition holds. The proof gives a necessary constraint on any such plane tiling. Existence and substitution remain open.

For a finite target, apply an exclusion only when its translated and oriented footprint lies in the required saturated region. Across the 263 certificates, 2 query a point outside their seeds' combined support. Even a point inside that support may lie outside a specified finite target. The exported fields therefore carry a saturation precondition. This experiment measures coverage and size. Search speed and RL effects require separate runs.
