Reference choices are products with a forbidden diagonal.

For a modus-ponens rule \(A,\ A\Rightarrow B\vdash B\), let \(X\) be all earlier ports compatible with \(A\), and \(Y\) all earlier ports compatible with \(A\Rightarrow B\). An unassigned port belongs to both. A single earlier line cannot carry both distinct finite formulas, so the exact number of candidate reference pairs is

\[|X|\,|Y|-|X\cap Y|.\]

Two integer masks store these sets. Every member is still available; branching streams the complete product with its diagonal removed. Degree zero and one use the exact count, never a sampled shortlist. Schema parameters are Cartesian blocks; a fully constrained output is matched to each schema and its parameters are checked against the declared pool. The finite modus-ponens implication catalog is still constructed; this is not an unlimited symbolic formula solver.

Each candidate occupies only its own proof point, so its reverse incidence is exactly the singleton containing that point. New complete formula markings update their own slot and all later candidate domains that can reference them. Copies restore the entire point state and immutable factor domains on failure. Global dead ends precede forced moves, then generation precedes degree ties.
