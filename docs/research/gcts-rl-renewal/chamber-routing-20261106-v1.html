Transport a checked chamber

The library uses a canonical boundary under the allowed poses. Each reuse records the pose and translation that return the canonical chamber to the receiver. The geometry checker tests the transformed boundary and rechecks a joined cover. It rejected a deliberately altered pose in each tile system.

Turtle uses the allowed poses of its axial \(A_2\) model. Penrose uses the unmarked unit rhombs with full-side internal contact in \(\mathbb{Z}[\zeta_5]\). The decisions concern finite fixed boundaries.

Compare the frozen policy and fixed schedules

Each system has four earlier chamber donors, 12 training outlines and 14 new test outlines. The tests comprise ten fresh grafts and four controls authored without a prescribed bridge. The grafts deliberately draw from recurring chamber families. No test starts with a seed tile or a nominated edge. Outer boundaries are distinct up to the allowed poses. Each run starts from the same donor snapshot for its registration arm.
