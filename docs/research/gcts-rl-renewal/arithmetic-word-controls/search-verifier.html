A resource guard for processes that overlap

Sequential child peaks should not all be added as if every child were alive at once. The proposed guard gives each native launch occurrence an interval from just before launch to just after reaping, weighted by that child's observed kernel peak. It sums weights where these expanded intervals overlap, adds the parent's global peak and the maximum of the serialized observer peaks, and also retains live samples. Missing intervals prevent admission. The ceiling remains \(512\,\mathrm{MiB}\).

This is a conservative bound for the declared owned leaf-process model. It is not an operating-system hard limit or a measured memory result. These colors distinguish process roles; they are not mathematical proof markings.
