WHAT THIS CONTRIBUTES

Direct proof search is demonstrated. General acceleration is open.

Eleven examples cover modus ponens with premise joins, universal instantiation, generalization, equality congruence, four numeral addition statements, addition by one with a parameter, and multiplication of one by one. No witness sequence, theorem-specific proof skeleton, old policy or searched lemma library is input. The two other cases are a shorter envelope for the implication theorem and an absent-fact control.

The same logical grammar gives GCTS \(644\) visited states versus \(12375\) for chronological symbolic DFS. Search time, including GCTS candidate construction and graph initialization, is \(4.511720\) seconds versus \(0.121492\) seconds. The controls use different schedulers and representations; this is not an adjacency-only versus distant-marking ablation. Equality congruence favors GCTS on both work and time, while multiplication strongly favors the symbolic control. These are single sequential runs, not benchmark rankings.

The real contribution so far: distant constraints allow GCTS to work backward from a conclusion while retaining earlier-reference proof semantics. It can automatically assemble a valid derivation from a finite grammar. A generic constraint solver could also express this problem; comparative superiority and useful RL remain unestablished.

These tiles are positional finite types with identity transforms, using exact formula syntax IDs as scalar values. They are Wang-style semantic constituents, not a translation-invariant four-edge Wang inventory. The grammar grows with the proof-cell bound. The markings define the mathematical problem; this batch does not learn new failure markings.

Arithmetic rules are authored compilation of every bounded contextual axiom instance in both directions, including variable-erasing reversals. Their derivations are checked before search. The bounded equational grammar does not include induction. Primitive FOL rules use an explicit subformula/schema closure, not the earlier fair language ladder. Universal closure of the arithmetic parameter is added after the selected equational chain; no induction strategy is discovered here.

CONFORMANCE AND TRUST

Check the tiles, then check the mathematics.

The independent auditor reconstructs the external theories and targets, enumerates every finite positional tile, recomputes all saved frontier domains, and replays every complete GCTS search tree, including its failed branches. It independently enumerates all bounded arithmetic terms and \(1232\) contextual rewrite edges, then expands every compiled rule and every found derivation into the frozen primitive kernel.

Each proof tile occupies a single point with \(t=1\). Earlier premise requirements and its conclusion assign scalar \(m\)-values at separate formula points. A complete tiling has exactly one tile per proof cell and agreeing formula ports. Reading cells in slot order gives strict earlier dependencies. Conversely, each valid command sequence in this grammar supplies exactly such a tiling. Unused commands and explicit copy rules are permitted; different schema witnesses can prove the same formulas.

The unchanged point graph checks global dead ends, then all global forced moves, then earliest frontier generation with degree breaking ties. This finite boundary starts every proof cell at generation zero. Differential updates include marking-only distant dependencies; snapshots preserve exact rollback. The new tests compare all visited domains with independent enumeration, enumerate a tiny certificate-set equivalence, test zero markings and repeated references, and reject altered ports, trees and unused invalid proof prefixes.

RESEARCH PRIORITIES

Concentrate on proof tiles.

Turtle and Penrose are useful controls for generic point bookkeeping, geometric interfaces and cluster behavior. They need not drive the proof experiment. The next gates are a matched encoding ablation, automatic promotion of searched subproofs into reusable multi-level tiles, and zero-start RL proposals measured against plain GCTS with all expansion costs charged. A fair semantic grammar with induction and fresh binders follows; failed bounded searches must never become unsound pruning.

The multiscale analogy is operational: a checked lemma summarizes a patch through an explicit premise/conclusion interface. Higher layers may reuse it only when those ports agree and its expansion checks. Learn which interfaces pay for themselves; measure the complete pipeline.
