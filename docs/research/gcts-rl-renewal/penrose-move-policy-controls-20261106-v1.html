What learned doublets add to Penrose search

A frozen move policy changed the first proposal at 1,206 search states. Its hybrid resolved 111 of 120 requests. The units-only control resolved all 120 with 72,372 placement checks, compared with 182,555 for the learned hybrid. A follow-up experiment identified thousands of doublet attempts that repeated already exhausted unit branches.

Hold the geometry and search budget fixed

The search tiles fixed polygonal regions with unmarked thin and thick rhombs in \(\mathbb Z[\zeta_5]\). Each request gives an initial tile and an exact boundary. The 120 requests cover 96 distinct regions. They include 72 generated regions, 24 subpatches from four certified Penrose hierarchy windows, and 24 generated regions retried with a different legal seed. The new region shapes are disjoint from the development shapes up to translation, rotation, and reflection. The alternate seeds deliberately share their parent regions. Source hierarchy windows

The policy learned from exact rollouts on 60 donor regions. It received positive reward when a move led to a completed tiling and a penalty for longer or exhausted branches. Its features include doublet size, contacts with the fixed target and current patch, and remaining tile count. The ten donor doublets and all learned weights were frozen before evaluation.

Each arm uses the same 1,200-node limit and exact cavity test. The cached arms start each request with an empty table of exhausted states. All doublet arms have the same offered actions at a given state. The three hybrids spend at most the region’s tile count on their first ordering, then use unit-first ordering with the remaining budget and the same cache. The static hybrid favors larger and better-sealing placements. The random hybrid shuffles those same proposals. The units-only arm uses the same geometry with doublet proposals disabled. Skip a doublet when its unit branch has already failed

Suppose the search exhausts every completion containing a particular unit placement. A doublet that includes that unit would require a completion of the same exhausted branch. The follow-up records the failed unit at the current state and skips such doublets before checking their geometry. A branch that reaches the node limit supplies no such record.
