WHAT THIS RUN ACTUALLY DISCOVERS

Inspect the result before claiming an advantage.

Each source proof is searched from its statement, arithmetic axioms and finite grammar. The miner takes every connected fragment of two or three proof cells. A schema retains inference families, relative cell positions and all internal or external premise offsets. It omits literal formulas, variable names, induction-hypothesis bodies and rewrite locations. Recipient rule types and their exact formula ports determine whether an instance is valid. No source proof sequence is authored or supplied.

The learned objects are proposal schemas. They package already checked recipient inferences; they introduce no new axiom or pruning hypothesis. Both base lanes retain the complete primitive inventory, and both cluster lanes receive the same library. All four lanes use the certified resource constraints from Notebook 34. This experiment uses deterministic proposal ordering. RL training and learned failure markings remain subsequent research work.

Generalization remains a checked inference in the closed root proof. A fragment containing it is not turned into an open-premise lemma that would illegally infer \(\forall n\,P(n)\) from an assumption \(P(n)\). The kernel rejects that shortcut. Reuse here means reconstructing valid recipient inference placements and their interfaces.

All lanes have a \(20\)-second search wall and an expanded-attempt cap of \(50000\). Search time pays for model construction, support certification, motif instantiation, propagation and full trace recording. Cold query time also pays for fresh complete catalog construction and validation, decoding and native acceptance. Point attempts count constituent placements; classical attempts count explicit constituent assignments after arc consistency. Those are different units. Proposals that repeat already fixed classical variables still pay for those explicit assignments.


Training is performed once per experiment and reused across recipient requests. Add that full cost once to either cluster lane when asking what a first query costs; do not add it to both alternative systems and call the sum one lifecycle. An unsuccessful budget cutoff cannot support a wall-time speedup ratio against a successful proof. Two repetitions show reproducibility on these cases and remain exploratory timing evidence.
Unknown requests retain their executed prefix and open suffix. Exhaustion applies only to the declared cell/term envelope. The missing-schema, shortened-envelope and shifted-target controls remain distinct from claims of falsehood or general non-provability.


CONFORMANCE EVIDENCE AND THE EXACT LIMIT OF THE SHORTCUT
Clusters preserve proofs, while changing the search graph.


Each recipient metatile consists of distinct original placements with compatible formula/resource markings. Its occupancy is their sum, and its marking is their union, with one owner identity for the atomic placement. An exact metatile tiling expands to an exact original proof-cell assignment. Every original exact assignment can also be tiled using the retained singleton placements. Ownership values constrain decorated representation; renaming those private owner values during expansion preserves the original formula/capacity problem. The tiny exhaustive tests check equality of all expanded solution sets.


Adding genuine atomic tile types changes point degrees and can change forced moves or branching order. The claim is solution equivalence, not preservation of the primitive scheduling trace. Within that enlarged exact model, the point engine uses full frontier/candidate bookkeeping, global dead ends, global forced moves and earliest generation. All finite roots have generation zero. Copied state and graph provide exact rollback; extended formula/resource marks update their dependencies through the same graph.


Classical search uses the same complete primitive domains and necessary resource constraints. It offers every compatible cluster that contains its MRV variable, then retains every ordinary value as fallback. Assigning a cluster is a reversible simultaneous restriction of its constituent variables. Every arc-consistency deletion and every open or closed branch is independently replayed.


SOURCE CERTIFICATES · COMPLETE JOINS · EVERY EXECUTED PREFIX
Evidence and remaining research.


The independent auditor imports no miner, generator, point solver, graph or producer. It reconstructs all source and recipient rule inventories, all connected source fragments and their certificate provenance, and all recipient instances by exact relational joins. It re-enumerates each decided point graph and checks every classical support deletion, attempt, backtrack, solution and open suffix. Every accepted certificate expands independently to primitive lines and receives complete native acceptance, with native program/input bindings audited. The compiler and native instruction implementation remain trusted layers.


The next gate is a fresh RL policy for composing and selecting these proven-valid proposals, with the same library and training charge provided to classical controls. Broader grammar transfer, hierarchical proof constructs, Euclid-style construction obligations, succinct statement encodings and a uniform finite computational tile inventory remain open. A bounded goal-derived grammar has not established Turing-complete expressive reach or proof-search completeness. Turtle and Penrose remain occasional geometry controls; practical fixed/movable boundaries and certified infinite constructions remain part of the active program.
