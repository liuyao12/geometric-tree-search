What was generated.

Every first-component receptor binds an actually selected original hypothesis. A second component may also bind the explicitly declared output of the included first component; at least one such connection is required. That output remains an obligation inside the proposed union. It is not added to the hypothesis list.

For each exact ordered binding, the generator preserves source-member order, reuses an earlier identical placement when legal, and otherwise chooses the earliest free row after its required sources. Component occurrences stay visible even when the union counts an identical placement once. Formula equality alone cannot authorize occupancy sharing.

This finite proposal grammar uses the full \(171\)-family checked inventory, at most two components, and one canonical embedding per binding. It does not generate every compatible cluster, every embedding, new lemmas or unrestricted first-order proofs. Source bodies and the finite \(229\)-recipe, \(217\)-formula language are existing infrastructure. The generator decoded and discarded the old projection example; no authored target-proof word was used as a hint.

One immutable descriptor represents the entire union. The forthcoming search adapter must revalidate it against the complete global point graph, allow forced moves to interrupt it, retain every base alternative, retire incompatible hints and restore the paired state exactly on rollback. Those execution checks were not run here.

The next learning experiment is defined, not trained.

The parallel learning track has frozen a first selector design: choose a ready whole proposal or choose the NULL action, using structural and completion features. NULL must suppress proposal preference in the executable adapter; immutable priorities cannot be changed to simulate a policy. The selection state must share the graph's rollback boundary.

Its source includes an epsilon-mixture policy, a saved-draw selection function, score-gradient calculation and a clipped episode update. Numeric functions, RNG draws, features, donor models and training have not been executed or prepared as an activated experiment. Python annotation compatibility and probability-input validation were repaired in preserved successor sources before any import.

The prospective comparison holds proposal availability, primitives, original hypotheses, scheduler and resource semantics fixed between baseline, untrained and trained lanes. Reward must use dependency-complete facts, avoid rewarding pending output marks or rollback rediscovery, and remain provisional until independent certificate checks. Held-out theorem trajectories must stay out of tuning and mining. This first lane would learn proposal selection; learning new cluster topology and reusable lemmas is a later experiment.
