The adapter first proves each projection from the conjunction of the hypotheses. Each source command is then lifted under that same conjunction, with explicit ordinary tautology, modus-ponens or quantifier-distribution commands. Finally it converts the conjunction antecedent into nested implications and universally closes the remaining free variables. The conjunction is balanced only to shorten its syntax depth.

This adds no trusted rule or premise axiom. Every generated command is checked by both existing kernels. Source proof discovery and deterministic certificate translation are separate operations; the generated tautological helpers are not claimed as newly discovered mathematics.

When generalizing during the original derivation, the variable must remain absent from every open hypothesis. After those hypotheses have been discharged, the complete conditional formula can be universally closed. A rejected source inference cannot be repaired by merely changing its scope label.
