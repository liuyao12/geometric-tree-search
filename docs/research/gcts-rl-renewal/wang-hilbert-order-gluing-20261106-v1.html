Hilbert geometry from four-point clusters

Give five abstract points a middle point for every triple. Checking four of the five quadruples forces those choices to come from a single linear order, up to reversal. The same four-point clusters suffice to glue an order on any finite set around one fixed anchor.

From local order to a global order

Hilbert’s order axioms give each triple of distinct collinear points exactly one middle point. His four-point axiom requires an order on each quadruple that realizes its four middle choices. Glue an arbitrary finite order

Fix two distinct anchors \(A,B\) and orient each local order so \(A\prec B\). For a pair \(X,Y\), use the local order on \(\{A,B,X,Y\}\) to read \(X\prec Y\). An order realizing a betweenness table is unique up to reversal. Its endpoints are precisely the points that never occur as a middle, and once an endpoint \(E\) is placed first, \(B(E,X,Y)\) fixes the comparison of each remaining pair.

For any three points \(X,Y,Z\), the union with the anchors has at most five elements. On a five-element union the four quadruples containing \(A\) suffice by the checked result above. Smaller unions already have a local order. Its restrictions agree with all three anchored pair comparisons, so the global comparison is transitive and realizes every original middle choice. This proves existence and uniqueness up to reversal for every finite size. Sets with fewer than two points carry their unique trivial order.

For \(n\geq4\), the proof uses the \(\binom{n-1}{3}\) quadruples containing \(A\). The table shows additional reconstruction tests on larger generated inputs.

Read the searched certificate

The search splits four anchored quadruples into their possible patterns. If two patterns choose different middles for the same triple, the uniqueness axiom closes that branch. On a compatible branch the choices give one of the 60 orders, contradicting the negated theorem. The proof shares repeated conflict certificates. Its last record is the empty clause \(\bot\).

In the clauses, \(Q_{i,j}\) selects pattern \(j\) of quadruple \(i\). The symbol \(D_{i,[r,s)}\) allows patterns from index \(r\) up to but excluding \(s\). The quadruples are numbered in lexicographic order by their point names.
