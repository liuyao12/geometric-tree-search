GCTS with an independent branch-order advisor

Forced moves run as usual. At the first ambiguous branch, the baseline continues and an optional RL worker orders the legal alternatives in its own search.

Only a complete fill that passes independent exact rerasterization can be returned. The untouched boundary and full cavity coverage are part of the check. If the advisor runs out of work, the baseline remains eligible to finish. A provisional dead end in the advisor's search has no effect on placements in the baseline.

Fresh hat and turtle cavities

Both the baseline and the protected solver filled all 40 cavities. The baseline found the same patch and visited the same states with the advisor enabled. Twelve cavities finished before the baseline reached any ambiguity, so no advisor search was started on them.

A one-state advisor limit on one ambiguous cavity per shape returned the baseline fill. Using a second worker preserves the original search and its budget, while elapsed time still depends on how the processes are scheduled.
