Why the same palette covers the instruction language

One transition table has 672 states, 31 symbols, and a fixed local membership rule for its finite palette. The archive gives every tile used in the accepting rectangles. It stores exact changes from the preceding row. Each square is placed by translation and checked by its four edge colors. The top boundary fixes the compiled program, initial configuration and goal, leaving the certificate cells free. The bottom cap requires the unique accepting head.

At program position \(p\), the atom \(P_p(x,y)\) records the two counter terms. The rule for a first-counter increment is \(\forall x\forall y\,(P_p(x,y)\to P_{p+1}(S(x),y))\). A first-counter decrement instruction with jump destination \(q\) uses

\[ \forall x\forall y\,(P_p(S(x),y)\to P_q(x,y)),\qquad \forall y\,(P_p(0,y)\to P_{p+1}(0,y)). \]

The second-counter rules exchange the argument roles. From the single initial fact, each implication before the halt label is the corresponding CM2 step. Only an out-of-program position enters cleanup. Cleanup empties both counters and reaches the designated zero-counter goal. Conversely, every halt yields a finite chain, an accepting verifier computation and a finite rectangle once its certificate width and time height are large enough.

Thus the unbounded framed tiling question for this palette inherits CM2 halting via this reduction. The source defines the exact instruction convention and gives its halting theorem. Dudenhefner, Definition 2 and Theorem 6.

Qualification exercised 96 instruction controls and 5 malformed strings. The four experiments use explicit search caps. Their checked executions demonstrate the encoding. Translation of a general first-order proof checker into this instruction language remains open.
