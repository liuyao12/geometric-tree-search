Learn from completed branch attempts

The model scores each legal pose from its symmetry, its position relative to the chosen sample, nearby uncovered sites, original rank, and search depth. The solver tries moves by score. Site selection, forced placements, and the imported conflict bank follow the same rules in each arm.

For a branch attempt that costs \(v\) visits including the initial placement, the training target is \(8\mathbf{1}_{\mathrm{cover}}-\min(7,\log_2(1+v))\). The cover indicator is set when that subtree returns a full cover. The model updates a linear action value from this return and explores by shuffling a fraction of decisions. Each seed runs eight rounds over six donor outlines. The weights are frozen for the held tests. Sutton and Barto on return-based action values

The reward and features were chosen for this experiment. Changing the move order can change which new conflicts the solver discovers. The same checker validates covers and refutations throughout.
