    How a learned failure becomes geometry
    A trial placement is excluded only after an independently checked certificate shows that every original candidate at a mandatory unfilled root conflicts with that trial. A fresh auxiliary point \((-100,k)\) receives a fixed initial marking \(1\); the impossible trial receives marking \(0\) at that point. Ordinary marking agreement removes it through the graph. A work cutoff never licenses an exclusion.
    All finite required roots start at generation zero. Point search checks global dead ends, then global forced placements, then earliest-generation branching. The code includes tiny controls and the first two full domain audits per point arm. Their results were not returned by these failed jobs; no actual conformance pass is claimed.
