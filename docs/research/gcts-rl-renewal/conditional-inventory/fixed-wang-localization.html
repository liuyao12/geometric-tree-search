A tape cell is either a plain symbol or a symbol carrying the unique head state. The deterministic local successor is \(F(a,b,c)\), where the old left, center and right cells are \(a,b,c\). Separate tagged color channels distinguish configuration values \(V\) from old-neighborhood pairs \(H\).

Horizontal agreement

Matching adjacent pair labels reconstructs the same old row: a tile cannot read one center symbol while its neighbor reads a different copy. The left and right ghosts are supplied by persistent frame columns.

Vertical agreement

The output configuration color of one computational row is the input configuration color of the next. A single deterministic transition supplies both the departing head's write and the arriving head's state.

The Source omits neighborhoods containing multiple nearby heads. That local restriction alone does not exclude distant heads. Exactly one head must come from the top input framing and be preserved by the deterministic step induction.

No cap tile admits a rejecting head. Moves through either side wall are blocked, so the only head cannot disappear outside the finite region. Accept and reject states are normalized to stationary loops. This allows time padding after acceptance, while rejection persists and cannot close an accepting cap.

\[n\ge 1,\quad H\ge 0,\qquad \text{width}=n+2,\quad\text{height}=H+2.\]

The rectangle contains the input selector row, \(H\) computational rows and the cap, with two side-wall columns. Zero computational steps can accept only if the prescribed start state is already the accepting state. A finite region that is too narrow is an insufficient window, not a global nonacceptance proof.

\[\text{one tile: }t(2x+1,2y+1)=12,\qquad m_N=N,\ m_E=E,\ m_S=S,\ m_W=W.\]

Every finite board cell center is a required root with generation \(0\). Edge midpoints are not occupancy roots. An assigned color ID \(0\) remains an assigned value; it is different from an absent assignment. The complete candidate universe is every palette type at every in-board cell, using translations only, with no rotations or reflections.

The adapter Source returns values and square vertices. A future search integration must still preserve complete point–candidate incidence, global dead-end checks, global forced moves, earliest-generation branching, exact rollback and full primitive fallback. No such engine integration or run is demonstrated on this page.

The correspondence target, and what remains open

\[\operatorname{Tile}_{W_M}(B_M(I,H))\iff\exists C_0\in\mathcal L_M(I):\ C_H=\operatorname{Step}_M^H(C_0)\text{ stays inside the walls and has one accepting head}.\]

This is the proposed finite machine correspondence to review, not a proved theorem from a compiler run. The query, dimensions and fixed fields determine the boundary. The certificate symbols are an internal existential choice of the tiling; a known proof is not supplied by this specification.

A machine configuration is not a mathematical proof line. A future proof reader must decode the accepted certificate band using an exact codec and source mapping, then independently check the recovered primitive proof. It must not narrate every tableau row as a logical inference.

For recursively axiomatized theories, a fixed wrapper must verify finite axiom-enumerator witnesses and preserve the declared theory and goal. Quantifier hygiene and proof-reference rules remain explicit obligations. Aperiodicity is a different property; it does not supply this input, acceptance or proof-decoding contract.

Failure at a finite width, height or resource cap does not show that no larger accepting witness exists. Any unbounded proof-search interpretation needs a justified fair outer region schedule and retains the general undecidability limits.
