What the failures tell us

Registry capacity is a shared bottleneck. For case \(1\), the compiler completes its guard requests, but the complete lemma inventory request returns unknown_space_budget. All three arms reach the same registry gate before either geometric or symbolic search. The saved native peak RAM is not the registry tape-space budget; these are distinct limits. This result cannot rank the search strategies.

Proof discovery transfers farther than the bounded implementation does. Case \(2\) retains three complete, native-accepted proofs, each using two essential universal instantiations and one essential generalization. The full selected point regions and proof rows agree with their saved checks. The three completed models, compiler results, inventories and initial states are identical within this case. All three conservative memory sums exceed the declared limit, so these are diagnostic proofs, not bounded benchmark successes.

Fixed hints are not consistently better. In the diagnostic diagonal case, hints-off GCTS takes \(60\) tile placements and fixed-guidance GCTS takes \(61\), with one backtrack. Direct symbolic search takes \(12\) row extensions. The units are different. A matching lemma hint on a successful path demonstrates use; it does not establish that the hint or geometry caused an improvement.

The curried case remains unresolved. Symbolic search consumes its \(5{,}000\) row-extension budget. Hints-off and fixed-guidance GCTS reach their search-time cutoff after \(2{,}030\) and \(2{,}739\) tile placements, respectively, and also exceed the memory limit. Their complete compiler, inventory, model and initial-state projections match within the case. UNKNOWN does not mean the statement is false, that no bounded proof exists, or that the search language is complete.

Research assessment: this is useful negative implementation evidence, not a competitive proof-search result. The first practical priorities are to understand native registry growth and reduce exact representation and trace-retention costs. A future compact representation must preserve all alternatives, full markings, exact rollback and independent final checking. Its resource savings remain unmeasured.

What was held fixed

All arms use the same \(12\)-row language, \(2\) syntax-expansion rounds, the same admitted primitive and lemma command language, complete four-template lemma policy, all admitted exported interfaces, unchanged native rules and the existing deterministic priorities. Within each case, the full compiler, inventory and point model are common wherever construction completes. Different cases naturally have different catalogs. The symbolic arm retains and pays for common point-model construction, then checks its candidate projection; it is not a standalone symbolic prover cost measurement.

The GCTS arms maintain complete frontier incidence, global DEAD then FORCED propagation, earliest-generation branching, full primitive fallback and exact rollback. Fixed hints order validated clusters; they do not delete alternatives. The direct symbolic control is an explicitly specialized chronological proof search, with different partial states and a different scheduler. Conditional equality of completed finite proof words does not imply identical search behavior.

GCTS allows \(5{,}000\) tile-placement attempts and symbolic search allows \(5{,}000\) row extensions, each with a nominal \(30\)-second search budget.
