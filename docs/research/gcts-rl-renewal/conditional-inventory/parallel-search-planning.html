Where the symbolic extensions went

\(4677\) extensions at zero-based row \(10\), or human line \(11\). \(323\) elsewhere. No extension reached the final row. This shows search concentration, not the effect of a tested repair.

The backward-distance heuristic treats dependencies individually. It can give a short distance to the legal instantiation licence

\[(\forall xR(x))\rightarrow R(x),\]

even though using that licence requires the still-unproved universal. In this retained trace its distance is \(2\), while the curried theory axiom’s is \(4\). The licence is a valid formula; its antecedent is not thereby an available fact. The issue is ordering, not unsound proof admission.

Proposed repair: compute a generic support estimate that respects all premises and rejects circular support within a proposal. Use it to rank existing choices, with full fallback. Supply the same semantic heuristic to the conventional control. Until measured, this is a search hypothesis rather than a speedup result.

Reusable lemmas exist; recursive receptor closure is missing

The current library mechanically abstracts searched proofs into formula-valued families, specializes their interfaces against the declared finite basis, and registers their complete expansions in dependency order. Each ground definition still requires native acceptance. This does not yet provide a general binder-aware theorem-schema language.

The current proposer assembles complete single rows, plus small sampled fragments. It does not recursively fill those rows’ unresolved premise receptors. In the retained curried fixed-advice run it started \(350\) hints and recorded \(120\) completed-phase node visits; \(194\) selected hints were lemma rows. Completed-phase visits can revisit a hint and are not counts of distinct proved lemmas. All \(8\) admitted interfaces in this case were first-level instances; no second-level theorem inventory was demonstrated. There was no accepted target proof.

Global dead ends still precede forced moves, followed by the earliest generation. Cluster execution follows those decisions and rolls back exactly. Proposal failure or a bounded support search supplies no pruning theorem. Learned long-range markings would need a separate declared justification before eliminating candidates.

The first implementation should separate support ranking from multirow composition. Comparing both with an equivalent symbolic heuristic will reveal whether any improvement comes from semantic guidance, cluster reuse, the point graph, or their combination. New RL should be judged only after a trained policy, its training cost and held-out evaluation exist.
