One implementation, two independent checks

The parallel team divided implementation, soundness review, and benchmark design. The actual experiment ran serially under the original resource limits. Both abstractions use one inventory entry per fresh atom-template class, preserving the same port sharing and multiplicity. Principal structures that coincide remain separate paired entries.

The new abstraction assigns a formula variable to each row and each receptor. For a modus ponens step with antecedent row \(a\), implication row \(i\), and result row \(v\), it imposes

\[X_i=\operatorname{Imp}(X_a,X_v).\]

An occurs-checked unifier solves all rows together. Residual variables can stand for whole first-order formulas. A production certificate and an independently written inferencer check each acquired fragment. The family is principal for that fixed graph and its declared formula-sharing quotient. It makes no claim about alternative port splittings or shortest proofs.

This applies established unification and principal-type ideas to the cluster interface; it is not a novelty claim about type inference. See Robinson (1965), section 5 and Hindley (1969), introduction and section 3. Each concrete use still expands to ordinary proof rows.
