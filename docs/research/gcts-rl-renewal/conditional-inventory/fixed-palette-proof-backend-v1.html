What is fixed, and what is supplied by the instance

The palette contains \(100\) ordinary square Wang tiles. Only translations are allowed; there are no rotations or reflections. The north and south colors each have two components: an operation and a bit. West and east carry a bit.

The operation component is pinned at every vertical edge, including interior edges. This is a program template supplied with the problem, not a computation specified only on the outer boundary. The point implementation splits operation and bit into separate marked ports or components; it never uses a wildcard tuple. The palette is not claimed to be aperiodic.

A large patch is saved as a compressed circuit certificate with CROSS ribbons and an exact expansion argument. The viewer expands at most \(12\) columns by \(6\) rows on demand. The large proof and counter patches were not searched by a GCTS frontier graph. The separately identified five-cell Wang example was searched directly. Any earlier semantic proof search is identified separately in the saved evidence.

Validation and algorithm conformance
Qualification covered all \(1{,}024\) raw bit assignments across four tiny producer-checker goals, \(24\) tiny counter-state assignments, literal routing checks and \(8\) corruptions rejected by both independent tiling checkers. Self-references in both real proof witnesses and changed final counters in both accepting traces were also rejected.
The unchanged GCTS engine searched two semantic proof inventories and two five-cell Wang instances. All \(65\) emitted event states received a complete recomputation of global candidate legality and both graph directions. The checks cover distant marking dependencies, global dead and forced decisions, and earliest-generation branching. Exact entry-state restoration was checked after each search. Separate passive checks validate the placement generations.
The successful supervised study took approximately \(1.77\) seconds including compilation, search, checking and evidence writes, with a native child peak of approximately \(65.2\) MB on this host. This is a mechanism check on small examples, not a benchmark comparison. The fixed tile patches are large circuit encodings; their efficient compressed verification does not establish efficient proof discovery. No RL policy is trained in this milestone.
The arithmetic example uses one addition axiom without induction. The incidence example uses a supplied closed uniqueness axiom and common-point hypotheses in symbolic first-order logic. The diagrams depict their checking circuits, not physical Euclidean constructions.
What the fixed palette establishes
For every finite NAND circuit \(C\), construct the selector template and boundary pins described here. A completed patch exists with output bit \(1\) exactly when some assignment to the circuit’s free inputs makes \(C\) accept. For a fixed input assignment the bit completion is unique. The proof is an induction over gate rows: crossings preserve stored bits, READ and NAND compute the current result, and WRITE stores it in a fresh column.
A manually proved compiler cluster family is now available; it was not learned or mined in this experiment: a CROSS ribbon has arbitrary positive length and interfaces specified by a horizontal bus bit, a vertical bit vector and the next row’s selector vector. Its validity follows from all \(20\) CROSS tile types, not a sample of ribbon lengths. The full north and south colors need not be equal; the bit component is preserved.
Applying the construction to bounded traces of a universal two-counter machine gives a uniform family of finite encodings of arbitrary computations as the time and counter bounds increase. Minsky’s primary universality result uses encoded inputs; it does not promise efficient simulation. See Minsky (1961), Theorem Ia. This is a universality construction with interior program pins. It is neither an aperiodicity result nor a single finite circuit performing every computation.
The present proof frontend is narrower: admitted finite formula/rule catalogues become data in a bounded producer checker. The catalogue is frozen before search and includes every producer in that basis, including alternatives the successful proof never uses. A universal first-order parser, substitution checker and logical kernel have not yet been lowered into the NAND checker. They remain an explicit next obligation.
Construction and limits
With \(I\) inputs and \(G\) topologically ordered NAND gates, the macro grid has \(W=I+G\) and \(H=G\). In row \(y\), READ visits the smaller input index, NAND visits the larger, and WRITE visits output column \(I+y\). Equal input indices use NOT and WRITE. Other cells are CROSS, and the bottom next-operation color is CROSS.
The fixed palette checks a bounded circuit computation with an interior operation template. This milestone does not establish a compiler for full first-order logic, Peano arithmetic or Hilbert geometry, a new general theorem, or a proof-search speed advantage.
