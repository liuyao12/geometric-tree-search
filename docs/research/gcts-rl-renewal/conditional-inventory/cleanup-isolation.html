Separate mathematical track · Source only

An explicit Wang tile, with visible marking layers

\[T(a,b,c)=\bigl(\operatorname{cell}(b),\operatorname{pair}(b,c),\operatorname{cell}(F(a,b,c)),\operatorname{pair}(a,b)\bigr)\]

The tuple lists north, east, south and west. Horizontal overlap forces consistent old neighborhoods; vertical matching carries the updated cell to the next row. The full specification gives every frame and acceptance-collector tile, exact boundary words, point markings, the partial update rule and both directions of the finite correspondence argument.

For one fixed declared deterministic machine \(M\), a complete one-head initial word \(C_0\) of width \(W\), and exact step count \(H\), the framed board has a tiling exactly when the machine has a legal accepting run of exactly \(H\) steps within that strip. This is an informal reviewed argument; the compiler has not been executed or machine checked.

The construction uses ordinary finite square Wang tiles and translations only. Its point encoding places unit occupancy at each required center and edge markings at shared midpoints. It neither establishes aperiodicity nor needs it for this finite statement. Finite computation rectangles are established in the primary literature; see Jeandel and Vanier, Slopes of Tilings, Section 2.3. That paper does not verify our compiler.

What still separates this from a proof system

A tableau row is a tape configuration, not a formula in a human proof. To support one tile set for arithmetic and symbolic Hilbert geometry, we still need to freeze one full first-order proof checker, its lossless statement/certificate codec, its faithful machine implementation and the resulting palette before theorem instances. The current meta-compiler accepts a machine parameter; that alone is not a fixed universal proof-checker artifact.

The future search must discover the certificate or derivation. A supplied proof accepted by a checker does not count as discovery. Human-readable logical rows need an explicit checked decoding layer. Receptor families and clusters must expose their exact premises and expand into primitive checked steps. No learned marking, trained policy, useful lemma transfer or current GCTS graph/scheduler/rollback qualification follows from this construction. Read the independent Source and mathematical review.
