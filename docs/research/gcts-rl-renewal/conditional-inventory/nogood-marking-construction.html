From a certified failure to long-range markings

A small chain of auxiliary tiles can encode a forbidden combination of placements. Its markings read the original tile choices, remember whether every forbidden choice has matched so far, and reject the all-matched ending.

Status: this is a finite construction and an informal projection argument. It has not been compiled, executed, or checked by a formal kernel. The current search implementation under development stores certified clauses directly. That cache is not this marking gadget. No performance, learned-policy, or universal fixed-palette result follows from this note.

What a reusable failure says

Work with a finite, translation-only Wang problem. Each required center receives exactly one tile from a full palette \(T\). Original edge-midpoint markings and permanent boundary pins must agree. A candidate placement is \((p,u)\), meaning tile \(u\) at center \(p\).

\[C=\{(p_1,u_1),\ldots,(p_k,u_k)\},\qquad \neg\bigwedge_{i=1}^{k}\operatorname{Chosen}(p_i,u_i).\]

The certificate being implemented finds an unfilled required center \(q\), distinct from every support center. For every original tile at \(q\), it supplies an actual assigned midpoint conflict with a permanent pin or a member of \(C\). Then no valid tiling can contain all of \(C\): whichever tile fills \(q\) would disagree with one of those assignments. A domain emptied by a branch exclusion alone supplies no such certificate.

Here support placements are selected, mutually compatible, and have distinct centers. The independent checker must recheck the full original palette, witness values, translated coordinates, pins and support placements against the current complete instance. A machine name, scope label, or matching hash alone is not that proof.

Four visible layers

Original edge constraintsTile-choice channelPrefix-state channelAnchor channel

Use fresh marking channels, disjoint from the original edge channel. Lift each original tile by adding a center marking that records its literal tile ID, and a center anchor with the base role. These assignments do not restrict the original tilings: only the tile occupying that center assigns its choice there.

Choose distinct fresh auxiliary centers \(r_1,\ldots,r_k\), outside the original region, and distinct state points \(z_0,\ldots,z_k\). None is an original required center; all may be placed at integer coordinates with auxiliary centers in \(2\mathbb Z^2\). The enlarged admissible-origin set and required-center set are both exactly the original centers together with those auxiliary centers; no other translation origins are allowed. Only translations in \(2\mathbb Z^2\) are allowed. Every allowed prototype assigns its own center anchor. Pins on that channel allow base tiles at original centers and only auxiliary role \(i\) at \(r_i\).

For each auxiliary role, each original tile ID and each incoming Boolean state, include a unit-center tile with these markings:

\[A_{i,v,a}:\quad t(r_i)=1,\qquad m_{\rm choice}(p_i)=v,\qquad m_{\rm state}(z_{i-1})=a,\qquad m_{\rm state}(z_i)=a\land[v=u_i].\]

Each displayed assignment is a finite offset from the auxiliary tile's own center, so it defines a translation-only tile prototype. Its center anchor is the unique auxiliary role \(i\). All symbolic channel values can be encoded by finite integer labels. State endpoints are pinned to:

\[m_{\rm state}(z_0)=1,\qquad m_{\rm state}(z_k)=0.\]

Markings at remote points have no positive tiling support. They enforce equality only where that channel is assigned. The chain reads the actual center tile IDs through the choice channel, rather than consulting an informal notion of a tile being absent.

Why projection preserves exactly the intended tilings

Finite extension lemma

For a nonempty support with distinct original centers, an original valid tiling extends to the enlarged instance if and only if it does not contain all of \(C\). The extension, when it exists, is unique once the original tile choices are fixed.

Project an extended tiling. Anchor pins forbid auxiliary tiles at original centers and forbid base tiles at auxiliary centers. Removing the auxiliary tiles and fresh channels therefore leaves exactly one original tile at each original center, with every original edge and boundary constraint intact. Let \(v_i\) be its tile ID at \(p_i\). Choice agreement forces the auxiliary tile to read \(v_i\). State agreement gives:

\[s_0=1,\qquad s_i=s_{i-1}\land[v_i=u_i],\qquad s_k=0.\]

Induction along the finite chain gives \(s_k=\bigwedge_{i=1}^{k}[v_i=u_i]\). The final pin excludes the all-matched combination.

Extend an allowed original tiling. Lift its base tiles with their own IDs and base anchors. Compute the unique prefix states from those IDs. If at least one forbidden choice is absent, the final state is zero. Choose \(A_{i,v_i,s_{i-1}}\) at each auxiliary center. All fresh choice, state and anchor assignments agree; original constraints are unchanged. Every newly required center has exactly one unit tile.

For an empty support, the certified clause says the original instance has no tiling. Use a separate fresh required center with an anchor value assigned by no tile type, yielding an unsatisfiable auxiliary component. Every allowed tile must still assign a different center-anchor value: leaving that channel unassigned would not conflict with the pin. The chain formula above is reserved for the nonempty case.

For multiple clauses, use separate state channels or separate state-point sets, distinct auxiliary anchors and centers, and the same base choice channel. Each auxiliary strip then enforces its own clause. If every clause has a valid primitive certificate, every original tiling already satisfies those clauses, so projection and extension preserve the original solution set. This set consists of tilings with literal base tile IDs; geometrically identical prototypes remain distinct choices unless an explicit quotient is separately justified.

This construction adds a fixed auxiliary strip for each concrete support. A receptor family that instantiates such strips for many logical interfaces would additionally need substitution, scope and primitive-expansion certificates. The useful research question remains whether the representation helps discover reusable structure and reduces total search cost after all certification, graph maintenance and output costs are counted.
