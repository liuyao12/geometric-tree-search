Proof families with explicit receptors

A finite grammar generates formula families and their possible premise receptors before search begins. The same arithmetic and symbolic incidence assertions from the previous study test the new catalogue, reusable lemmas, cluster proposals and a fresh ordering policy. All four strategies receive the same eligible lemma inventory, actual catalogue and row bound for each case.

The scope of the experiment

This is a new finite catalogue, with a different grammar and some larger row bounds. Results do not establish a semantics-preserving speedup over the previous catalogue. The assertions are reused regression and transfer cases, held out from this run’s policy training; they are not globally unseen problems. Catalogue authors have seen earlier failures. Earlier target proofs and outcome labels are not generator or policy inputs.

The base model has unit occupancy at each symbolic proof row. Formula-valued markings can reach earlier rows, where they act as premise receptors. All required rows start at generation zero. Tiles have a fixed orientation; only translation along rows is represented. These are symbolic point tiles with remote markings, with a problem-specific finite catalogue. A single fixed literal Wang palette remains a separate open construction.

The arithmetic fragment contains the defining equations for addition, without induction. The geometry fragment contains explicitly declared incidence axioms in a symbolic language with point, line and incidence predicates. No drawing or coordinate geometry enters the checker. A coarse lemma row is a higher-level construct: its row bound is not equivalent to a bound on the expanded primitive proof.

Exhausting this finite catalogue establishes only a finite-model result. Resource limits and expansion limits remain unresolved. Template mining uses connected donor proof subgraphs of at most four nodes. The learning pilot is an episodic tabular contextual bandit, with the current required formula's outer connective as context. It does not establish unrestricted cluster invention, full first-order completeness or an RL advantage.

Frozen inputs, limits, complete attempts and custody


Generate assertions without generating every context
Core assertions start with input subformulas and bounded universal instantiations over fixed input terms. Generated instantiation-axiom syntax does not feed the core again. Equality templates come from atomic input formulas; both filled endpoints must already be core assertions. Goal receptors and bounded propositional bridges allow possible premises to be connected later by search. Every rule witness and every reference choice in the resulting finite catalogue is available to all strategies.
These restrictions can omit useful equality intermediates. Lower construction cost alone is insufficient: the results must show which proofs the catalogue can express and which searches actually find them. Refusal to finish generation exports no usable catalogue.


Why a completed row tiling is a proof


This is a mathematical argument about the encoding, written by the researcher. It is separate from the theorem certificates discovered by search below. The finite catalogue is generated automatically from assertions and a declared grammar; this argument does not supply a target proof.


Fix a closed first-order theory \(\Gamma\), a finite set \(\mathcal F\) of literal formula trees, and a finite set \(\mathcal A\) of independently checked zero-premise rule witnesses. Let \(n\geq1\) be the number of proof rows and \(G\in\mathcal F\) the desired conclusion. Formula colors are injective encodings of literal trees, not colors for logical equivalence or implicit renaming.


Use the point domain \(\mathbb Z^2\). Row \(i\), for \(0\leq i<n\), has a required occupancy point \(s_i=(0,i)\) and an output marking point \(o_i=(1,i)\). A candidate places unit occupancy at its own \(s_i\), assigns its conclusion color at \(o_i\), and assigns each premise color at the corresponding earlier output point. Missing markings are unconstrained. All row obligations are explicitly activated roots of generation \(0\).

A zero-premise tile carries a witness in \(\mathcal A\). A modus ponens tile for \(A\) and \(A\to B\) outputs \(B\) and reaches back to the two indicated earlier rows. A generalization tile outputs \(\forall x\,A\) and reaches back to an earlier \(A\). Admit only formulas in \(\mathcal F\), all syntactically fitting rule instances, and references \(j<i\). At the final row admit only conclusion \(G\). Candidates are translated to their row; there are no rotations. The square drawing is a reader view of this explicitly stated unit-point model, not an additional legality test.


Encoding theorem. Exact unit occupancy and agreement of these markings hold precisely for the encoded, exactly \(n\)-line proofs from this finite inventory. In particular every such completed tiling proves \(G\) from \(\Gamma\).


    

  1. Exact occupancy selects one rule instance for each row. Its output color is fixed at the corresponding \(o_i\).

  2. At a reference to an earlier row, marking agreement and color injectivity force the earlier conclusion to be exactly the required premise. References to one row with different required formulas conflict and cannot be selected.
    3. 

  3. Induction over row index proves soundness. A zero-premise witness is already checked. Modus ponens uses two established premises. Generalization uses an established formula; the assumption that the theory axioms are closed makes the usual free-variable restriction on undischarged assumptions immediate. Strictly earlier references exclude circular support.
    4. 

  4. Conversely, a proof whose formulas, zero-premise witnesses, and rule references belong to the declared inventory places the corresponding tile in each row. Each premise equals its earlier conclusion, so all markings agree, and every required occupancy point is filled exactly once.
    5. 



Exact rows and upper bounds. In this inventory every nonempty proof begins with a zero-premise witness, and its translated copies are available at every row. A proof with \(k\leq n\) lines can therefore be padded to exactly \(n\) lines: prepend \(n-k\) copies of a zero-premise witness and shift every original reference by \(n-k\). The final conclusion is unchanged and every reference remains earlier. Thus the point model and an at-most-\(n\)-line control have the same existence question for this inventory, although they may have very different search costs. A padded certificate is a derived construction; it is not evidence that the point search found those placements.


This completeness statement is relative to the declared finite inventory and exact row count. Exhaustion does not refute provability in the original theory. A resource-limited catalogue is not a complete inventory and cannot justify a dead-end or forced-move claim. The implementation therefore exports no usable catalogue on refusal.


Each rule tile in this encoding assigns at most three output/premise points. Checking marking agreement can use an array indexed by row and work proportional to the total stored assignments and their formula-color bytes; it need not compare every pair of tiles. Checking the logical rule witnesses and expanded original-theory proof remains a separate, measured cost. This argument establishes neither a fixed finite adjacent-edge Wang palette nor completeness for first-order logic.

Does GCTS contribute?


Remaining research goals
  1. Broaden useful formula and equality families under explicit finite grammars, with complete candidate enumeration and checked original-theory proofs.
  2. Learn and compose reusable lemma families with explicit receptor conditions; measure total costs against the same-information conventional control.
  3. Separate numerical policy changes, executed choices, reduced branching and actual speedup. Fresh training weights alone are not evidence of an advantage.
  4. Reach stronger arithmetic and Hilbert-style geometry theorems, including explicitly encoded induction when added to the theory.
  5. Construct a single fixed finite tile palette with a proved accepting-boundary correspondence.
  6. Retain the broader turtle and Penrose tiling objectives, including geometric failure markings and certified infinite constructions, while following the current priority on symbolic proof search.
A model to test next: grow proof obligations


Unimplemented research proposal. A flat strip makes search choose where premises will sit among many empty rows. A growing proof tree could put those premises at explicit receptors instead. This would change the search model and requires new implementation, independent verification and fair comparisons. It is not a result of the present experiment.


Take the nodes of a finite binary tree as anchored sites \(V_D\), with maximum depth \(D\). Every non-root site has a unique parent; the root has none and depth \(0\). Allowed placements are explicitly indexed by their anchor site; arbitrary geometric translations and alternative parents are excluded by this model definition. This is an anchored point model, not a fixed translation-invariant Wang palette.


Seed only the root with occupancy \(\tfrac12\) and its requested formula marking. A rule instance anchored at \(v\) contributes \(\tfrac12\) at \(v\) and \(\tfrac12\) at each of its premise-child sites. Exclude a rule if any prescribed premise child lies outside \(V_D\); sites at depth \(D\) therefore admit only zero-premise rules. A zero-premise witness has no children; a unary rule uses the first child; a binary rule uses both. Mark the anchor with the conclusion formula and children with required premise formulas. All arithmetic can use integer capacity \(2\) and unit contributions.


Begin with only the root active. Every selected placement must meet the active frontier; activate new sites exactly from its positive support. Unused sites of \(V_D\) are not required. Activation, generation and the complete frontier/candidate graph must roll back exactly. Initially an exposed obligation has occupancy \(\tfrac12\). Its unique parent is already filled, so another rule at that parent would overfill it. The only remaining way to complete the obligation is a producer anchored at the obligation itself, with a matching conclusion. That producer fills it and exposes its own premises. This invariant starts at the seeded root and propagates by induction.


Consequently, a finite completion of all activated obligations describes a well-founded proof tree, and any allowed proof tree of depth at most \(D\) gives such a completion. This statement assumes the site anchoring, unique-parent incidence, fixed rule-child convention and checked logical witnesses just described. Removing those conditions could admit unintended fillings. For an executable bounded model, declare a finite formula/rule-witness inventory; completeness is relative to that inventory and depth bound. It covers the activated proof patch, not every unused site of \(V_D\) or the plane.


The reference GCTS scheduler would still check every global dead end, propagate every global forced move, then branch at the earliest generation. Here generation would track actual proof growth rather than every possible row beginning at generation zero. For a finite connected rooted rule patch, viewed without its incoming parent half or root seed, completed interior sites have full occupancy and the patch root and unfinished receptors have half occupancy. An arbitrary disconnected collection may have several boundary roots and does not have this single-root interface. That offers a concrete interface for a family of clusters whose shape depends on the receptor.


The model duplicates shared subproofs unless a certified lemma tile replaces them. It therefore needs separate accounting for tree size, distinct facts, primitive expansion and all validation costs. The proposal predicts no speedup or learning benefit. Its purpose is to test whether proof dependency structure gives GCTS a more useful role than choosing reference positions in a flat strip.
