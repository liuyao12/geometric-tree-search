Why the boundary is constrained
The finite horizontal states are PRE, ACTIVE, PAD and POST, each carrying an unseen/seen head flag. Bits stay active; a terminator enters padding; padding emits only blanks; the fixed suffix exits to POST. The right frame requires one head and a closed certificate band. Initialization north colors are never emitted by a south edge, so these tiles cannot appear below the pinned top row.
For alphabet size \(b\), the initializer adds \(9b+16\) tiles and \(2b+11\) colors. For tape width \(W\) and exact physical horizon \(H\), the framed board has size \((W+2)\times(H+2)\). Every palette tile remains available at every declared origin. The implemented preflight counts the full retained palette before attempting materialization.
The calibration exhausts the declared top-strip populations. It does not execute a whole physical machine, run the generic GCTS point-search engine, or search for a theorem. Postfix-invalid bitstrings remain tile-admissible; the actual BOOT parser must reject them.
