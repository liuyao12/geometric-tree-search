What the board would ask the search to find

  1. Fix the entire program and public statement on the boundary of the initialization row.
  2. Leave a certificate interval free. Local selector tiles permit a binary word, its terminator, then blank padding.
  3. Require each subsequent row to encode a machine transition, using overlapping neighbor-pair labels.
  4. Require an accepting collector at the bottom of the declared finite horizon.

Reduction to the point-value model

Use \(\mathbb Z^2\). Each tile has \(t(0,0)=1\) and markings at \((0,-1),(1,0),(0,1),(-1,0)\). Required centers are \((2x,2y)\); allowed translations are even integer displacements. Exact coverage chooses one tile per center, and shared midpoint values enforce Wang matching. Boundary midpoint pins are part of the problem.

This construction is a reduction to the point model, not a tested search engine. Complete frontier incidence, global dead and forced checks, generation ordering, exact rollback, validated cluster expansion and base fallback remain requirements for a future GCTS search.
