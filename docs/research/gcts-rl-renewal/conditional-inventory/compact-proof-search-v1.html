What the search actually found

The first two targets receive no proposed proof body: the search chooses the rule byte from its full byte domain. Later targets may receive a candidate from generic rewriting, rule enumeration, propositional closure or previously discovered inventory. These symbolic generators do substantial work; their contribution is recorded separately.

Each of the two raw controls has only one free byte: the rule at offset 2. All other positions follow from the given target and the minimum format length. These are deliberately tiny searches.

These are authored controls, not a held-out benchmark. Arithmetic uses two recursive addition axioms; geometry uses a symbolic incidence axiom. Full Peano arithmetic, induction search and full Hilbert geometry are not established. The geometry predicates \(\operatorname{Point},\operatorname{Line},\operatorname{On}\) are uninterpreted symbols constrained by the stated axiom; no coordinates or geometric diagram enters the checker.

A rejected choice becomes a geometric constraint

Byte positions are required points. Each byte candidate occupies its point and assigns a value at a separate marking point. A failure witness occupies another required point and reaches the byte marking. Equality of assigned values enforces the constraint.

Positive occupancyMarking layerFailure-witness occupancy

For a rejected joint assignment \(b_{i_1}=a_1,\ldots,b_{i_k}=a_k\), the auxiliary point has candidate families witnessing at least one inequality \(b_{i_j}\ne a_j\). Its byte markings can take all values except the forbidden value. Thus a complete point tiling exists exactly when the selected bytes avoid the rejected joint assignment.

Only a completed normal rejection can generate a constraint. Time limits, heap limits, VM faults and partial traces produce no learned negative. The construction is scoped to the same program, theory, goal and byte capacity; it rebuilds the point model after a rule change.

This is certificate-derived constraint generation. It is not the reference cold pair-corona marking learner, and its additional witness families are not a single fixed primitive tile palette.

Actual square tiles: the compact computation control

A separate compiler turns a finite nondeterministic tape machine into a finite square Wang palette. Tiles translate without rotation or reflection. Colored sides encode exact matching values; an optional second layer records head information.

The head layer is drawn with a small offset to show its separation from the edge layer. Purple remote marks share a point with the neighboring source tile’s input-head mark. The exact support is shown below the diagram.

A complete two-step row tiling from the control
Each row is one machine step. Every shown side match and both marking layers were checked in the saved finite control. This board simulates the tape machine, not a mathematical proof.


The compact construction uses copy, wall, stay, two moving-source and two receiving families. The tests compare whole configuration sets through bounded layers, not just a selected successful path. They establish only the reported finite controls, not universal proof execution.


What this says about GCTS


The experiment separates three jobs: generate a candidate proof, represent rejection constraints geometrically, and check the proof. A geometric representation can share the same information as an ordinary constraint solver. Its benefit has to appear in measured search behavior or useful reusable structure; expressiveness alone is not evidence of an advantage.




No trained reinforcement-learning policy participates in this run. The conventional control uses the same goal boundary, proposals, checker and certified constraints. It is a simple finite-domain control rather than an optimized SAT solver or a competitive automated theorem prover.


The next useful comparison should test unseen theorem families, genuinely reusable receptor interfaces, acquisition cost and both optimized conventional search and learned proposal policies. A literal fixed Wang proof palette remains a separate implementation obligation.
