Source-derived live pressure

The main common suspects are millions of small point/assignment objects and reverse-index set entries. Each recursive child also copies complete state and incidence containers; parents remain on the stack. The full explored census trace stays retained until return. These mechanisms are visible in Source, but no RAM amount is assigned to them here.

The driver retains model-record wrappers and repeatedly hashes a full JSON encoding. It shares immutable mark tuples rather than deep-copying the complete model twice. The final raw-region check reparses the complete result. Native tables, loaded Z3 and possible recursive closure/allocator retention are additional unprofiled contributors. The nominal serialization flush threshold does not cap the size of one large string part.

A compact representation that keeps the proof-search contract

  1. One immutable literal catalog with stable point/candidate/formula/command IDs and contiguous support/dependency arrays. IDs are a bijection over the full original literal keys and typed values, with original t/m preimages and source epoch retained. Do not merge distinct inventory/provenance identities. Use exact presence masks: assigned \(0\) and assigned \(-1\) remain real values; missing is separate. Keep all \(7,441\) candidates and all off-frontier marking dependencies. CSR/packed arrays may replace Python container overhead, not candidate coverage. No current live-byte estimate. For this fixed catalog uint32 IDs suffice, but generic growth must have explicit bounds/extension and cannot recycle IDs across epochs/rollback.
  2. Lossless transition trace with a catalog once, node/parent IDs, full initial state, delta events and periodic complete checkpoints. Each node records exact selected candidate, changed t/m assignments/reference counts, incidence additions/removals, generation/root metadata, ordered alternatives, failed-child cursor and hint/event references. Preserve all failed branches and UNKNOWN boundaries. Do not replace full candidate truth by top-k, hashes or hint members. An independent verifier must be able to reconstruct every complete census from the full catalog and literal state, check DEAD before FORCED before earliest generation, and inspect the whole fallback order. For scale only, \(932,967\) stored candidate IDs have a \(3,731,868\)-byte uint32 element body before container/point/node metadata and the catalog. This is a representation arithmetic example, not measured RSS or a frozen format. Delta encoding may save more but is not yet specified/certified.
  3. Transactional state/incidence trail or persistent copy-on-write storage instead of deep sets at every child. Trail totals, explicit marking presence/value/reference counts, selected set/order, tile/point generations, roots, complete domains/reverse edges, branch cursor/exclusions and any inventory version. Restore the complete semantic state exactly; observational counters stay separate. Shared candidate incidence must stay one coherent graph. This is the largest correctness risk; current copy-based rollback is the reference. Requires independent forward/inverse reconstruction and unchanged selected/failed decision traces before performance claims.
  4. Stream full semantic identity/custody and artifact output; avoid duplicate model-record wrappers once the immutable representation is actually enforced. Keep before/after effective full model equality and exact raw Source/runtime/native custody; do not substitute object identity or a hash without literal preimages. Native certificates and whole-point verification still consume complete reconstructible data. Chunk large string serialization or place full SMT-LIB in an exact content-addressed sidecar, with atomic manifest and complete size/hash/EOF checks. Changing monolithic packet structure needs a new protocol/Source review. Rejected/partial/truncated output remains UNKNOWN/unavailable; no proof salvage. Full sidecar set must be present before positive admission.
  5. Intern complete canonical word spans as exact symbols instead of materializing one object per byte. An internal packed span representation can preserve every old byte-point value through a literal expansion dictionary. Collapsing a whole span to one abstract m-value is a different point representation and needs an explicit equivalence argument. In this grammar whole word assignments have a distinct \(256\) terminator; exact symbol equality is safe only for checked complete-span writes. Partial/sparse overlays must use the original pointwise path. Do not silently call a quotient model the unchanged physical point data; all compatibility graphs and original expanded t/m preimages must independently agree.

Every proposal is prospective. Keep complete point/candidate incidence, off-frontier dependencies, global DEAD then FORCED then earliest generation, exact full rollback, all base alternatives, and native checking. Hashes or selected hint members cannot stand in for a complete domain. A dictionary-backed trace must retain full literal preimages and allow an independent checker to reconstruct every census and failed branch.

Recommended order

Finish the direct symbolic comparison now. If later authorized, test immutable packed support/dependency data and a lossless reconstructible trace first. Trail-based rollback is a larger correctness change and should follow only with independent forward/inverse verification. Gzip publication packaging reduces downloads; it does not reduce the current search heap. No speed, RAM reduction or additional theorem is claimed.
