What these markings mean

This is certified unary failure tabling represented by literal point markings. A key names one literal formula, remaining proof height and fixed theory/basis scope. It is not Turtle pair-corona inference, a learned dynamic joint constraint or an unrestricted nonprovability result. Only requested certified absences receive seed marks; internal negative DAG nodes are supporting evidence.

Storing and reusing subgoal results is established in tabled logic programming; see the official XSB manual on tabling. Our unary failed-port table is an encoding comparison, not an invention of memoization or a claim to reproduce full XSB/SLG semantics. E, Vampire and XSB were not run; no standard ATP comparison is made.

The ordinary engine compares assigned marking values and keeps complete primitive domains. The direct-table filter uses the same certificates as a conventional comparator. The frozen RF family bank and shape policy are reused; there is no new RL training.

The point model uses bounded binary proof addresses. Each rule and the root seed contribute one half of capacity at their declared positive points. Failure ports carry marking data only and are outside the filling target. This is a specialized reduction in proof space, not a homogeneous plane tile set.

These runs search semantic point-proof trees. The preceding fixed-palette circuit remains a separate encoding backend: no new literal Wang-grid search or raw-NAND compilation is claimed here.

Preservation proposition · human metatheory
Fix a context-free finite producer grammar, rooted proof-height bound \(H\), and independently certified absence keys \(N\). At producer site \(s\), decorate each premise \(F\) with value \(1\) at key \((F,H-|s|-1)\), and seed keys in \(N\) with value \(0\). This preserves exactly the complete rooted proof placement sets under projection.
A complete original proof supplies each required premise subtree within the stated remaining height, so it cannot request an absent key. All added placement values are \(1\), hence agree with one another, and occupancy is unchanged. Conversely, projecting a decorated proof removes only the added marks and leaves a valid original proof. Partial states need not be preserved: eliminating their impossible extensions is the intended pruning.
The keys are scoped to context-free literal syntax, theory, basis and depth semantics. This is a human argument about the encoding, separate from the example proofs discovered automatically.

Costs and assurance scope
The one-second classification limit applies only to the bounded search. Total acquisition also includes independent positive-proof, absence-certificate and mark-model checking; its measured cost can be much larger. Classification search is a component of acquisition, not an additional cost. Preparation and post-search assurance are measured separately.
Cold-equivalent pipeline sums reuse observed preparation/acquisition costs: they are accounted estimates, not repeated cold trials. No new RL training occurs. Charged adapter work includes base-provider work, rather than measuring adapter overhead alone.
Large-run assurance samples first and last retained marked-query records, which may differ from the last emitted query when retention is truncated. It does not reconstruct every intermediate graph. Tiny qualification has separate broader checks. Every negative remains finite-basis/height scoped.
