What is checked inside NAND
The circuit checks raw node syntax, declared arities, term/formula sorts, strictly prior child-node references, free-variable vectors, closed theory axioms, substitution maps and capture hygiene. All \(11\) logical rules are checked internally. There is no supplied zero-rule or producer-admission catalogue deciding which formulas count as valid steps.
The transitive syntax closure of the problem’s axioms and goal, its signature, axiom IDs and goal ID are pinned before witness generation, together with any explicitly declared auxiliary syntax. Remaining syntax rows, proof formulas, rule codes, references and substitution-task data are free inputs, subject to the circuit’s checks. No alpha-renaming is silently applied; repeated IDs denote exact shared syntax.
Human conjunction and disjunction are shorthands: \(A\land B:=\neg(A\to\neg B)\) and \(A\lor B:=(\neg A)\to B\). The core certificate stores implication, negation, universal quantification, equality, predicates, functions, variables and bottom.
This is a circuit proof checker, not an automated proof-search algorithm. Some witnesses reuse proofs found automatically in the earlier study, including seven-line examples. This milestone claims no new proof search, RL training or proof-search advantage.

The same fixed tile palette
The palette contains \(100\) ordinary square Wang tiles, used by translation only. North and south colors each carry an operation and a bit; west and east carry a bit. The operation component is pinned at every vertical edge, including the interior program template. This is not an outer-boundary-only construction or an aperiodicity result. The point implementation uses separate operation and bit ports, never a wildcard tuple.
Large patches use saved compressed CROSS ribbons and an exact expansion argument. The viewer expands at most \(12\) columns by \(6\) rows. These raw-kernel grids were not searched by GCTS; earlier proof discovery and present certificate checking are separate stages.

Bounded implementation and unbounded calculus
A compiled instance has fixed caps for syntax nodes, variables, function and predicate slots, axioms, proof lines, substitution tasks and arity. Its circuit accepts only certificates within those caps. The associated eleven-rule calculus has no such fixed resource bound; increasing a bound requires a new checking circuit, while the Wang palette stays unchanged.
This kernel milestone replaces the earlier externally admitted producer catalogue with internal syntactic and logical checks. It does not show that GCTS or RL can efficiently discover a satisfying proof certificate. Reusing a prior automatically found proof tests the checker and encoding, not new theorem discovery.


Circuit expansion and provenance
With \(I\) circuit inputs and \(G\) NAND gates, the macro grid has \(W=I+G\) and \(H=G\). Each gate row reads its operand columns, computes NAND (NOT for repeated operands), and writes column \(I+y\). CROSS preserves the stored vertical bit and transports the horizontal bus; the bottom next-operation selector is CROSS.
Syntax, substitution, line and final-acceptance bands cover newly emitted gates. Hash-consed dependencies may come from earlier bands; a band is not an independent subproof. Large patches use the recorded exact compressed-expansion argument, with literal-check limits shown in the evidence.
