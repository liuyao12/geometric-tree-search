What a cluster proposal means here

Clusters suggest base-placement continuations after global dead/forced checks and earliest-generation selection. Base fallback remains available. Members need not be adopted together: this is not an atomic macro.

Each constituent contributes integer occupancy \(t=1\) at its output and premise points, against capacity \(C=2\). Equal literal formula markings agree at shared points. The root has a half-capacity seed. Tiles have fixed roles and orientation; this anchored proof-tree adaptation is not yet one fixed translation-only universal Wang palette.

Leader-only uses the same policy and library, retaining only the first preference. Uniform clusters, lexical GCTS, cluster DFS and dynamic programming are comparison controls. Smaller trees alone establish no speed advantage; training, validation and search costs matter.
