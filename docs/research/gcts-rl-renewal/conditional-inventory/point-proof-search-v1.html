Why the next study changes its inventory explicitly

The earlier symbolic producers limited formulas used during discovery, while their local-assumption compiler could emit larger primitive formulas. A direct tile search cannot quietly introduce those extra tiles when a cluster is proposed: earlier claims that a move was forced would become invalid.

The new study instead declares its full primitive inventory before searching a frame. It includes all eight logical axiom families, the chosen theory profile including arithmetic induction, hypotheses, modus ponens and generalization. A frame \((n,b)\) has exactly \(n\) rows. Every tile witness and formula port has at most \(b\) expanded syntax-tree nodes, with variable and binder identifiers below \(b\). There is no implicit padding. Full fixed hypotheses still govern generalization, even when some lie outside the envelope. Restart dovetailing gives each frame increasing search allowance; every repeat counts toward the whole budget.

\[\text{finite primitive proof}\quad\Longrightarrow\quad\text{fits some finite frame and syntax envelope}.\]

This implication is a design argument, conditional on complete enumeration and correct rule membership. It is not a runtime result. A cluster may abbreviate only base tiles already admitted by the current envelope; an expansion that exceeds it waits for a larger envelope.

The former discovery configuration remains unchanged in its own records. This is a distinct study, and its ordinary comparison method will use exactly the same new inventory and boundaries. The common rule vocabulary is still parametric; a single strict finite Wang palette has not been constructed here.

Lazy storage must preserve complete domains

For each unfilled row, the domain means all currently legal placements from the declared inventory. The cache of placements already seen by the search is only part of its representation.

A dead end requires a complete exhaustion certificate. Finding no candidate in a sample cannot close the branch.

Every frontier point must be resolved before a branch decision. A dead point anywhere outranks a forced move; forced moves outrank branching. Changes at distant formula ports must invalidate every affected domain, including placements not yet materialized. Rollback must restore the whole parent state and its exact remaining alternatives.

All row cells in a fixed frame start as generation-zero roots. The generation rule therefore gives an initial tie. This model alone cannot test nontrivial growth generations, fractional occupancy or candidates shared by several required points; independent point-model controls must cover those cases.

What several agents can improve

Implementation

Specify complete primitive-tile generation, stable placement identities, memory use and a reversible search interface.

Independent tests

Define the finite problem independently and prepare small exhaustive checks that can expose missing candidates and rollback errors.

Critical review

Challenge inventory completeness, hidden changes of scope, invalid pruning and claims that go beyond the evidence.

Root integrates the contracts, implementation and evidence. The agents develop the search program and its tests; they do not supply target proofs. The work proceeds concurrently, with one integrated review record. Timed proof-search experiments remain isolated.
