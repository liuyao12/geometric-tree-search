What the algorithm actually searched

A frame \((n,b)\) requires exactly \(n\) occupied proof-row cells. Every primitive tile witness and formula port has at most \(b\) expanded syntax nodes, and identifiers are below \(b\). All row cells start as generation-zero roots. The inventory includes hypotheses, all eight logical axiom schemas, theory axioms including induction for the arithmetic profile, modus ponens and generalization. This proof used only E1 and generalization.

The controller classifies every unfilled row domain, checks for a dead end anywhere, propagates globally forced moves, then branches at the earliest generation, with row order breaking ties in this model. Empty and singleton classifications require complete exhaustion; two distinct witnesses suffice to certify multiple candidates. An unfinished classification blocks the decision. Unseen candidates remain possible until complete enumeration rules them out. Unchanged dependency projections allow domain reuse; distant marking changes invalidate affected domains. Rollback restores the exact parent and remaining branch alternatives.

Fresh frame restarts visit increasing sizes and budgets. The successful certificate contains a valid unused row; it is neither padded implicitly nor a shortest-proof result. A fair unbounded search argument gives no practical runtime guarantee.

The contribution is now testable, but the advantage is unestablished. A concrete point-domain controller produced this certificate. Formula markings are mandatory logical constraints, not learned failure rules. There is no RL policy, learned marking or reusable lemma family in this run.
