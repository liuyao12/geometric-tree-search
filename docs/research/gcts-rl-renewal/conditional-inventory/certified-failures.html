Certified failures become point markings

The integration question is whether a real failed search can supply a checkable exclusion, then use its geometric encoding through the ordinary point graph while preserving every original solution.

Scope: a finite propositional and point-domain control. Its palettes depend on the input. This does not supply the single universal first-order Wang palette, arithmetic or Hilbert geometry integration, Turtle marking learner, or trained RL policy.

The complete declared run

Correctness integration passed. No search benefit was observed.

The complete declared bank contains \(23\) cases and \(18\) diagnostics. Search acquired \(13\) independently checked primitive failure clauses. All \(37\) original solutions were preserved, including complete agreement in \(5\) exhausted negative cases. The independent checker audited \(829\) normal live graph censuses.

Plain and compiled search each made \(54\) base branch attempts. Auxiliary placements logged \(0\) base-candidate removals. These are event counts in a single instrumented finite control, not an estimate of general proof-search performance.

A concrete next experiment
The saved data exposes a receptor selectivity gap. In one retained case, the referenced base point allowed \(2\) original types while its first receptor still allowed \(10\) choice values. The current auxiliary type reads a fresh choice channel but does not carry the original type’s role and truth markings. The choice channel therefore need not reveal the base domain before a base placement.
One proposed compiler variant would copy the referenced original type’s markings into the receptor at the corresponding absolute points. It would copy no positive support. The intended extension argument is that the existing choice equality already identifies that same original type in every complete solution. This is a Source-level proposal: it has not been implemented, independently qualified or measured. It may still give no benefit.
A fair next comparison must retain this exact original bank, full candidate universe and original resource ceilings, check extension and projection independently, and compare the same certificates in a conventional constraint engine. Acquisition and expansion costs must remain visible.
