Why the second-row restriction is sound

This argument covers the declared six rules and the original empty hypothesis context. Its constraint is necessary for completed words and boards; it does not claim that every locally matching partial cluster is a proof.

  1. At row \(1\), the sole earlier row is \(0\). Repeated premise reads are allowed.
  2. Modus ponens requires \(A\) and \(A\to C\). If both ports read row \(0\), literal formula-mark agreement requires \(A=\operatorname{Imp}(A,C)\).
  3. Every formula is a finite syntax tree. But \(\lvert\operatorname{Imp}(A,C)\rvert=1+\lvert A\rvert+\lvert C\rvert>\lvert A\rvert\), a contradiction.

The producer and independent verifier were written separately. Independent Source review checked the complete rule cases, and both actuals regenerated and checked the full current marking. The case argument is human-designed and implemented in the verifiers; it was not discovered by RL or proved in a separate metatheory kernel. Runtime timeouts are never used as negative certificates.
