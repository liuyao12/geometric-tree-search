Supplied mathematical analysis
The limit of fixed equality markings
If fixed literal markings reject a family, either one placement conflicts with the seed or two placements assign different values at a common component. Thus, preserving a complete cover for each pair of \(A,B,C\) forces their entire marking union to agree. Such a layer cannot directly reject only \(\{A,B,C\}\).
This is a supplied argument, not a general theorem discovered by this search. Arbitrarily distant marking reach does not alter this pairwise obstruction. Auxiliary states, placements or receptor interfaces may express a higher-order condition, with a separate projection proof.
Binary encodings using auxiliary variables are established: Samaras and Stergiou; Dubois, 2020. These are precedents, not novelty or formal-verification claims for this implementation.

Assessment
The current contribution is an independently checkable semantic certificate for a finite shared-fact point reduction, with useful bounded failed contexts. This is not evidence of a distinctive GCTS search advantage, new reinforcement learning, learned point markings or a new mathematical theorem.
The next substantive comparison should encode the same certified failure information both as a direct constraint filter and as validated point markings or auxiliary receptor states, keeping the task, scheduler, complete fallback and assurance identical.
Costs and assurance scope
Retrospective work measured here is new assurance only. Historical acquisition and native positive checks are reused observations; the engine and kernel were not rerun. The mixed work counter includes serialization/callback charges, so equal numeric thresholds are not equal core work.
Semantic replay checks independently reconstructed decisions plus actual serialized endpoints. It does not observe all intermediate producer tables. Optional rollback metadata can be a prefix while the semantic event proof is complete; event prefixes never certify absence.
