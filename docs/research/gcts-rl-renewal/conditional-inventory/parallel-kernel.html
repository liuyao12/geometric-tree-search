A lemma belongs to a theory

The proposed inventory needs to remember the exact theory and premises of each certified cluster. A theorem from one context cannot simply be carried into another. This is a concrete condition on the higher-level structures we want GCTS and RL to discover.

Manual interface counterexample from the Source audit. This display explains an unrun low-level reuse recipe; it is not a newly discovered mathematical proof or a physical tile trace.

Let \(T_1=\{\bot\}\). This deliberately inconsistent toy theory makes the scope error visible.

  1. Read the declared axiom: \(T_1\vdash\bot\).
  2. Certify a block \(L\) with no premises and conclusion \(\bot\), relative to \(T_1\).
  3. Calling \(L\) in the same theory justifies \(T_1\vdash\bot\).

The checker establishes a derivation relative to supplied axioms. It does not establish their truth.

Now change to the empty theory \(T_0=\varnothing\).

  1. The old axiom is no longer available.
  2. The old block still carries an obligation relative to \(T_1\); it is not a certificate for \(T_0\).
  3. Importing it unchanged would claim \(T_0\vdash\bot\) without justification.

The audit predicts that reusing the old low-level checker can leave this stale block registered. The public check(payload) entry point creates a fresh checker and avoids that path.

The proposed Source repair makes each low-level checker accept at most one request, including after a failed first request. Its independent delta review passes; it has not been run or integrated. The broader inventory must retain complete context binding, premises and expanded certificates.

The current block rule consumes exact earlier premises. A learned receptor family would still have to propose an instantiation, supply its complete certificate and check it in the target theory. The audit establishes an obligation for that design; it does not implement family discovery or inventory selection.

This matters equally for arithmetic and geometry. Peano arithmetic requires its licensed axioms and induction schema. Hilbert geometry requires its symbolic signature, axiom groups and a faithful encoding of point, line and plane sorts. A picture supplies none of those obligations.
