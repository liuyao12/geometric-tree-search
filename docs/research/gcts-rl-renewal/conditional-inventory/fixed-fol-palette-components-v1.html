See the tiles, including their marks

Tiles keep their orientation and move by translation only. Each simulated transition uses two rows: CHOOSE records one transition tag, then EXEC applies that same choice across the overlapping neighborhoods. A tag carried by adjacent tiles prevents a row from mixing incompatible choices.

Inspect a tile

Select any square. Each edge label below is its complete literal matching value.

These colored marks enforce the computation. In a point encoding, a square supplies \(t=1\) at its cell and matching \(m\)-values at shared edge points; both copies of a shared mark must agree. This run uses an independent literal row enumerator, not the master GCTS frontier scheduler. Learned GCTS search marks and RL cluster proposals are absent from this qualification.

Why use two rows for a single transition?

A local transition may have several possible outputs. If each neighborhood selected independently, the left and right sides could describe different global moves. The choice phase places the chosen transition index on the unique head. Overlapping neighborhoods read that same tag during execution. The test compares the resulting complete configurations with a simulator that chooses one whole machine transition at a time.

The finite tape has two wall cells. The initial row supplies one head, the construction preserves it on valid transitions, and accepting states absorb. An outward move has no completed execution row. A locally compatible fragment alone does not establish a valid initial row or acceptance.

Integration open

Earlier finite first-order catalog searches remain useful results. Their inference catalogs and palettes can depend on the problem. The stronger objective is one fixed finite palette whose boundary data supplies the theory and goal, while proof choices remain unknown inside the search. A fixed checker that only replays a supplied proof does not meet that objective.

The next arithmetic panel should include quantified cancellation, comparison, parity and distributivity, with the search choosing any needed induction instance. The separate symbolic geometry panel should include segment subtraction, midpoint uniqueness, derived outer Pasch and SSS consequences, against an explicit Hilbert-type incidence/order/congruence axiom ledger. These are candidate targets, not results from this run.

Reusable clusters should carry checked premises, conclusions and side conditions, so a receptor family can instantiate a lemma safely. A conventional baseline must receive the same certified inventory. We will count acquisition, validation and reuse costs before attributing an advantage to GCTS or RL.
