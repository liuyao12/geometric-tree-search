Exactly what is being searched

These are finite symbolic point-tile models. Each proof row has one unit occupancy root. Its formula-valued marking and remote premise receptors must agree exactly. All row roots are activated at generation zero; the engine checks global dead ends, then global forced moves, then branches at the earliest generation, using domain size only to break ties. Rotations and reflections are absent.

The eight kernel rules are named axioms, equality reflexivity, propositional tautologies, universal instantiation, quantifier distribution, equality substitution, modus ponens and generalization. The generated basis, schema witnesses, term set and line bound restrict which instances are available. Exhaustion proves only that no derivation exists in that declared finite model. A resource cutoff remains unknown.

The arithmetic inputs use addition's defining equations; they do not include the Peano induction schema. The geometric inputs explicitly list incidence or betweenness axioms in a one-sorted symbolic language with point and line predicates. They are fragments associated with Hilbert-style geometry. No Euclidean drawing, coordinate calculation or spatial intuition enters the logical checker.

A fixed complete physical machine, together with a correct machine-to-Wang simulation and accepting boundaries, would give one finite palette for its accepted input language. The present symbolic proof-row models are not that palette. Tiny bridge controls do not establish the complete checker construction or a universal formalization of mathematics.




What this says about GCTS and learning


This milestone tests representation and proof search. It contains no new RL training run. The previous pilot's policy updates did not change executed choices or improve results. A useful future cluster proposal must validate its whole instantiated interface against the current state and compete against a control with the same available lemmas and total costs.


Verified clusters can become reusable conditional lemma families. Such reuse still needs explicit assumptions, capture and freshness conditions, exact proof expansion or an independently verified certificate, and accounting for acquisition and invocation costs. The current finite basis remains visible in the archive so that helpful formula selection is not mistaken for an unrestricted completeness result.


Sources, complete results, raw certificates and execution evidence are retained in the linked archive. The report distinguishes observed finite results, source-level arguments and unfinished constructions. The broader research program remains active.
