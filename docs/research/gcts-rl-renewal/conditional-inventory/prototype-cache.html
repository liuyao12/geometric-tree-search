One optimization, the original arithmetic target

\[G:=\forall n\,\bigl(\operatorname{add}(n,S(S(0)))=S(S(n))\bigr).\]

The target, named addition axioms AS/AZ, empty hypothesis context \(\Gamma=\varnothing\), parameter \(n\), grammar bounds \(B=12,\;N=44\) and required \(24\)-row board are unchanged. Both modes load and seal the same \(30\) current executable Sources and preserve the original \(17\)-Source mathematical binding. Each starts with a fresh instance and empty cache. Scientific work has an absolute \(17\;\mathrm{s}\) endpoint inside the same \(20\;\mathrm{s}\), \(512\;\mathrm{MiB}\) native limit. Construction, guards, keying, checking, copies, cache warmup and memory, rollback, serialization and terminal closure are charged. The tests ran first; the two search runs were separate, sequential, once-only actuals.

This is the existing symbolic, translation-only unit-row proof adaptation. It is not full Peano arithmetic, a fixed universal Wang palette, full geometric GCTS or trained RL. The cache adds no axiom, marking, pruning rule or mathematical authority.

What may be reused

Exact request

The full prototype preimage, translation, literal marking, effective language and checker context, and current Source epoch identify one instance.

Checked miss

Original reconstruction, decoration and the independent full tile check must finish before an immutable packet is stored.

Guarded hit

Current Source and effective context are checked again. The original native visit/deadline tick runs, and a fresh owned packet is returned.

Current placement

Occupancy, remote marking agreement, selected or excluded keys, degree evidence and fallback remain checks of the current search state.

Cache capacity is bounded by \(512\) entries and \(8\;\mathrm{MiB}\) of accounted key/context/packet payload. A full or disabled cache falls back to ordinary checked reconstruction. Payload accounting is not a total-memory estimate; the native peak is reported separately. Cache contents and counters are outside semantic checkpoints. Their survival across rollback cannot certify a placement, dead end, exclusion or proof.

Packet identity and ownership · \(5\) passed finite cases

Compare complete packets and ensure caller-owned mutable data cannot become stored authority.

  1. Same complete packets literal_packets

    Compare the previous adapter with both new cache modes on independently assembled generic tile requests. Cold and repeated cached packets equal the uncached packet in full; a fresh instance starts without a warmed entry.

    Coverage: Two original named axioms, one instantiation license and one generalization; retained parent V7 is compared. Limit: Four generic prototype requests, not all possible tiles or a supplied target proof.

  2. Returned data cannot poison later packets returned_packet_ownership

    Mutate nested data returned on a miss and a hit, then request the same tile again. The next packet remains pristine and independently checkable; modifying returned statistics cannot alter later statistics.

    Coverage: See the declared behavior above. Limit: Exercises declared nested fields and one prototype; does not mutate private cache storage.

  3. Different full requests stay distinct distinct_full_keys

    Change the full tile preimage, translation or ordered read offset after another request has been stored. Each distinct request is a miss with its own insertion and equals ordinary uncached reconstruction.

    Coverage: See the declared behavior above. Limit: Five literal requests; no cryptographic collision is forged or claimed.

  4. Malformed requests cannot reuse a valid entry invalid_requests

    Try a wrong marking identity, wrong input epoch, wrong premise list and invalid translations after priming a valid entry. Both cache modes reject; cached hits, entries and insertions do not increase.

    Coverage: See the declared behavior above. Limit: Five specific invalid requests; not a complete parser or hostile-input audit.

  5. Constructor owns its marking copy constructor_marking_input_ownership

    Mutate the caller-owned marking object after constructing and priming the adapter. Future packets still use the original frozen marking and pass full reconstruction.

    Coverage: See the declared behavior above. Limit: The changed caller object is not a newly authenticated marking model; private adapter fields are untouched.
