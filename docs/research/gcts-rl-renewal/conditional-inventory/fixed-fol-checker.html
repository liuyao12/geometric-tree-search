Source and design note · 19 October 2026

One checker boundary, several mathematical theories

The project has a full serialized first-order certificate checker. The next foundation is to preserve its meaning through one fixed machine and one fixed Wang palette, then search for an unknown certificate.

Design status: the checker Sources and a narrow delegation adapter are pinned. The adapter has not been invoked. A faithful fixed single-tape checker table, its resulting fixed palette and the unknown-certificate board language are still missing. This note supplies no discovered proof, compiler execution, runtime qualification or universal artifact.

The chain, with its current gaps

Existing tree bytecode, tape-lowering and Native artifacts do not establish the deterministic single-tape table required here. The compiler takes a machine parameter; a single fixed proof system requires freezing that table across theorems.

The framed compiler maps a unit Wang tile to a center with \(t=1\) and four edge-midpoint \(m\)-channels; centers lie at \((2x,2y)\), with translations in \(2\mathbb{Z}^2\) and no rotations. Pair colors enforce configuration overlap. Sidewalls forbid head escape, and an accepting collector requires the accepting head. An all-plain bottom is insufficient; halting cannot be padded. The fixed FOL table and its resulting complete palette remain unbuilt.

Freeze the problem; leave the proof unknown

The current public protocol is gcts-fol-1. A request has exactly five fields: protocol, theory, target, blocks and proof. The first three define the public problem. The last two are proposed certificate data.

Frozen public input

\[\bigl(\Theta,\varphi\bigr)\]

The whole signature, authorized closed axioms, schema policy and exact target are fixed before search.

Certificate boundary

\[K(\Theta,\varphi,\pi)\]

The fixed checker examines the proposed blocks and primitive rows in \(\pi\). A candidate cannot rewrite the public problem.

Search output

An accepted certificate is evidence relative to the declared theory. A search contribution additionally needs authenticated provenance that the search found it.

The public-problem hash covers only protocol, theory and target, using compact sorted JSON with ensure_ascii=True. Its expected digest must come from the frozen problem. Other evidence hashes are not interchangeable.

The unexecuted adapter delegates to check, creating a fresh checker per request. It adds no rules. Reusing mutable Checker.request across requests could retain earlier blocks and needs separate isolation.

A future owner must bind exact Source/code/callable identities and charge parsing, copying, checking, guards and output. Path/protocol matching is insufficient; adapter guards do not supply hard preemption.

A small explicit language

Terms are variables and applications of declared functions. Formulas use equality, declared predicates, Boolean connectives and universal quantification:

\[ \begin{aligned} t&::=x\mid f(t_1,\ldots,t_n),\\ \varphi&::=\bot\mid s=t\mid P(t_1,\ldots,t_n)\mid\neg\varphi \mid(\varphi\to\psi)\mid(\varphi\land\psi)\mid(\varphi\lor\psi)\mid\forall x\,\varphi. \end{aligned} \]

Every function and predicate has a declared exact arity. Variables and symbols are literal names. The host representation uses tagged arrays such as ["all", "x", body] and ["eq", left, right]. Existential notation can be expressed as \(\exists x\,\varphi\equiv\neg\forall x\,\neg\varphi\); it is not an extra primitive rule.

Parsing rejects duplicate keys, floats, malformed tags, fields and arities. Natural-number indices exclude booleans. Matching uses exact named trees, not automatic bound-variable renaming.

The tagged tree wire uses byte atoms and immutable cons cells. Host/machine correspondence still needs exact treatment of names, unpaired surrogates, duplicate keys, integer types and delimiters.

Rule interfaces the fixed checker already expresses

These are schematic rule interfaces, not discovered proofs, target certificates or executed tests.

Universal instantiation

\[\forall x\,A\ \to\ A[t/x]\]

This row checks a capture-avoiding schema. Obtaining the instance still requires a proved universal premise and modus ponens.

Capture avoidance

\[(\forall y\,R(x,y))[y/x]=\forall z\,R(y,z)\]

Here \(z\) is fresh. This is a schematic display of binder renaming, not the literal checker output name. The implementation chooses the first available freshN name and requires the corresponding exact tree.

Generalization

\[\frac{\Gamma\vdash A}{\Gamma\vdash\forall x\,A}\qquad x\notin\operatorname{FV}(\Gamma)\]

The condition covers every declared local block premise, not an inferred dependency subset. Root proofs have no local assumptions; named theory axioms must be closed.

Quantifier distribution

\[\forall x(A\to B)\to(A\to\forall xB),\qquad x\notin\operatorname{FV}(A)\]

The free-variable condition is part of the checked interface. Omitting it would change the rule.

Equality substitution

\[s=t\to\bigl(A[s/x]\to A[t/x]\bigr)\]

The full formula template uses capture-avoiding substitution. Reflexivity checks \(t=t\); neither rule invokes arithmetic or geometry evaluation.

Generic induction authorization

\[\bigl(A[0/x]\land\forall x(A\to A[S(x)/x])\bigr)\to\forall xA\]

Requires nat-induction, nullary zero and unary succ. Other free parameters are universally closed. Human choice of an instance is not evidence of an automatically discovered strategy.

The eleven row kinds are axiom, tautology, refl, instantiate, distribute, eq_subst, mp, generalize, induction, assumption and block. Propositional tautology is checked over its finite atom set. References must be exact natural-number indices to strictly earlier rows, and the final row must equal the declared target.

Common logic, different authorized axiom data

Theory inputWhat can varyWhat must remain fixed
ArithmeticThe declared signature, complete closed arithmetic axioms and explicit induction authorization.The checker algorithm, codec and eventual machine/palette. An addition equation or logical reflexivity control does not by itself establish full PA coverage.
Hilbert geometryA faithfully translated, fully licensed theory with its point/line/plane representation, incidence, order, congruence and exact assumptions.The same logical kernel and eventual palette. Imported definitions, classical choices and dimensional assumptions cannot be dropped or silently strengthened.

Acceptance is relative to supplied axioms. An independent source-theory policy must freeze and authorize them; otherwise a candidate could add its target as an axiom.

Historical Hilbert controls use a closed five-rule dialect and ordered hypotheses. They need a root-request bridge and do not supply complete Hilbert axioms.

The hypothesis bridge is still a gate. For closed ordered hypotheses \(\Gamma=(A_1,\ldots,A_n)\), an explicitly licensed translation could preserve each occurrence as a fresh named closed theory fact, or use a certified sequent/deduction encoding. Neither bridge is supplied by this note. Open hypotheses cannot be silently universally closed or promoted to closed axioms: that can strengthen the problem and invalidate generalization permissions.

Reusable receptor families need a proof interface

A block records ordered premises, conclusion and complete primitive derivation. Names are unique; checking is dependency-first without recursion. Calls must match the exact proved premises in order.

\[ \mathcal{B}:\ (A_1,\ldots,A_k)\Longrightarrow B \quad\text{with a checked primitive expansion under those premises.} \]

A receptor family or cluster proposes through that interface. Policy, donor success and local fit confer no logical authority. Instantiation must preserve variable hygiene, theory, scope, ordered premise occurrences and expansion into primitives.

A logical step may summarize many machine configurations. Its interface certificate and checked expansion form the missing bridge. Learned markings and pruning hypotheses remain separate from proved constraints.

Checking a certificate is different from finding one

Acceptance by \(K\) demonstrates checking relative to the pinned theory and target. Discovery additionally needs the original problem, candidate provenance, complete controls, budgets and independent final validation.

Unknown-certificate Wang search needs variable certificate symbols, a fixed public problem, explicit boundary grammar and lossless checked decoding. Complete-word calibration pins every initial cell: it tests finite compiler/search correspondence, not unknown-proof search or theorem benchmarks.

Certificate lengths, widths and exact times need fair effective enumeration beyond one bound. A timeout or exhausted board does not reject larger bounds. Calibration must retain its full domain, negatives and limits.

Future receptor/RL comparisons need conventional search with the same axioms, library and charged discovery/loading/checking costs, plus complete fallback. Computation encoding alone supplies no search advantage.

The next concrete obligations

  1. Check the host and tree-kernel correspondence, including malformed wire data, substitution freshness, name ordering, induction parameters and block scopes.
  2. Freeze the source-authorized theory/target policy and one lossless problem/certificate codec. Review the ordered-hypothesis bridge and the full Hilbert translation separately.
  3. Produce and independently verify one fixed single-tape checker table. Then compile and freeze its complete Wang palette before theorem instances.
  4. Implement the unknown-certificate board language, complete point search and independent verifier. A reusable macro must carry an exact interface and primitive expansion.
  5. Only then run genuinely unknown proof tasks with matched-knowledge controls and complete resource/learning-cost evidence.

These obligations do not replace the failed whole six-root production workload or confer full cold-pipeline admission. Arithmetic/Hilbert theorem search and the broader tiling programme remain open goals.
