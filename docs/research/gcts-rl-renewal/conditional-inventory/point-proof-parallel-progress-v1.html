Using the display aliases in the original report below, every current family concludes

\[V_i=\bigl(D_i\to(D_i\to D_i)\bigr)\to(D_i\to D_i).\]

There are five occurrences of \(D_i\) and four further implication nodes. The donor skeletons remain rigid even though their atom parameters can be replaced by whole formulas. Every formula image contains at least one node, so

\[|D_0|_{\min}=9,\qquad |D_1|_{\min}=12,\qquad |V_0|_{\min}=5\cdot9+4=49,\quad |V_1|_{\min}=5\cdot12+4=64.\]

Equal substitutions do not merge repeated syntax occurrences. Since \(15<49<64\), exact structural matching cannot attach any output to the evaluation goal or one of its subformulas. The initial hypothesis context is empty. We therefore retain the target unspent instead of timing a predetermined zero-match experiment.

Scope of this result. It rules out the goal/subformula interface for this inventory. Search can introduce larger auxiliary formulas, and primitive proof reconstruction can expose larger obligations. Neither possibility has been tested here. This is not a non-provability result or a general limitation of lemma reuse.

A small manual example, and why it still does not settle transfer

The closed fragment has an H1 row, an H2 row and one application of modus ponens. Write independent axiom variables first:

\[X\to(Y\to X),\qquad \bigl(A\to(B\to C)\bigr)\to\bigl((A\to B)\to(A\to C)\bigr).\]

Matching the first row to the second row's antecedent requires \(X=A=C\) and \(Y=B\), giving the schematic consequence

\[(A\to B)\to(A\to A).\]

This manual derivation is a prospective expectation for the implementation, not a newly discovered machine proof. Its minimum size is only \(7\) nodes. Nevertheless, every instance contains the proper tautological subformula \(A\to A\). The evaluation input rules exclude proper tautological subformulas, so this closed schema still cannot match its goal or subformulas.

The conditional fragment can have arbitrary output \(C\), but it requires a prior proof of \((A\to(B\to A))\to C\). Its antecedent is an H1 theorem, so this boundary requirement is equivalent to proving \(C\); the boundary cannot be treated as a free fact. Useful transfer still needs a suitable contextual or auxiliary-obligation search interface and a more useful inventory.
