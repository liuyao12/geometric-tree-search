The concrete statement

\[\forall x\bigl(P(x)\rightarrow(Q(x)\rightarrow R(x))\bigr),\quad\forall xP(x),\quad\forall xQ(x)\ \vdash\ \forall xR(x).\]

If every object satisfying the two premises satisfies the conclusion, and every object satisfies both premises, then every object satisfies the conclusion. This is a basic first-order assertion, not an arithmetic or geometric axiom. It is familiar development data, not a blind test or a new mathematical theorem.

What changed

The old distance ranking could favor a legal instantiation licence for the desired universal statement even while that universal remained unproved. The new heuristic models inference as a dependency with all required premises attached. It seeds only justified completed rows, assigns positive cost to each new inference, and ranks the available choices by their effect on the remaining support for the target.

Justified facts

A complete row needs its actual earlier input rows. A guard tile alone supplies no fact.

Joint dependencies

All premises of a rule must be supported together. A licence for \((\forall xR(x))\rightarrow R(x)\) does not supply \(\forall xR(x)\).

Rank the choices

Positive inference costs keep circular support from seeding itself. Scores reorder available choices; the checker decides validity.

\[c(\text{rule})=1+\sum_{i=1}^{k}c(\text{premise}_i).\]

This is a heuristic potential, not a certified lower bound. The same implementation is used by both methods.
