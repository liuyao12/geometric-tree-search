Memory rule and scope

The separately declared sequential cutoff rule is \[C=\max_i P_i,\qquad B_{\mathrm{live}}=S_{\mathrm{cut}}+C,\qquad B=\max(B_{\mathrm{live}},T).\] Every child lifetime must close before the irreversible no-spawn cutoff; \(T\) is the actual external terminal inclusive high-water value, not an earlier sample. For the primary, \(S_{\mathrm{cut}}=20{,}774{,}912\), \(C=T=293{,}240{,}832\), hence \(B=314{,}015{,}744\) bytes. The time gate still fails.

Fixed reviewed Sources and the pinned Darwin runtime define this scope; it is not a hostile operating-system or universal hard-cap guarantee. All historical UNKNOWNs retain their original resource rules and outcomes.
