What the experiments establish

There is now a working path from unmarked tiling searches to certified failures, learned proposals and reusable clusters, and a separate path from symbolic statements to automatically found Wang proof diagrams. The prototypes have reproducible evidence. A broad practical advantage from GCTS or RL remains unproved.

Why the current proof grammar can encode computation

This is our mathematical construction for the existing grammar, rather than a new theorem discovered by its search. Consider the two-counter instruction convention studied by Dudenhefner: increment advances to the next instruction; a positive decrement jumps, while zero advances. Its halting problem is undecidable.

For a program with finitely many labels, use one binary predicate \(A_p\) per label, a constant \(0\), a unary constructor \(S\), and a nullary predicate \(H\). The boundary contains its starting fact. An increment of the first counter has the clause

\[\neg A_p(x,y)\lor A_{p+1}(S(x),y).\]

A first-counter decrement with positive jump destination \(q\) has two clauses:

\[\neg A_p(S(x),y)\lor A_q(x,y),\qquad\neg A_p(0,y)\lor A_{p+1}(0,y).\]

Exchange arguments for the second counter. Identify every out-of-program destination with the halt label. At that label add \(\neg A_{\mathrm{halt}}(x,y)\lor H\), and deny the goal with \(\neg H\). All free clause variables are universally quantified.

Every machine step gives a ground instance and a resolution from the preceding configuration fact. A halting run therefore gives a finite refutation. Conversely, if the machine does not halt, interpret \(A_p(S^i(0),S^j(0))\) as true exactly for reachable configurations, and interpret \(H\) as false. This Herbrand interpretation satisfies all the clauses, so soundness rules out a refutation. Thus a finite accepting proof diagram exists exactly when the encoded computation halts.

The number of predicates changes the encoded boundary text, not the tile palette. Their names, terms and proof references use finite strings over the fixed tape alphabet. The same source-instantiation and resolution verifier handles these clauses and the arithmetic and geometry examples.

This establishes expressiveness in the unbounded mathematical system. It neither makes all true statements provable nor makes theorem search decidable. A mathematical theory still needs specified axioms. The current fair backstop takes a finite clause boundary; searching an infinite axiom schema requires an additional fair enumeration of finite axiom prefixes.

The next scientific question

The examples establish that the system can discover proofs without a human supplying each proof. They do not yet establish that the geometric organization is the reason it finds useful proofs, or that learning improves performance reliably. The clause-encoding control is particularly important: conventional direct clauses with propagation solved the same fourteen geometry cases as the mined inventory. On that representation the inventory reduced counted resolution work, with additional premise-matching work.

The strongest next comparison would freeze a learned inventory and test genuinely different theorem structures, accounting for donor training, matching, expanded proof checking, memory and elapsed time. Conventional propagation, conventional lemma reuse and an external prover should receive the same statements and available lemmas. Automatic decisions about which receptor families to retain or compose would then test the proposed hierarchy more directly.

This audit records the available evidence and its limits. The open performance questions above are recorded as open findings; this page does not claim a solved general proof-search problem.
