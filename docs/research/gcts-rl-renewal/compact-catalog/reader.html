This run does not yet measure a GCTS or RL advantage

This experiment prepares the repertoire on which search would operate. It has no search nodes, learned rewards, policy updates or newly discovered proofs. Low compiler memory is useful engineering progress; it cannot establish that GCTS searches better.

The compact graph's source preserves complete point/candidate factors, remote marking dependencies and the original global-dead-end, forced-move, earliest-generation scheduler through the unchanged core. Actual mutation, re-enumeration, rollback and the legacy Controller/feature interfaces still need new dynamic conformance tests before this adapter can drive a search episode.

After qualification, the comparison remains primitive search, fixed cluster guidance, and learned ordering under the same licensed primitives, complete fallback, boundary and total budgets. Automatic connected proof-window mining must start from checked donor searches; supplying a human proof would not test the stated objective. Other provers need separately checked returned proofs and clearly labeled semantics.

The previously checked incidence proof remains inspectable row by row. Its acceptance is unchanged and separate from this new arithmetic attempt.

Next: account for the compiler's time before activating search

  1. Freeze a new version with bounded phase telemetry for syntax expansion, external sorting, identity emission and evidence writing. Measure the complete run under the same envelope.
  2. Optimize the measured bottleneck while preserving the full grammar and exact identity preimages. Any changed byte protocol needs an explicit new version and independent source review.
  3. Only a complete admitted producer can trigger the independently owned whole-catalog and point-domain audit. It gets its own full cost and caller gate.
  4. Then validate the compact engine's dynamic scheduler and exact rollback, qualify Controller/RL interfaces, and run fresh donor search, automatic cluster mining and fair controls.

The research goal stays active. Resource UNKNOWN is not a theorem counterexample, a proof of impossibility or a sound reason to prune a mathematical candidate.
