Starting from an empty library, GCTS searches each statement; every eligible dependency-chain window of two to four moves is checked and promoted. Each fragment is a closed, universally quantified equation. At use time, substitution and equality in a surrounding context connect it to the current anchored equation. Those explicit input/output formulas are its ports. The theorem block may call only previously checked blocks; all definitions and the final request expand into primitive kernel rules.

WHAT THIS CONTRIBUTES

Reusable proof search is demonstrated. The gain is specific.

Plain GCTS, level-one sequences and the full hierarchy each find and completely verify sixteen proofs across twenty requests, and exhaust the same four finite control envelopes. The full hierarchy reduces cold request time from \(30.623\) to \(21.445\) seconds. Charging its entire donor search, mining, checking and whole-library native validation adds \(1.587\) seconds, giving \(23.032\) seconds. A shared native compilation costs \(1.006\) seconds in either lane.

A concrete contribution: automatically searched subproofs become reusable checked constituents, and validated sequence proposals reduce total work and time on this small fixed family. The second hierarchy level saves only about \(0.211\) seconds beyond level one before charging learning. This is evidence for fragment reuse; it does not establish that deeper hierarchies generally pay.

The nested-right addition case uses \(391\) plain-search states versus \(4\) with the full hierarchy. Its actual solution uses a level-one fragment inside the second argument, followed by the level-two fragment. Multiplication instead needs more work with sequence proposals: \(547\) states versus \(515\), and slightly more cold time. Ranking the next single tile with the same hierarchy leaves both multiplication repeats unknown at the search limit. All unknowns remain unknown.

These are two deterministic repeats in rotated lane order, with identical targets, axioms, term bounds, cell bounds, base candidates and global scheduler. They are timing repeats on ten fixed statements, not random-seed trials or broad theorem generalization. The rank-only lane has different outcomes, so its aggregate time is not an equal-success ranking. No RL is trained in this experiment.

The result is a hierarchical proof representation and a sequence proposer over the base graph. A parent fragment is not counted as an extra frontier candidate, and it does not reduce the primitive cell envelope. This avoids changing the comparison's logical grammar. A genuinely coarse search graph with its own complete interface bookkeeping remains a later experiment.

EXACT INTERFACES · PROVENANCE · ROLLBACK

Keep proposals separate from proved constraints.

Each base inference tile occupies one cell with \(t=1\); its output and earlier premise requirements assign scalar \(m\)-values at formula points. All overlapping values must agree. Every lane retains the complete frontier/candidate incidence graph. Global dead ends come first, then global forced moves, then earliest generation with degree breaking ties. The fixed finite boundary initializes all cells at generation zero.

A sequence proposal is replayed on a copied state and complete copied graph. Before every constituent, the global scheduler is recomputed. Forced moves outside the fragment execute too; a branch member must be incident to the selected point. An incompatible interface, absent scheduled member or global dead end rejects the proposal and restores the parent exactly. A resource cutoff is unknown. Rejected proposals do not eliminate base candidates.

The independent auditor imports no miner, proposer, graph implementation or producer. It reconstructs the external statements, every base rewrite rule, every eligible mined source window, every proposal instance, all saved domain samples, and every complete search tree with its transactions and failed branches. It checks all promoted definitions and every positive certificate by full primitive expansion, and binds every native input to the frozen program and original problem hash.

The audit does not replay every native instruction or certify the truncated trees of unknown runs. The native adapter, toolchain and frozen kernel remain trusted implementation layers. There is no new formal universal compiler-soundness proof. The finite positional tile grammar uses identity transforms and exact syntax IDs; it is Wang-style, not a translation-invariant four-edge inventory. This experiment learns interfaces and sequences, not new failure markings.

RESEARCH PRIORITIES

Concentrate on proof tiles and interface selection.

The next gate is zero-start RL selecting checked sequence proposals, measured against these exact plain, level-one and hierarchy controls with training and all checking costs charged. Then broaden the theorem family, introduce induction and a fair language grammar, and test a coarse graph against a constraint-solver control. No bounded failure may become an unproved pruning rule.

The multiscale analogy now has a concrete local solution relation: a checked equation interface hides a solved interior and composes inside another expression. Automatic promotion is demonstrated at two levels; arbitrary boundary composition and generally useful scale selection are open. Turtle and Penrose remain occasional geometric and bookkeeping controls. A substitution rule need not be a prerequisite.
