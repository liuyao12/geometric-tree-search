Agents exchange APIs and source reviews. They do not write or supply the target proof. Author and dependency overlap is disclosed in the exact review records. Parallel development does not itself demonstrate faster mathematical proof search.

What parallelism contributes—and what remains open
The concrete contribution is independently authored proposal code, checking code and attempts to expose their errors. This creates a useful division of research work while retaining one shared statement of the experiment. It does not establish a GCTS-specific gain, reinforcement learning, learned markings, reusable learned lemmas or theorem discovery.
All engine methods, full base fallback, global dead/forced/earliest-generation scheduling, advisory family retirement and rollback remain unchanged. The engine update changes only version coupling. The cold caller changes only four component pins and its own identifiers. New controls must qualify before target experiments are admitted.
Finite-index fairness has a Source argument but no separate dynamic calibration in this milestone. A one-term control does not establish multi-term diversity. Full graph conformance, full PA, Hilbert geometry benchmarks, a universal proof compiler, learned receptor families and the broader turtle/Penrose program remain active work.
