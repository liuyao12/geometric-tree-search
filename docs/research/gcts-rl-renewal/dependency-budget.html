A checkable necessity certificate preserves every original solution.

Let \(\Gamma\) be the supplied hypotheses and \(U\) the finite set of grammar formulas excluding those hypotheses. For each formula \(F\), the compiler calculates a set \(D(F)\) of necessary distinct original inference outputs. Hypotheses have \(D(H)=\varnothing\). For all other formulas it solves

\[D(F)=\{F\}\cup\bigcap_{\substack{r\text{ eligible}\\\operatorname{out}(r)=F}}\ \bigcup_{A\in\operatorname{in}(r)}D(A).\]

The intersection covers every eligible alternative rule; each inner union covers all premises of that rule. Shared dependencies are counted once. The empty intersection is \(U\), and the empty union is \(\varnothing\). Scope guards are evaluated against the original fixed ambient hypotheses.

Start non-hypothesis sets at \(U\), then iterate downward to the greatest fixed point. Starting with singleton sets instead was too weak in this grammar: circular instantiation/generalization alternatives hid the necessary intermediate outputs. Only the completed fixed point is activated.

The independent certificate checker confirms every round, every eligible rule and the final local implication

\[D(\operatorname{out}(r))\subseteq\{\operatorname{out}(r)\}\cup\bigcup_{A\in\operatorname{in}(r)}D(A).\]

Preservation proof. Induct on the original source line. A supplied hypothesis contributes no required output. Every premise of an inference is a supplied hypothesis or an earlier source output. By induction its dependency set already occurs among the earlier non-hypothesis outputs. The checked local implication therefore puts every member of the conclusion's dependency set among those earlier outputs and the current output. Hence any formula written at source port \(i\geq0\) must satisfy \(|D(F)|\leq i+1\). The argument follows actual finite proofs and remains sound in grammars containing cycles. A completed original tiling's continuation and word markings identify the same source prefix, so the argument applies equally when a later tile writes a requirement at an earlier port.

At distant point \(\rho(i)=(-3000,i)\), the fixed root writes \(0\). A tile writing formula \(F\) at port \(i\) also writes

\[m_F(\rho(i))=\mathbf{1}_{\{|D(F)|>i+1\}}.\]

A disagreement is an ordinary marking conflict. Negative hypothesis ports receive no capacity marking. Erasing the new layer gives the original point model; conversely every original complete solution admits the new layer. This is a proved redundant constraint for the declared finite grammar, with no new axiom or supplied proof.
