Connect each clause to a source formula

  1. The syntax encoder reads closed typed formulas, tracks lexical scope, and pushes the sign of the refutation into each connective. For an existential it gives the fresh function the effective universal arguments in scope.
  2. The rectangle checks the reported binder kind, sort and dependency set against the compiled syntax. It reads a source selector and conjunction choices. A disjunction joins both selected clauses. The resulting literal bitmap must match the clause admitted by the ground-instantiation stage.
  3. Typed term matches admit each concrete premise. The same rectangle checks the parent indices, pivot and exact resolvent at each line. The final clause must be empty.

Forgery control. The invalid entailment \(\forall x\,P(x)\models\forall x\,Q(x)\) would admit a resolution refutation if its negated conclusion were replaced by \(\neg P(c)\). The resolution-only checker accepts that fabricated pair of clauses. The source-aware rectangle rejects the same witness at its acceptance boundary.

The source encoder, equality schemas and the bounded ground alphabet are part of the compiled boundary. The squares verify the supplied origin choices and dependencies under that boundary. The finite interpretation tests check the predicate-only examples separately. The quantifier-order control has a two-element countermodel with \(R(x,y)\) interpreted as equality.
