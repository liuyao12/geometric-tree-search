ACTUAL RECIPIENT DISCOVERY · TRAINING IS NOT A SPEEDUP CLAIM

Does the learned order help?

Two fresh statement-to-proof searches discover the source arithmetic arguments. All connected two- and three-cell proof fragments form the library, without a supplied proof sequence, saved policy or previous result. Every recipient cluster is re-instantiated from the complete original rule inventory and exact formula ports. All singleton placements remain available.

The policy has no access to formula literals, variable names or a teacher’s proof path. Its features measure cluster size and span, relative location, premise geometry, filled external premises, inference families and current progress. Features are exact integers at scale \(1024\); parameters start at zero and are quantized at scale \(10^6\). Greedy recipient rankings use exact integer dot products with the fixed ordering as a tie breaker. The policy only reorders macro proposals; ordinary moves remain the complete fallback.

This implements learned selection of validated clusters. It does not yet synthesize unrestricted new compositions or higher-level lemma grammars. Resource markings remain certified redundant constraints, shared by all four recipient lanes. No learned policy score can exclude a candidate, establish a dead end, bypass a forced move or supply a proof.

ZERO INITIALIZATION · NO RECIPIENT TRAINING · EVERY UPDATE REPLAYED

Inspect what was actually learned.

Within each source episode, weighted sampling without replacement orders all currently applicable clusters. The exact point search executes that order and retains every base alternative. The policy is frozen throughout the episode. Only executed cluster choices contribute score gradients; sampling the unused suffix earns no gradient credit. Complete native acceptance precedes a positive proof reward and parameter update.

The episodic reward is \[R=\mathbf{1}_{\text{accepted proof}}+\frac{1}{10}\frac{k}{n}-\min\left(1,\frac{a}{A}\right),\] where \(k\) is filled base proof cells, \(n\) is the source envelope, \(a\) is expanded constituent attempts and \(A\) is the declared attempt cap. Unknown cutoffs receive no proof-success credit. Each executed score gradient receives the same episode return; the update averages those gradients at learning rate \(0.2\). This small exploratory policy uses no learned value baseline. Passing the source episodes does not establish held-out improvement.

CONFORMANCE EVIDENCE AND THE EXACT LIMIT OF THE SHORTCUT
Clusters preserve proofs, while changing the search graph.


Each recipient metatile consists of distinct original placements with compatible formula/resource markings. Its occupancy is their sum, and its marking is their union, with one owner identity for the atomic placement. An exact metatile tiling expands to an exact original proof-cell assignment. Every original exact assignment can also be tiled using the retained singleton placements. Ownership values constrain decorated representation; renaming those private owner values during expansion preserves the original formula/capacity problem. The tiny exhaustive tests check equality of all expanded solution sets.


Adding genuine atomic tile types changes point degrees and can change forced moves or branching order. The claim is solution equivalence, not preservation of the primitive scheduling trace. Within that enlarged exact model, the point engine uses full frontier/candidate bookkeeping, global dead ends, global forced moves and earliest generation. All finite roots have generation zero. Copied state and graph provide exact rollback; extended formula/resource marks update their dependencies through the same graph.


Classical search uses the same complete primitive domains and necessary resource constraints. It offers every compatible cluster that contains its MRV variable, then retains every ordinary value as fallback. Assigning a cluster is a reversible simultaneous restriction of its constituent variables. Every arc-consistency deletion and every open or closed branch is independently replayed.
