Keep only the branches that can meet the window

For each patch, store its exact extrema in \(x\), \(y\), and \(x+y\). Every Turtle symmetry permutes the three axes up to sign. A placement transforms its extrema by permuting them, changing signs, and adding the translation. If the window's range in any axis has disjoint interior from the patch range, the entire branch can be skipped.

Choose an odd triangle large enough that its certified centered disk contains the window. Alternate the root half-turn as the odd level increases so all selected roots belong to the same nested plane tiling. In every trial the next odd root returned the same tile list. For two small windows, scanning all 30,624 tiles of the level-five triangle gave the same list as the hierarchy. Proof of the learned coordinate recurrence

For each result, a separate exact check triangulates the window and each returned tile, clips each pair of triangles using rational coordinates, and adds their intersection areas. The audit checks pairwise tile nonoverlap and equality of the total intersection area with the window area. The six-tile fixed region has zero excess. A positive excess means that this tiling covers the window with tiles that extend outside its boundary.

Why the window query can skip a distant patch's interior

Write \(a=L_n\) and \(b=L_{n-1}\) for adjacent strip lengths. They obey \(a=3b-L_{n-2}\), with \(a/3\le b\le a/2\) from level two onward. The macro placements have translation norm at most \(3a\), and the strip anchor, stride and primitive tile size keep the strip within radius \(12a\). The same radius bound holds for the macro patches by induction because \(12b+3a\le 9a\).

For \(n\ge 5\) a triangle contains a disk of radius at least \(a\). A half-turn patch contains an earlier triangle with a disk of radius at least \(b\). Patches of the same level occupy disjoint interiors, so their disks do too. For a fixed window, any patch of that level whose axis bounds survive pruning has its disk center within a constant multiple of \(a\) from the window. Disk packing bounds the number of such macro patches per level.

Along one strip, a signed axis with nonzero stride maps a fixed window to a bounded interval of letter positions. Occurrences of equal-height word blocks have disjoint index intervals, so only a bounded number can survive at each height. The macro levels give a linear bound on the number of strips inspected. Each strip can require a linear number of word levels. Together these give a quadratic bound in the root level on node visits for a fixed window size, counting exact integer operations separately from their bit cost.

Index the strips as words

Store the strip recurrence as a graph of shared word blocks. The second child of a concatenation starts at the word stride multiplied by the length of the first. The same axis extrema describe every block, so the query can skip whole parts of a strip.

In a matched level-nine trial, both versions returned 41 tiles and performed 41 polygon tests. Expanding strips into explicit tile lists required 3,628 tile bounding-box checks. The shared word representation needed 54. The compressed query visited 210 hierarchy nodes compared with 170 for the flat strips. The nine flat strips held 15,124 tile placements, while the shared graph reused four tile placements at its leaves.
