Propositional inference becomes marking agreement.

\[ A,\quad A\Rightarrow B\quad\vdash\quad B. \]

A command tile writes its formula. A rule guard writes the formulas required at its earlier source lines. Agreement at those distant ports binds the argument. A lemma call additionally selects an exact registered interface, and separate premise tiles choose the corresponding earlier sources. Every premise slot is represented, including inactive slots; an inactive value and source line zero are distinct assigned values.

\[m_{\mathrm{source}}(p_{i,r})=\operatorname{enc}(A)_r=m_{\mathrm{requirement}}(p_{i,r}),\qquad i<j.\]

Formula words are canonical UTF-8 JSON with a distinct terminator. Matching compares complete words, not hashes or embeddings. Strict earlier references prevent circular self-support. Colors distinguish marking layers for the reader; exact integer values determine compatibility. The learned policy scores compatible clusters in the same spirit as attention over distant dependencies. Its scores choose search order and carry no proof authority.
The factored model has command and guard points plus one point for each possible premise slot. Separate source choices avoid enumerating the Cartesian product of all premise tuples. All original commands and all strict-prior source choices remain available. This changes the high-level point representation relative to Notebook 62; it is not claimed to preserve that older model's occupancy or placement-count benchmark.


Inspect the actual learning decisions.
Twenty-four stochastic episodes start from zero weights and cycle through four training declarations. The final policy is frozen before the eight held-out declarations. The reward counts accepted base obligations and penalizes proposal work. Native catalog, definition-registration and final-check costs are reported separately; the reward does not price all of them.

\[R=\frac{(2+a)\,L_{\mathrm{accepted}}}{\max(1,N_{\mathrm{placements}})}-\frac14\min\!\left(1,\frac{N_{\mathrm{validation}}+N_{\mathrm{sample\ pair\ tests}}}{100000}\right),\]

Here \(a\) is the declared number of premise-slot points per row. REINFORCE uses a softmax over ten features, learning rate \(0.4\) and an exponential reward baseline. Only a native-accepted whole certificate earns the positive term. An exact training-only acceptance cache is disclosed for repeated certificates.

What this establishes, and what remains open.
The independent auditor imports none of the new miner, compiler, point model, policy or search. It reconstructs each candidate and marking, all visited point domains, complete fallback, every pool and hint, all stochastic choices and gradients. It separately reruns every native query from the true parser start and derives each full accepting response DAG again. Human-readable lines are projections of the actual local and root native contexts. All submitted Z3 assertions are reconstructed; selected point regions and the small UNSAT result are checked separately.
Hierarchical semantic reuse is now exercised by concrete searched proofs. The learned ordering has not improved the difficult held-out chains. Broader proof grammars, learned certified failure markings, stronger theorem-proving controls and multiple learning seeds are still needed. Full first-order proof-search completeness, a universal high-level compiler theorem, full PA and Hilbert geometry remain open, as do the original Turtle and Penrose research goals.
