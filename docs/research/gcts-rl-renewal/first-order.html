What this adds, and what remains open.

The adapter starts with input and target subformulas. Its fixed term pool contains input/target subterms whose free variables are free in the target. Two rounds uniformly construct universal-instantiation instances and include their subformulas. Atomic formula templates are formed by abstracting every eligible closed subterm. Equality operand pairs come from equality subformulas with operands in the closed term pool. One layer of the resulting equality schemes and their subformulas is added.

Every parameter instance has a determined scheme output. Each adds one positional command per eligible row, with a guard only after native admission. The historical five-rule command field products remain complete within this new formula basis. All allowed command and guard placements are present in the shared graph. There is no logical callback or chronological proof script inside search.

There is a scoped correspondence argument. Exact occupancy selects one command and one guard for each row. Their complete command words must agree. A guard either represents a native-admitted logical axiom instance or writes the exact formulas required at strict earlier rows. Induction over row order therefore gives a valid symbolic certificate. Conversely, a valid certificate in the declared finite command language selects its matching guards; all word assignments agree. This argument relies on the stated native rule semantics and complete guard admission. It is separate from a mechanically verified compiler theorem or an infinite-plane construction.

Global dead ends precede forced moves; both precede earliest-generation branching. Every required point is an explicit generation-zero root. Cluster suggestions validate exact point values, preserve all fallback alternatives and restore state on rollback. This is a finite unit-capacity proof-strip specialization. Occupancy uses \(12\) integer units per point: each selected role contributes \(12\), giving normalized tile value \(1\). Fractional tiling, arbitrary geometric transformations and fair infinite-domain activation are outside this experiment.

The addition target instantiates one defining axiom. It does not discover an induction proof or establish full Peano arithmetic. The incidence target is a symbolic typing consequence with no explicit geometry. It prepares the first-order language for Hilbert geometry; it does not establish the complete Hilbert axiom system or a Euclidean proposition. Quantifier distribution, induction, arbitrary equality templates and unrestricted first-order compiler completeness remain open.

The measured fixed and reused learned orderings are controls on the same point model. They do not establish a general RL advantage or superiority over existing theorem provers. New reusable first-order lemma families, freshly certified failure markings and appropriate external benchmarks are subsequent work.
