Build an exact continuation inventory

Start at the empty clause and enumerate its predecessors. At a target clause \(R\), take any admitted premise \(P\) and a pivot literal \(\ell\) in it. The residual premise \(Q=P\setminus\{\ell\}\) must lie in \(R\). Every predecessor has form \(C=(R\setminus Q)\cup S\cup\{\bar\ell\}\) with \(S\subseteq Q\setminus\{\bar\ell\}\). The complementary pivot \(\bar\ell\) cannot lie in \(R\setminus Q\). Enumerating these choices gives every legal non-tautological predecessor. With \(k\) rows left, an active clause may have at most \(k\) literals, since each row can remove at most one.

A completed layer is a boundary condition. If a forward state is absent from the layer for its remaining row count, that branch is exhausted. A present state carries a checked continuation. If a layer reaches its work cap, the solver uses the last complete layer.

When propagation stops without a conflict, Glucose tests the remaining ground problem. Proof length sets the rectangle dimensions in this control.
