Result and scope

The independently checked exclusions, together with an independent replay of all three remaining branches, rule out an infinite tiling by this nonacube on the integer cubic lattice, allowing all three cubic orientations. This does not rule out other Euclidean placements or determine the unrestricted geometric Heesch number. The previously verified unmarked first corona remains valid.

From local holes to a useful collection

The earlier single forbidden pair only established that the method could work. This run enumerated all 60 neighbouring pair types from the unmarked model. For each pair, it required every voxel within Chebyshev distance two of either fixed tile to be covered. Every integer placement touching that target was included, including tiles extending outside it, with overlap checked everywhere.

Each solver call had a five-second solving budget. All 58 exclusions have separately checked DRAT proofs; two timeouts remain unknown. A finite successful filling would not establish infinite extension. No earlier exclusions or learned markings were supplied to these tests.

Fresh collection, proof checking and certificate writing took 208.93 seconds. Reconstructing and replaying all saved proofs before the benchmark took another 63.80 seconds. These are preparation costs, not search time.

What the markings do to the tree

The compiler produces 1,392 sparse components with 2,784 assigned values across the three orientations. Every disagreement was checked against the certified pair orbits; all other neighbouring pairs agree. During search the ordinary point-marking section removes candidates. There is no runtime pair classifier or region solver.

At the root obligation \((0,4,4)\) in the model’s doubled coordinates, only three placements remain. Each produces a dead frontier immediately. The replay independently enumerates every candidate at that point and every possible completion at the resulting dead points.

Since each marking exclusion is necessary in any infinite tiling, an infinite unmarked tiling would survive the markings and furnish a continuation of one of these three branches. None exists.

Replay and implementation

Model and full pair catalogue · All outcomes and proof digests · Search results · Three-branch replay · Certificate manifest

With an independent drat-trim executable, the saved dataset can be re-proved and benchmarked directly from the repository:

node scripts/benchmark-voxel-region-markings.mjs \
  --input data/nonacube-region-study \
  --drat-trim /path/to/drat-trim \
  --output /tmp/nonacube-benchmark.json
node scripts/verify-voxel-region-root.mjs \
  data/nonacube-region-study /tmp/nonacube-root.json

The benchmark refuses to use saved exclusions without regenerating their formulas and replaying every negative proof. Fresh collection is available through export-voxel-pair-regions.mjs and screen-voxel-pair-regions.py; the latter uses Python-SAT / Glucose3. No learned marking assignments are committed.

This headless research run supplies the recorded results above. The browser’s cold learner still uses its earlier immediate-dead-point and one-corona tests; it does not silently load this dataset. Its “Recorded evidence” link opens this study.
